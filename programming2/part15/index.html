Undantagshantering (Exception Handling) ​

Undantagshantering är en viktig del av programmering och handlar om att hantera fel och oväntade situationer som kan uppstå när ett program körs.

Här ska vi gå igenom vad undantag är, hur de hanteras i Python och varför det är viktigt.

Vad är undantag? ​

Undantag är ett fel som inträffar när ett program körs, till exempel:

  • Ett försök att dela ett tal med noll.
  • Försök att öppna en fil som inte finns.
  • Användning av fel datatyp i en funktion.

Om ett undantag inträffar och det inte hanteras, kommer programmet att krascha.

Exempel på ett undantag:

python
tal = 5 / 0
# Detta kommer att ge felet "ZeroDivisionError: division by zero".

2

Hur fungerar undantagshantering i Python? ​

I Python används nyckelorden try, except, else och finally för att hantera undantag. Här är deras roller:

  1. try
    Koden som kan orsaka ett undantag placeras här.

  2. except
    Denna del används för att hantera det specifika undantaget som kan uppstå.

  3. else (valfritt)
    Körs om inget undantag inträffar i try-blocket.

  4. finally (valfritt)
    Körs alltid, oavsett om ett undantag inträffar eller inte. Används ofta för att städa upp resurser, till exempel stänga filer.

Exempel på undantagshantering ​

Låt oss skriva ett program som tar två tal och dividerar dem. Vi hanterar undantag för att undvika att programmet kraschar.

Exempel:

python
try:
    täljare = int(input("Ange täljare: "))
    nämnare = int(input("Ange nämnare: "))
    resultat = täljare / nämnare
except ZeroDivisionError:
    print("Fel: Du kan inte dela med noll!")
except ValueError:
    print("Fel: Du måste ange ett heltal!")
else:
    print(f"Resultatet är: {resultat}")
finally:
    print("Programmet avslutades.")

Förklaring:

  1. try: Försöker köra koden som kan orsaka ett fel.
  2. except ZeroDivisionError: Fångar ett specifikt fel om användaren försöker dela med noll.
  3. except ValueError: Fångar felet om användaren matar in något annat än heltal.
  4. else: Körs om inget undantag inträffar.
  5. finally: Skriver alltid ut meddelandet att programmet avslutades.

Hantering av flera undantag ​

Man kan hantera flera olika typer av undantag med separata except-block.
Om du inte är säker på vad som kan gå fel kan du också fånga alla typer av undantag med ett generellt except-block.

Exempel:

python
try:
    fil = open("data.txt", "r")
    data = fil.read()
except FileNotFoundError:
    print("Fel: Filen hittades inte.")
except PermissionError:
    print("Fel: Du har inte rättigheter att öppna filen.")
except Exception as e:
    print(f"Ett oväntat fel inträffade: {e}")
finally:
    print("Klart!")

Förklaring:

  1. except Exception as e:
    • Här fångas alla fel som ärver från basklassen Exception.
    • Felet lagras i variabeln e, som kan skrivas ut eller användas för felsökning.
  2. Programmet kommer inte att krascha, även om ett oväntat undantag uppstår, som:
    • Division med noll (ger ZeroDivisionError).
    • Felaktig inmatning (ger ValueError).

Skapa egna undantag ​

Python låter dig skapa egna undantag med hjälp av klasser som ärver från Exception.

Exempel:

python
class NegativtTalError(Exception):
    pass

def kontrollera_positivt_tal(tal):
    if tal < 0:
        raise NegativtTalError("Talet får inte vara negativt!")

try:
    nummer = int(input("Ange ett positivt tal: "))
    kontrollera_positivt_tal(nummer)
except NegativtTalError as e:
    print(f"Fel: {e}")

Förklaring av klassen:

  1. class NegativtTalError(Exception):
    • Här definieras en ny undantagsklass som ärver från den inbyggda Exception-klassen.
    • Genom att ärva från Exception kan NegativtTalError användas precis som andra inbyggda undantag, till exempel ValueError eller ZeroDivisionError.
  2. pass
    • Nyckelordet pass används för att indikera att klassen inte behöver någon ytterligare funktionalitet just nu.
    • Klassen är i princip bara ett namn som kan användas för att kasta och hantera undantag.
  3. Varför ingen kod inuti?
    För en anpassad undantagsklass behövs oftast inte extra funktionalitet, eftersom undantagets huvudsakliga syfte är att:
    • Skilja sig från andra undantag genom sitt namn.
    • Möjliggöra specifik hantering av just detta undantag med try-except.

Sammanfattning av nyckelbegrepp ​

  • Undantag : Fel som uppstår under programmets körning.
  • try-except : Används för att fånga och hantera undantag.
  • else : Körs om inget undantag inträffar.
  • finally : Körs alltid, används för att städa upp.
  • Egna undantag : Skapa och använda specialanpassade undantag.

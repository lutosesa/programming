Stark och svag samt statisk och dynamisk typning. ​

Typning är hur vi hanterar olika typer av data i programmet. I denna del går vi igenom vad typning betyder i Python, hur det fungerar, och varför det är viktigt.

Vad är typning i programmering? ​

Typning handlar om hur programmeringsspråket hanterar datatyper. Datatyper kan vara till exempel:

  • Heltal (engelska: integers) – t.ex. 5
  • Text (engelska: strings) – t.ex. "Hej"
  • Decimaltal (engelska: floats) – t.ex. 3.14
  • Booleska värden (engelska: booleans) – t.ex. True eller False

I Python behöver du inte säga vilken typ en variabel har innan du använder den. Men språket håller ändå koll på vilken typ variabeln är när du kör programmet.

Stark och svag typning ​

Stark typning ​

Python är ett starkt typat språk, vilket betyder att du inte kan blanda olika typer av data utan att få fel.

Exempel

python
x = 10          # x är ett heltal
y = "5"         # y är en text
print(x + y)    # Fel! Du kan inte lägga ihop ett heltal med en text.

Lösning: Om du verkligen vill kombinera dessa, måste du omvandla datan:

python
x = 10
y = "5"
print(x + int(y))  # Här görs y om till ett heltal innan addition.

Svag typning ​

I svagt typade språk (som vissa andra programmeringsspråk) skulle programmet försöka göra om typerna automatiskt. Men Python gör inte detta, eftersom det kan leda till oväntade resultat.

Statisk och dynamisk typning ​

Dynamisk typning ​

Python använder dynamisk typning, vilket betyder att du inte behöver säga vilken typ en variabel har när du skapar den. Python bestämmer automatiskt typen utifrån vad du skriver.

Exempel

python
x = 10          # x är ett heltal nu
x = "Hej"       # Nu blir x en text istället
print(x)        # Programmet fungerar utan problem.
1
2
3

Statisk typning ​

I statiskt typade språk måste du alltid bestämma vilken typ en variabel ska ha när du skapar den, och den typen kan inte ändras.

Exempel i ett annat språk (C++):

python
int x = 10;     // x är ett heltal
x = "Hej";      // Fel! Du kan inte ändra typen på x.
1
2

Python kan vi använda typanoteringar för att visa vilken typ vi förväntar oss, men Python kontrollerar inte detta strikt.

Exempel:

python
def add(a: int, b: int) -> int:
    return a + b

resultat = add(5, 3)  # Detta fungerar.
resultat = add("Hej", 3)  # Programmet kraschar eftersom vi försöker lägga ihop text och ett heltal.

Typanoteringar är mest användbara för att göra koden tydligare och för att undvika misstag.

Exempel på typning i Python ​

  1. Skapa variabler med olika typer

Exempel:

def add(a: int, b: int) -> int:
    return a + b

resultat = add(5, 3)  # Detta fungerar.
resultat = add("Hej", 3)  # Programmet kraschar eftersom vi försöker 
                          # lägga ihop text och ett heltal.

  1. Ändra typen dynamiskt

Exempel:

python
x = 100                  # x är ett heltal
x = "Nu är jag en text!" # Nu är x en text
print(x)                 # Skriver ut: Nu är jag en text!

  1. Fel med stark typning

Exempel:

python
tal = 5
text = "Nummer"
print(tal + text)   # Fel! Du kan inte blanda heltal och text.

Sammanfattning ​

  1. Python är starkt typat, vilket betyder att du inte kan blanda olika typer utan att konvertera dem.
  2. Python är dynamiskt typat*, vilket innebär att du inte behöver specificera typen för variabler när du skapar dem. Python bestämmer typen automatiskt.
  3. Typanoteringar kan användas för att göra din kod tydligare, men de är valfria och Python kommer fortfarande att vara dynamiskt typat.

Uppgift 1: Djurhierarki ​

Skapa en klasshierarki som representerar olika typer av djur. Du ska ha en superklass som heter Djur och sedan skapa subklasser som är specifika typer av djur. Varje subklass ska ha en unik metod som är specifik för just den djurarten.

Instruktioner:

  1. Skapa en superklass Djur med attributen namn och ålder samt en metod gör_ljud.

  2. Skapa två subklasser: Katt och Fisk.

    • Katt ska ha en metod som heter kurrar.
    • Fisk ska ha en metod som heter simmar.

  3. Överskriv gör_ljud-metoden i både Katt och Fisk.

  4. Skapa objekt av varje subklass och anropa deras unika metoder.

Lösning:

python
# Superklass: Djur
class Djur:
   def __init__(self, namn, ålder):
      self.namn = namn
      self.ålder = ålder

   def gör_ljud(self):
      print(f"{self.namn} gör ett ljud.")

# Subklass: Katt
class Katt(Djur):
   def __init__(self, namn, ålder):
      super().__init__(namn, ålder)

   def gör_ljud(self):
      print(f"{self.namn} jamar.")
   
   def kurrar(self):
      print(f"{self.namn} kurrar.")

# Subklass: Fisk
class Fisk(Djur):
   def __init__(self, namn, ålder):
      super().__init__(namn, ålder)

   def gör_ljud(self):
      print(f"{self.namn} gör inget ljud.")
   
   def simmar(self):
      print(f"{self.namn} simmar.")


# Testa hierarkin
katt = Katt("Misse", 3)
fisk = Fisk("Nemo", 1)

katt.gör_ljud()   # Output: Misse jamar.
katt.kurrar()     # Output: Misse kurrar.

fisk.gör_ljud()   # Output: Nemo gör inget ljud.
fisk.simmar()     # Output: Nemo simmar.

Uppgift 2: Fordonshierarki ​

Skapa en klasshierarki för olika typer av fordon. Fordonen ska ärva från en gemensam siperklass och ha olika specifika egenskaper beroende på vilken typ av fordon det är.

Instruktioner:

  1. Skapa en superklass Fordon med attributen märke och modell, samt en metod beskrivning.
  2. Skapa två subklasser: Bil och Cykel.
    • Bil ska ha ett extra attribut dörrar.
    • Cykel ska ha ett extra attribut typ (t.ex. mountainbike, stadscykel).
  3. Överskriv beskrivning-metoden i både Bil och Cykel för att inkludera deras specifika attribut.
  4. Skapa objekt för både Bil och Cykel och anropa deras beskrivning-metoder.

Förväntad utdata:

python
bil = Bil("Toyota", "Corolla", 4)
cykel = Cykel("Crescent", "Classic", "Stadscykel")

bil.beskrivning()    # Output: Toyota Corolla med 4 dörrar.
cykel.beskrivning()  # Output: Crescent Classic, typ: Stadscykel.

Uppgift 3: Skapande av Elektronikhierarki ​

Skapa en klasshierarki för olika typer av elektroniska enheter. Fokusera på att hantera attribut som är gemensamma för alla enheter och unika för specifika typer av enheter.

Instruktioner:

  1. Skapa en superklass ElektroniskEnhet med attributen märke och pris, samt en metod info.
  2. Skapa två subklasser: Telefon och Laptop.
    • Telefon ska ha ett attribut antal_kameror.
    • Laptop ska ha ett attribut ram_minne.
  3. Lägg till en metod i Telefon som heter ringa_samtal och en metod i Laptop som heter starta_program.
  4. Överskriv info-metoden i både Telefon och Laptop.
  5. Skapa objekt för både Telefon och Laptop och anropa deras metoder.

Förväntad utdata:

python
telefon = Telefon("Apple", 12000, 3)
laptop = Laptop("Dell", 15000, "16GB")

telefon.info()          # Output: Telefon: Apple, Pris: 12000 kr, Kameror: 3
laptop.info()           # Output: Laptop: Dell, Pris: 15000 kr, RAM: 16GB

telefon.ringa_samtal()  # Output: Ringer ett samtal från Apple telefon.
laptop.starta_program() # Output: Startar ett program på Dell laptop.

Uppgift 4: Bibliotekshierarki ​

Bygg en klasshierarki för att hantera olika typer av media som finns i ett bibliotek. Det kan inkludera böcker, tidningar och digitala medier.

Instruktioner:

  1. Skapa en superklass Media med attributen titel och år.
  2. Skapa tre subklasser: Bok, Tidning, och Ebok.
    • Bok ska ha ett extra attribut författare.
    • Tidning ska ha ett extra attribut nummer.
    • Ebok ska ha ett extra attribut filstorlek.
  3. Överskriv en metod beskrivning i varje subklass för att visa relevant information om varje media.
  4. Skapa objekt för varje subklass och anropa deras beskrivning-metod.

Förväntad utdata:

python
bok = Bok("Harry Potter", 1997, "J.K. Rowling")
tidning = Tidning("Dagens Nyheter", 2023, 145)
ebok = Ebok("Python Programming", 2020, "5MB")

bok.beskrivning()       # Output: Bok: Harry Potter av J.K. Rowling, publicerad 1997.
tidning.beskrivning()   # Output: Tidning: Dagens Nyheter, Nummer: 145, År: 2023.
ebok.beskrivning()      # Output: E-bok: Python Programming, År: 2020, Storlek: 5MB.

Sammanfattning av uppgifterna ​

Dessa uppgifter ger praktisk erfarenhet av att arbeta med:

  • Skapande av klasser och subklasser.
  • Implementering av arv för att återanvända kod.
  • Överskrivning av metoder i subklasser för specifik funktionalitet.

Du får träna på att bygga klasshierarkier för att modellera verkliga företeelser, vilket hjälper dig att bättre förstå och använda objektorienterade begrepp i Python.

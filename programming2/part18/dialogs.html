Tkinter Dialoger ​

Tkinter-dialoger är specialiserade fönster eller moduler som tillhandahålls av Tkinter, det inbyggda GUI-biblioteket i Python, för att interagera med användaren. Dessa dialoger används ofta för att utföra vanliga uppgifter som att visa meddelanden, hämta inmatning från användaren, välja filer, färger, eller andra funktioner. De fungerar som popup-fönster som tillfälligt tar fokus från huvudapplikationen.

Här är en översikt över några vanliga Tkinter-dialoger:

1. Messagebox (Meddelanderutor) ​

Används för att visa information eller fråga användaren om något. Den tillhör modulen tkinter.messagebox.

Man kan använda olika funktioner beroende på vad du vill säga till användaren:

  • messagebox.showinfo(): För att visa information.
  • messagebox.showwarning(): För att visa en varning.
  • messagebox.showerror(): För att visa ett felmeddelande.
  • messagebox.askquestion(): För att ställa en fråga som returnerar en sträng med värdet "yes" eller "no".
  • messagebox.askyesno(): För att be om användarbekräftelse som returnerar värdet True eller False svar.

Messagebox demo

python
import tkinter as tk
from tkinter import ttk
from tkinter.messagebox import showerror, showwarning, showinfo, askyesno

# create the root window
root = tk.Tk()
root.title('MessageBox demo')
root.resizable(False, False)
root.geometry('350x200')

options = {'fill': 'both', 'padx': 10, 'pady': 10, 'ipadx': 5}

ttk.Button(
    root,
    text='Visa ett felmeddelande',
    command=lambda: showerror(    
        title='Felmeddelande',
        message='Detta är ett felmeddelande!')
).pack(**options)

ttk.Button(
    root,
    text='Visa ett informationsmeddelande',
    command=lambda: showinfo(     
        title='Information',
        message='Detta är ett informationsmeddelande!')
).pack(**options)

ttk.Button(
    root,
    text='Visa ett varningsmeddelande',
    command=lambda: showwarning(   
        title='Varning',
        message='Detta är ett varningsmeddelande!')
).pack(**options)

# click event handler
def confirm():
    answer = askyesno(title='Bekräftelse',    
                      message='Är du säker på att du vill avsluta?')
    if answer:
        root.destroy()

ttk.Button(root, text='Ställ Ja/Nej fråga',
           command=confirm).pack(**options)    

root.mainloop()

2. Filedialog (Filvalsdialog) ​

Används för att öppna eller spara filer. Tillhör modulen tkinter.filedialog.

Exempel på funktioner:

  • filedialog.askopenfilename(): Öppna och returnerar filnamnet (en fil) du valde.
  • filedialog.asksaveasfilename(): Välj en plats för att spara en fil.
  • filedialog.askopenfilenames(): Öppna flera file
  • filedialog.askdirectory(): Välj en katalog (map).

Filedialog demo

python
from tkinter import Tk, ttk, filedialog
from tkinter.messagebox import showinfo
# Skapa huvudfönstret
root = Tk()
root.title("filedialog.askopenfilename demo")
root.geometry("400x200")

# Funktion för att öppna en filvalsdialog
def open_file():
    filename = filedialog.askopenfilename(
        title="Välj en fil",
        filetypes=[("Textfiler", "*.txt"), ("Pythonfiler", "*.py"), ("Alla filer", "*.*")]
    )
    if filename:
        showinfo( title='Vald Fil', message=filename)
    else:
        showinfo(title='Vald Fil', message="Ingen fil valdes!")

# Skapa en knapp som öppnar dialogen
options = {'fill': 'both', 'padx': 50, 'pady': 50, 'ipadx': 5}
ttk.Button(root,
           text="Öppna fil",
           command=open_file).pack(**options)

root.mainloop()

3. Color chooser (färgvalsdialog) ​

Används för att välja färger. Tillhör modulen kinter.colorchooser.

Color chooser demo

python
import tkinter as tk
from tkinter import ttk
from tkinter.colorchooser import askcolor

# Skapa huvudfönstret
root = tk.Tk()
root.title('Color Chooser demo')
root.geometry('400x200')

# Funktion för att byta bakgrundsfärg
def change_color():
    colors = askcolor(title="Välj en färg")
    if colors[1]:  # Kontrollera om användaren valde en färg
        root.configure(bg=colors[1])

# Skapa en knapp för att öppna färgväljaren
options = {'fill': 'both', 'padx': 50, 'pady': 50, 'ipadx': 5}
ttk.Button(root,
           text='Byt bakgrundsfärg',
           command=change_color).pack(**options)

root.mainloop()

4. SimpleDialog (Enkel inmatningsdialog) ​

Används för att be användaren skriva in något, t.ex. ett namn eller ett nummer. Tillhör modulen tkinter.simpledialog.

Exempel på funktioner:

  • simpledialog.askstring(): Be om en textsträng.
  • simpledialog.askinteger(): Be om ett heltal.
  • simpledialog.askfloat(): Be om ett decimaltal.

Enkel inmatningsdialog demo

python
from tkinter import Tk, ttk
from tkinter.simpledialog import askstring

# Skapa huvudfönstret
root = Tk()
root.title("SimpleDialog demo")
root.geometry("350x200")

# Funktion som visar en enkel dialog för att fråga efter användarens namn
def ask_for_name():
    name = askstring("Inmatning", "Vad heter du?")  # Öppnar inmatningsdialog
    if name:                   # Kontrollera om användaren skrev något
        label_name.config(text=f"Användarens namn: {name}", foreground="green")
    else:
        label_name.config(text="Inget namn angavs.", foreground="red")

# Skapa en knapp för att öppna dialogen
options = {'fill': 'both', 'padx': 50, 'pady': 40, 'ipadx': 5}
ttk.Button(root, text="Fråga efter namn", command=ask_for_name).pack(**options)

# Skapa etikett för användarens namn
label_name = ttk.Label(root)
label_name.pack()

root.mainloop()

Sammanfattning ​

Tkinter-dialoger är kraftfulla och användarvänliga verktyg för att skapa interaktiva GUI-program i Python. De gör det enkelt att hantera vanliga användarinteraktioner utan att behöva koda all funktionalitet från grunden.

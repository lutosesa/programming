Skapande av användarvänliga gränssnitt, Tkinter ​

När vi bygger program som användare ska köra är det viktigt att tänka på hur gränssnittet ser ut och fungerar. Ett användarvänligt gränssnitt gör det enklare för användare att förstå och använda programmet.

I detta avsnitt kommer vi att gå igenom hur man skapar ett användarvänligt grafiskt användargränssnitt (GUI) med hjälp av Tkinter, ett bibliotek i Python. Vi kommer att titta på grundläggande komponenter som fönster, etiketter, knappar, textrutor och hur man gör dessa komponenter (widgets) enkla att använda och förstå.

Några viktiga steg för ett användarvänligt gränssnitt ​

  • Designprinciper för användargränssnitt: Hur man skapar ett användarvänligt gränssnitt, till exempel genom att hålla det enkelt, tydligt och lätt att navigera.
  • Interaktivitet: Hur man lägger till funktionalitet som gör att användaren kan interagera med programmet, till exempel genom att klicka på knappar eller skriva text i fält.
  • Funktionalitet: Att programmet fungerar smidigt när användaren interagerar med det, utan fördröjning eller oväntade beteenden.
  • Tillgänglighet: Att säkerställa att programmet är användbart för så många som möjligt, till exempel genom att använda tydlig text och kontraster, samt erbjuda olika sätt att interagera med gränssnittet.

Vad är Tkinter? ​

Tkinter är ett av de enklaste och mest populära sätten att skapa grafiska användargränssnitt (GUI) i Python, skrivbordsapplikationer. Det är en inbyggd modul i Python, vilket betyder att du inte behöver installera något extra för att använda det.

Tkinter erbjuder en mängd olika widgets (komponenter/element) som etiketter, knappar, textrutor och mer som kan användas för att skapa interaktiva användargränssnitt.

Interaktiva användargränssnitt bygger på händelsedriven programmering, vilket innebär att programmet reagerar på olika händelser (events) som användaren utför, till exempel att klicka på en knapp, skriva text i en textruta eller trycka på en tangent. I stället för att programmet körs sekventiellt rad för rad, väntar det på dessa händelser och utför specifika funktioner (så kallade callbacks) när en händelse inträffar. En "callback" i Python är en funktion som skickas som argument till en annan funktion.

I Tkinter används en händelse-loop,root.mainloop(), som kontinuerligt lyssnar efter användarinteraktioner. När en händelse inträffar, t.ex. ett knappklick, anropas en fördefinierad funktion som hanterar händelsen, vilket gör gränssnittet interaktivt och dynamiskt.

De viktigaste komponenterna:

  • Root: Huvudfönster där allt skapas.
  • Widgets: Dessa är element som etiketter, knappar, textrutor, osv.
  • Layouthanterare: Hur widgets placeras i fönstret, används det följande funktioner: pack(), grid(), place().
  • Händelser: Knappar och andra element kan få funktioner kopplade till sig för att reagera på användarens handlingar.

Komma igång med Tkinter ​

Skapa ditt första fönster ​

Först och främst måste man importera Tkinter modulen:

  • import tkinter as tk

Det finns två huvudmetoder som du behöver komma ihåg när du skapar Tkinter-applikationer:

  • root = tk.Tk(): för att skapa en instans av tk.Tk klassen som skapar programfönstret.

  • root.mainloop(): metoden används för att köra applikationen när den är klar. Det är en oändlig loop som håller applikationen igång, väntar på att händelser inträffar (som knappklick) och bearbetar dessa händelser så länge fönstret inte är stängt.

    Följande program visar hur man skapar det enklaste huvudfönstret i Tkinter:

    python
    import tkinter as tk 
root = tk.Tk()        
root.mainloop()

Det finns flera attribut och metoder som gör det möjligt att styra huvudfönstrets egenskaper. Här är några av de vanligaste attributen och metoderna för att ändra huvudfönstret i Tkinter:

  • title(): sätter titeln på huvudfönstret.

    • Exempel: root.title("Mitt första GUI")

  • geometry(): används för att definiera fönstrets storlek och position.

    • Exempel: root.geometry("500x300+100+100"). Detta ställer in fönstrets storlek till 500x300 pixlar och placerar det på positionen (100, 100) på skärmen.

  • configure(): kan användas för att ändra flera attribut på en gång, såsom fönstrets storlek, färger, och mer.

    • Exempel: root.configure(bg="#C5DBF7"), ändrar bakgrundsfärgen på huvudfönstret till ljusblå.
    • Färgen kan anges som hexadecimal eller text t.ex, 'red' eller '#FF0000', 'green' eller '#00FF00'.

  • resizable(): anger om fönstret kan ändra storlek eller inte.

    • Exempel: root.resizable(False, False), fönstret blir inte ändringsbart i storlek (varken horisontellt eller vertikalt).

  • iconbitmap(): sätter fönstrets ikon (det lilla bilden som visas i fönstrets övre vänstra hörn).

    • Exempel: root.iconbitmap("path_to_icon.ico"), anger en egen ikon för fönstret, här används en .ico-fil.
    • Ladda ner ikon-bilden i mappen där du har din Python fil: favicon.ico

    Exempel med flera ändringar på huvudfönstret

    import tkinter as tk

# Skapar huvudfönster
root = tk.Tk()     
root.title("Mitt första GUI")    
root.geometry("500x300")         
root.configure(bg="#C5DBF7")     
root.resizable(False, False)     
root.iconbitmap("favicon.ico")   

root.mainloop()

Lägg till Widgets ​

I Tkinter är widgets de byggstenar du använder för att skapa ett grafiskt användargränssnitt (GUI). Tänk på widgets som olika delar eller verktyg som du lägger in i ditt fönster för att användaren ska kunna se och göra saker. Det kan vara allt från knappar och textrutor till menyer och rullgardiner.

Här nedan kommer vi att visa tre av det vanligaste widgetarna, dess parametrar, hur de används och exempel på dem ( Det finns flera av det vanligaste widgetarna på nästa sida):

Label (Etikett) ​

Används för att visa text eller bilder i ett fönster. Det är en av de enklaste och mest grundläggande widgets i Tkinter, och den används ofta för att visa rubriker, meddelanden, instruktioner eller annan statisk information.
Här nedan finns det flera parametrar för att ändra Etikettens egenskaper.

Vanliga parametrar för Label-widget:

  1. text: Texten som ska visas i etiketten. Det är den vanligaste parametern för att visa en enkel text.

  2. font: Bestämmer vilken font (stil och storlek) som ska användas för texten. Du kan ange fonten som en tuple med tre delar: stil, storlek och eventuell andra egenskaper.

  3. fg (foreground): Färgen på texten (textfärgen). Du kan använda färgnamn som "red", "blue", eller hexadecimal-koder som "#FF5733".

  4. bg (background): Bakgrundsfärgen på etiketten. På samma sätt som fg, kan du använda färgnamn eller hexadecimal-koder.

  5. width: Bestämmer bredden på etiketten i antal tecken. Om texten är kortare än bredden, fylls området med tomrum.

  6. height: Bestämmer höjden på etiketten i antal rader. Om texten är kortare än höjden, fylls området med tomrum.

  7. anchor: Bestämmer hur texten ska justeras inom etikettens område (t.ex. centrera (standard), vänster- eller högerjustera). T.ex. anchor="w" vänster, anchor="e" höger

  8. justify: Om texten består av flera rader, kan du använda justify för att bestämma hur texten ska justeras på varje rad (t.ex. vänster, höger, eller centrerad).

  9. image: Används för att visa en bild istället för text. Du måste skapa ett bildobjekt med hjälp av t.ex. PhotoImage eller PIL (Python Imaging Library).

    Label demo

    python
    import tkinter as tk

# Skapar huvudfönster
root = tk.Tk()
root.title("Label demo")
root.geometry("500x300")
root.config(bg="#C5DBF7")
root.iconbitmap("favicon.ico")

# Skapar en etikett med flera attribut och visar en text
tk.Label( root,                             
        text="Välkommen till Tkinter",    
        font=("Arial", 28, "bold"),       
        fg="#2A669A",                     
        bg="#C5DBF7"
        ).pack(pady=10)  # lägger/placerar etiketten i fönstre                                

# Skapar en etikett och visar en bild
image = tk.PhotoImage(file="bild.png")   # Laddar en bild med PhotoImage-klass
tk.Label( root, image=image, bg="#C5DBF7" ).pack(pady=10)   

root.mainloop()

Button (Knapp) ​

Används för att skapa knappar. En knapp kan användas för att låta användaren klicka på den och på så sätt utföra en viss funktion eller köra en specifik kod när den trycks.

Vanliga parametrar för Button-widget:

  1. text: Texten som visas på knappen
  2. command: En funktion som ska köras när knappen klickas på. Detta är mycket användbart för att göra knappen interaktiv.
  3. borderwidth: Bestämmer bredden på knappens kant. Används för att skapa en upphöjd eller nedtryckt effek
  4. relief: Bestämmer knappens stil (utseende). Vanliga värden är:
    • "flat": Platt knapp utan upphöjning.
    • "raised": Upphöjd knapp.
    • "sunken": Nedtryckt knapp.
  5. state: Bestämmer knappens tillstånd. Vanliga värden är:
    • "normal" (standard, knappen är klickbar)
    • "disabled" (knappen är inaktiv och kan inte klickas på)
  6. font: Bestämmer textens stil och storlek på knappen.
  7. fg (foreground): Färgen på knapp-texten.
  8. bg (background): Bakgrundsfärgen på knappen.
  9. width: Bestämmer bredden på knappen.
  10. height: Bestämmer höjden på knappen.
  11. image: Om du vill visa en bild på knappen istället för text, kan du använda denna parameter. Du behöver skapa en bild med PhotoImage eller PIL.

Button demo

python
import tkinter as tk

# Skapar huvudfönster
root = tk.Tk()
root.title("Button demo")
root.geometry("500x300")
root.configure(bg="purple")
root.iconbitmap("favicon.ico")

# command - funktion som ökar räknaren
count = 0
def increase_count():
    global count
    count += 1
    label.config(text=f"Räknare: {count}")

tk.Button( root,                        
           text="Öka antalet",          
           command=increase_count,      
           width=15,                    
           font=("Bookman Old Style", 13, "bold"),  
           bg="Violet",                 
           relief="raised",  
           borderwidth=5
         ).pack(pady=30)  

label = tk.Label(root, text="Räknare: 0", font=("Arial", 16), bg="purple", fg="white")
label.pack(pady=10)
root.mainloop()

Entry (Textruta) ​

Används för att skapa en textruta (textfält) där användaren kan skriva in information, t.ex. ett namn, lösenord eller ett tal. Den används när du vill ha en enkel, enradig inmatning från användaren.

Vanliga parametrar för Entry-widget:

  1. state: Bestämmer om textfältet är redigerbart eller ej. Vanliga värden är:
    • "normal": Textfältet är redigerbart.
    • "disabled": Textfältet är inaktivt och kan inte redigeras.
    • "readonly": Textfältet är synligt men kan inte ändras.
  2. justify: Bestämmer hur texten ska justeras i textfältet. Vanliga värden är:
    • left": Vänsterjusterad text (standard).
    • "center": Centrerad text.
    • "right": Högerjusterad text.
  3. font: Bestämmer vilken font som används för texten i textfältet. Anges som en tuple med fontnamn och storlek.
  4. fg (foreground): Sätter textfärgen (textens färg).
  5. bg (background): Sätter bakgrundsfärgen på textfältet.
  6. width: Bestämmer bredden på textfältet i antal tecken. Om texten är kortare än bredden, fylls området med tomrum.
  7. insert: Används för att sätta in en förvald text i textfältet när det skapas.
    python
    entry = tk.Entry(root)
entry.insert(0, "Förvald text")
  8. get(): metoden get() används för att hämta texten som användaren har skrivit in i ett Entry-fält. Detta returnerar texten som en sträng.
    python
    def get_data():
    text = entry.get()           # Hämtar texten från Entry-widgeten
    print("Inmatad text:", text)

entry = tk.Entry(root)
button = tk.Button(root, text="Hämta text", command=get_data)
  9. delete(): Används för att tömma textfältet. Denna metod tar två argument: start- och slutindex för det textområde som ska tas bort. För att tömma hela fältet kan du använda startindex 0 och slutindex tk.END (som refererar till slutet av texten).
    python
    def clean_entry():
    entry.delete(0, tk.END)  # Tömmer hela textfältet

entry = tk.Entry(root)
button = tk.Button(root, text="Töm fält", command=clean_entry)
  10. validate: Används för att specificera en valideringsfunktion som körs när texten i textfältet ändras. Det gör att du kan säkerställa att användaren skriver in korrekt information.
    python
    def validate_input(input_value):
    if input_value.isdigit():
        return True
    return False

entry = tk.Entry(root, validate="key", 
                 validatecommand=(root.register(validate_input), "%P"))
  11. show: Gör så att texten som skrivs in inte visas i klartext, utan istället visas som t.ex. asterisker (*). Detta används ofta för lösenordfält.
    python
    def show_password():
    password = entry.get()
    label.config(text=f"Lösenordet är: {password}")

entry = tk.Entry(root, show="*")   
entry.pack(pady=(30, 15))

# Skapa en knapp som visar det inmatade lösenordet i en etikett
tk.Button(root, text="Visa Lösenord", command=show_password).pack()

# Skapa en etikett för att visa lösenordet
label = tk.Label(root, text="Lösenordet kommer att visas här")
label.pack(pady=10)

Layouthanterare (pack(), grid(), place()) ​

För att placera och arrangera olika element (widgets) i ett fönster eller en ram använder vi layouthanterare. De tre vanligaste layouthanterarna i Tkinter är:

  • pack(): Placerar widgets i ordning (uppifrån och ned).
  • grid(): Använder ett rutnät för att placera widgets.
  • place(): Tillåter dig att exakt positionera widgets med koordinater.

Här förklarar vi hur de fungerar och när man bör använda dem.

pack() ​

pack() är den mest grundläggande layouthanteraren. Den används för att placera widgets vertikalt eller horisontellt inom en container (t.ex. ett fönster eller en ram). Widgets placeras automatiskt baserat på ordningen de läggs till i koden.

Parametrar i pack() ​

  • padx, pady: Lägger till utrymme (padding) runt widgeten horisontellt (x) och vertikalt (y).
  • side: Bestämmer vilken sida av fönstret widgeten ska placeras (t.ex. top, bottom, left, right). Standard är top.
  • fill: Fyller widgeten horisontellt (X), vertikalt (Y), eller båda (BOTH).
  • expand: Om True, får widgeten mer utrymme om fönstret ändrar storlek.

Exempel med padx, pady:

  • padx: Lägger till ett extra horisontellt utrymme (mellan widgeten och andra objekt på vänster och höger sida).
  • pady: Lägger till ett extra vertikalt utrymme (mellan widgeten och andra objekt ovanför och under).
  • De används ofta i layouthanterare som pack(), grid(), eller place().

Exempel

python
import tkinter as tk

# Skapa ett fönster
root = tk.Tk()

label1.pack(pady=(60,10))   
label2.pack(pady=10)        
button.pack(pady=10)        

# Starta huvudloopen
root.mainloop()

Exempel med side:
'side' anger vilken riktning en widget ska packas i förhållande till andra widgets.

  • side="top": Placerar widgeten överst (standardläge).
  • side="bottom": Placerar widgeten längst ner.
  • side="left": Placerar widgeten till vänster.
  • side="right": Placerar widgeten till höger.

Det bestämmer alltså ordningen och placeringen av widgeten i förhållande till de andra element som packas i samma container.

Exempel

python
import tkinter as tk

# Skapa ett fönster
root = tk.Tk()

# Skapa widgets

# Packa widgets
label1.pack(side="top", pady=(15, 0))      # Packas på toppen
label2.pack(side="left", padx=10 )         # Packas på vänster
button.pack(side ="bottom", pady=(0, 15))  # Packas till botten

# Starta huvudloope
root.mainloop()

Exempel med fill:
'fill' styr hur en widget ska fylla utrymmet i den riktning som anges.

  • fill="x": Widgeten fyller hela bredden horisontellt (över hela fönstret eller behållaren).
  • fill="y": Widgeten fyller hela höjden vertikalt.
  • fill="both": Widgeten fyller både bredden och höjden, alltså hela utrymmet.

Om fill inte specificeras, kommer widgeten endast att ta upp så mycket utrymme som behövs för sitt innehåll.

Exempel expand:
'expand' styr om en widget ska ta upp extra utrymme om det finns ledigt utrymme i containerfönstret.

  • expand=True: Widgeten får extra utrymme och växer för att fylla det lediga utrymmet i containerfönstret.
  • expand=False (standard): Widgeten växer inte och tar bara upp det utrymme som behövs för sitt innehåll.

Detta gör det möjligt att skapa flexibla layouter där vissa widgets kan växa för att fylla tomma utrymmen.

Exempel

python
import tkinter as tk

# Skapa ett fönster
root = tk.Tk()
root.title("Layouthanterare pack() demo med parametern 'expand'")
root.geometry("500x300")
root.configure(bg="#C5DBF7")

# Skapa widgets
label1 = tk.Label(root, text="Detta är label 1", bg="lightcoral")
label2 = tk.Label(root, text="Detta är label 2", bg="lightyellow")
button = tk.Button(root,text="Klicka här", bg="lightgreen", width=11, relief="raised", borderwidth=3)

# Packa widgets
label1.pack(fill="both", expand=True, padx=10, pady=6)  # 'expand' växer för att fylla utrymmet
label2.pack(fill="both", padx=10, pady=(3, 3) )  # Fyller bara sin storlek
button.pack(fill="both", expand=True, padx=10, pady=(3, 6))  # 'expand' växer för att fylla utrymmet

# Starta huvudloope
root.mainloop()

grid() ​

grid() är mer avancerad än pack() och används för att placera widgets i ett rutnät, med rader och kolumner. Den här layouthanteraren gör det enklare att skapa mer strukturerade och flexibla användargränssnitt.

Parametrar i grid() ​

  • row: radnummer (startar från 0). Rader numreras uppifrån och ner.
  • column: kolumnnummer (startar från 0). Kolumner numreras från vänster till höger.
  • padx, pady: lägger till utrymme/mellanrum (padding) i pixlar runt widgeten horisontellt och vertikalt.
  • sticky: förankrar widgeten i en viss riktning (t.ex. N, S, E, W för nord, syd, öst, väst).
  • rowspan, columnspan: hur många rader eller kolumner widgeten ska sträcka sig över.

Händelser (Events) ​

I Tkinter används händelser för att beskriva de interaktioner som användaren har med applikationen. En händelse kan vara ett användarklick, tangentbordsinmatning, musrörelse eller andra användarinteraktioner som påverkar gränssnittet. Händelser gör det möjligt att skapa interaktiva applikationer där användarens handlingar leder till specifika åtgärder.

Vad är en händelse i Tkinter? ​

En händelse i Tkinter är en handling som triggas av användaren eller systemet. Exempel på händelser är:

  • Klicka på en knapp
  • Tangentbordsinmatning
  • Musrörelse eller musknapptryck
  • Fönsterändringar eller stängningar

När en händelse inträffar, aktiveras en händelsehanterare (event handler) eller en callback-funktion. Detta gör att ett visst block av kod körs som svar på händelsen.

Vanliga händelser i Tkinter ​

Här är några vanliga händelser som kan inträffa i Tkinter:

  • <Button-1>: Vänster musklick
  • <Button-2>: Mitt musklick (muskulärt hjul eller 2:a musknappen)
  • <Button-3>: Höger musklick
  • <KeyPress>: Tryck på en tangent
  • <KeyRelease>: Släpp av en tangent
  • <Motion>: Musrörelse
  • <Enter>: När muspekaren går in i ett widget-område
  • <Leave>: När muspekaren lämnar ett widget-område
  • <Configure>: Ändring av storleken eller placeringen på ett fönster eller en widget
  • <Destroy>: När ett fönster stängs

Att binda en händelse till en widget ​

I Tkinter används metoden bind() för att koppla en händelse till en specifik widget. En bindning kräver en händelse och en funktion som ska köras när händelsen inträffar. Exempelvis:

Exempel 1: Händelsehantering för en knapp

python
import tkinter as tk
root = tk.Tk()
root.geometry("400x250")

count = 0
def on_button_click(event):    
    global count
    count += 1
    label.config(text=f"Knappen klickats:  {count}")

# Skapa en knapp och Bind händelsen
button = tk.Button(root, text="Klicka här")
button.pack(pady=50, padx=50)
button.bind("<Button-1>", on_button_click)    

label = tk.Label(root)
label.pack(pady=20)
root.mainloop()

Argument för händelsehanteraren ​

När en händelse inträffar skickas information om händelsen till händelsehanteraren. Denna information är ett event-objekt och innehåller information som:

  • event.x och event.y: Musens position vid händelsen
  • event.widget: Widgeten som händelsen inträffade på
  • event.keysym: Namnet på den tryckta tangenten

Exempel 2: Händelsehantering med musposition och den tryckta tangenten

python
import tkinter as tk
root = tk.Tk()
root.geometry("400x250")

def on_mouse_move(event):   
    label1.config(text = f"Musen är på position:  ({event.x}, {event.y})")  

def on_key_press(event):    
    key = event.keysym  # Hämta den tryckta tangentens keysym
    label1.config(text=f"Du tryckte på tangenten:  {key}")

# Skapa en etikett
label = tk.Label(root, text="Flytta musen här eller \nTryck på en tangent!")
label.pack(pady=30, padx=50)

# Bind händelsen för musrörelse
label.bind("<Motion>", on_mouse_move)   
# Bind tangenttryckning till händelsehanteraren
root.bind("<Key>", on_key_press)        

label1 = tk.Label(root)
label1.pack(pady=50, padx=50)
root.mainloop()

Binda flera händelser till samma funktion ​

Tkinter tillåter att man binder flera händelser till samma funktion. Detta kan vara användbart för att utföra samma åtgärd vid olika typer av användarinteraktioner.

Exempel 4: Flera händelser för en knapp

python
import tkinter as tk
root = tk.Tk()
root.geometry("400x250")

def on_mouse_event(event):      
    if event.type == '7':       # "<Enter>"
        label.config(text="Musen är på knappen!", fg="red")
    elif event.type == '8':     # "<Leave>"
        label.config(text="Musen har lämnat knappen.", fg="green")
    elif event.type == '4':     # "<Button-1>"
        label.config(text="Vänster musknapp klickades!", fg="blue")

# Skapa en etikett som visar statusen
label = tk.Label(root, text="Hovra eller klicka på knappen", font=("Arial", 14))
label.pack(pady=50)

button = tk.Button(root, text="Klicka här")
button.pack()

# Bind flera händelser till samma funktion
button.bind("<Enter>", on_mouse_event)     # Musen går in i knappen
button.bind("<Leave>", on_mouse_event)     # Musen lämnar knappen
button.bind("<Button-1>", on_mouse_event)  # Vänster musklick

root.mainloop()

Tkinter - Skapande av användarvänligt gränssnitt ​

När vi bygger program som användare ska köra är det viktigt att tänka på hur gränssnittet ser ut och fungerar. Ett användarvänligt gränssnitt gör det enklare för användare att förstå och använda programmet.

I detta avsnitt kommer vi att gå igenom hur man skapar ett användarvänligt Grafiskt Användargränssnitt (GUI = Graphical User Interface) med hjälp av Tkinter, ett bibliotek i Python.
Vi kommer att titta på grundläggande komponenter som fönster, etiketter, knappar, textrutor med flera, hur man placerar (layout) och interagera med dessa komponenter.


Vad är Tkinter? ​

Tkinter är ett av de enklaste och mest populära sätten att skapa grafiska användargränssnitt (GUI) i Python, skrivbordsapplikationer. Det är en inbyggd modul i Python, vilket betyder att du inte behöver installera något extra för att använda det.

Tkinter erbjuder en mängd olika widgetar (komponenter/element) som etiketter, knappar, textrutor och mer som kan användas för att skapa interaktiva användargränssnitt.

Interaktiva användargränssnitt bygger på händelsedriven programmering, vilket innebär att programmet reagerar på olika händelser (events) som användaren utför, till exempel att klicka på en knapp, skriva text i en textruta eller trycka på en tangent. I stället för att programmet körs sekventiellt rad för rad, väntar det på dessa händelser och utför specifika funktioner (så kallade callbacks) när en händelse inträffar.
En "callback" i Python är en funktion som skickas som argument till en annan funktion.

I Tkinter används en händelse-loop, root.mainloop(), som kontinuerligt lyssnar efter användarinteraktioner. När en händelse inträffar, t.ex. ett knappklick, anropas en fördefinierad funktion som hanterar händelsen, vilket gör gränssnittet interaktivt och dynamiskt.

De viktigaste komponenterna:

  • Root: Huvudfönster där allt skapas.
  • Widgets: Dessa är element som etiketter, knappar, textrutor, osv.
  • Geometrihanterare: Hur widgets placeras i fönstret, används det följande funktioner: pack(), grid(), place().
  • Händelser: Knappar och andra element (widgetar) kan få funktioner kopplade till sig för att reagera på användarens handlingar.

Komma igång med Tkinter ​

Skapa ditt första fönster ​

  • Först importera Tkinter modulen till programmet:

    python
    import tkinter as tk

    'tk' är ett alias som gör att du kan referera till modulen med det kortare namnet istället för att skriva 'tkinter' varje gång.

  • För det andra, skapa en instans av tk.Tk klassen som skapar programfönstret:

    python
    root = tk.Tk()

    Enligt konventionen kallas huvudfönstret i Tkinter root. Men du kan använda vilket annat namn som helst som main eller window.

  • För det tredje, anrop mainloop()-metoden för huvudfönsterobjektet:

    python
    root.mainloop()
    • Metoden root.mainloop() säkerställer att huvudfönstret förblir synligt på skärmen.
    • Om du inte anropar root.mainloop()-metoden kommer huvudfönstret att visas och försvinna nästan omedelbart.
    • Metoden är en oändlig loop som håller applikationen igång, väntar på att händelser inträffar (som knappklick) och bearbetar dessa händelser så länge fönstret inte är stängt.
    • Du placerar vanligtvis root.mainloop()-metoden sist i programmet.

    Följande program visar hur du skapar ditt första fönster i Tkinter:

    python
    import tkinter as tk 
root = tk.Tk()  
root.mainloop()

Låt oss lära oss hur man ändrar attributen (egenskaperna) för huvudfönstret.

  • title(): funktionen sätter titeln på huvudfönstret.

    • Exempel: root.title("Mitt första GUI")

  • geometry(): används för att definiera fönstrets storlek och position.

    • Exempel: root.geometry("500x300+100+100"). Detta ställer in fönstrets storlek till 500x300 pixlar och placerar det på positionen (100, 100) på skärmen.

  • configure(): kan användas för att ändra flera attribut på en gång, såsom fönstrets storlek, färger, och mer.

    • Exempel: root.configure(bg="#C5DBF7"), ändrar bakgrundsfärgen på huvudfönstret till ljusblå.
    • Färgen kan anges som hexadecimal eller text t.ex, 'red' eller '#FF0000', 'green' eller '#00FF00'.

  • resizable(): anger om fönstret kan ändra storlek eller inte.

    • Exempel: root.resizable(False, False), fönstret blir inte ändringsbart i storlek (varken horisontellt eller vertikalt).

  • iconbitmap(): sätter fönstrets ikon (det lilla bilden som visas i fönstrets övre vänstra hörn).

    • Exempel: root.iconbitmap("path_to_icon.ico"), anger en egen ikon för fönstret, här används en .ico-fil.
    • Ladda ner ikon-bilden 'favicon.ico' i mappen där du har din Python fil

    Exempel med flera ändringar på huvudfönstret

    python
    import tkinter as tk

# Skapar huvudfönster
root = tk.Tk()     
root.title("Mitt första GUI")    
root.geometry("500x300")         
root.configure(bg="#C5DBF7")     
root.resizable(False, False)     
root.iconbitmap("favicon.ico")   

root.mainloop()

Lägg till Widgets ​

I Tkinter är widgets de byggstenar du använder för att skapa ett grafiskt användargränssnitt (GUI). Tänk på widgets som olika delar eller verktyg som du lägger in i ditt fönster för att användaren ska kunna se och göra saker. Det kan vara allt från knappar och textrutor till menyer och rullgardiner.

Här nedan kommer vi att visa tre av det vanligaste widgetarna, dess parametrar (options), hur de används och exempel på dem ( Det finns flera widgetar på denna sida: 'Widgetar'):

Label (Etikett) ​

Används för att visa text eller bilder i ett fönster. Det är en av de enklaste och mest grundläggande widgets i Tkinter, och den används ofta för att visa rubriker, meddelanden, instruktioner eller annan statisk information.
Här nedan finns det flera parametrar för att ändra Etikettens egenskaper.

Vanliga parametrar för Label-widget:

  1. text: Texten som ska visas i etiketten. Det är den vanligaste parametern för att visa en enkel text.

  2. font: Bestämmer vilken font (stil och storlek) som ska användas för texten. Du kan ange fonten som en tuple med tre delar: stil, storlek och eventuell andra egenskaper.

  3. fg (foreground): Färgen på texten (textfärgen). Du kan använda färgnamn som "red", "blue", eller hexadecimal-koder som "#FF5733".

  4. bg (background): Bakgrundsfärgen på etiketten. På samma sätt som fg, kan du använda färgnamn eller hexadecimal-koder.

  5. width: Bestämmer bredden på etiketten i antal tecken. Om texten är kortare än bredden, fylls området med tomrum.

  6. height: Bestämmer höjden på etiketten i antal rader. Om texten är kortare än höjden, fylls området med tomrum.

  7. anchor: Bestämmer hur texten ska justeras inom etikettens område (t.ex. centrera (standard), vänster- eller högerjustera). T.ex. anchor="w" vänster, anchor="e" höger

  8. justify: Om texten består av flera rader, kan du använda justify för att bestämma hur texten ska justeras på varje rad (t.ex. vänster, höger, eller centrerad).

  9. image: Används för att visa en bild istället för text. Du måste skapa ett bildobjekt med hjälp av t.ex. PhotoImage eller PIL (Python Imaging Library).

    Label demo

    python
    import tkinter as tk

# Skapar huvudfönster
root = tk.Tk()
root.title("Label demo")
root.geometry("500x300")
root.config(bg="#C5DBF7")
root.iconbitmap("favicon.ico")

# Skapar en etikett med flera attribut och visar en text
tk.Label( root,                             
          text="Välkommen till Tkinter",    
          font=("Arial", 28, "bold"),       
          fg="#2A669A",                     
          bg="#C5DBF7"
        ).pack(pady=10)  # lägger/placerar etiketten i fönstre                                

# Skapar en etikett och visar en bild
image = tk.PhotoImage(file="bild.png")   # Laddar en bild med PhotoImage-klass
tk.Label( root, image=image, bg="#C5DBF7" ).pack(pady=10)   

root.mainloop()

Button (Knapp) ​

Används för att skapa knappar. En knapp kan användas för att låta användaren klicka på den och på så sätt utföra en viss funktion eller köra en specifik kod när den trycks.

Vanliga parametrar för Button-widget:

  1. text: Texten som visas på knappen
  2. command: En funktion som ska köras när knappen klickas på. Detta är mycket användbart för att göra knappen interaktiv.
  3. borderwidth: Bestämmer bredden på knappens kant. Används för att skapa en upphöjd eller nedtryckt effek
  4. relief: Bestämmer knappens stil (utseende). Vanliga värden är:
    • "flat": Platt knapp utan upphöjning.
    • "raised": Upphöjd knapp.
    • "sunken": Nedtryckt knapp.
  5. state: Bestämmer knappens tillstånd. Vanliga värden är:
    • "normal" (standard, knappen är klickbar)
    • "disabled" (knappen är inaktiv och kan inte klickas på)
  6. font: Bestämmer textens stil och storlek på knappen.
  7. fg (foreground): Färgen på knapp-texten.
  8. bg (background): Bakgrundsfärgen på knappen.
  9. width: Bestämmer bredden på knappen.
  10. height: Bestämmer höjden på knappen.
  11. image: Om du vill visa en bild på knappen istället för text, kan du använda denna parameter. Du behöver skapa en bild med PhotoImage eller PIL.

Button demo

python
import tkinter as tk

# Skapar huvudfönster
root = tk.Tk()
root.title("Button demo")
root.geometry("500x300")
root.configure(bg="purple")
root.iconbitmap("favicon.ico")

# command - funktion som ökar räknaren
count = 0
def increase_count():
    global count
    count += 1
    label.config(text=f"Räknare: {count}")

tk.Button( root,                        
           text="Öka antalet",          
           command=increase_count,      
           width=15,                    
           font=("Bookman Old Style", 13, "bold"),  
           bg="Violet",                 
           relief="raised",  
           borderwidth=5
         ).pack(pady=30)  

label = tk.Label(root, text="Räknare: 0", font=("Arial", 16), 
                 bg="purple", fg="white")
label.pack(pady=10)
root.mainloop()

Entry (Textruta) ​

Används för att skapa en textruta (textfält) där användaren kan skriva in information, t.ex. ett namn, lösenord eller ett tal. Den används när du vill ha en enkel, enradig inmatning från användaren.

Vanliga parametrar för Entry-widget:

  1. state: Bestämmer om textfältet är redigerbart eller ej. Vanliga värden är:
    • "normal": Textfältet är redigerbart.
    • "disabled": Textfältet är inaktivt och kan inte redigeras.
    • "readonly": Textfältet är synligt men kan inte ändras.
  2. justify: Bestämmer hur texten ska justeras i textfältet. Vanliga värden är:
    • left": Vänsterjusterad text (standard).
    • "center": Centrerad text.
    • "right": Högerjusterad text.
  3. font: Bestämmer vilken font som används för texten i textfältet. Anges som en tuple med fontnamn och storlek.
  4. fg (foreground): Sätter textfärgen (textens färg).
  5. bg (background): Sätter bakgrundsfärgen på textfältet.
  6. width: Bestämmer bredden på textfältet i antal tecken. Om texten är kortare än bredden, fylls området med tomrum.
  7. insert: Används för att sätta in en förvald text i textfältet när det skapas.
    python
    entry = tk.Entry(root)
entry.insert(0, "Förvald text")
  8. get(): metoden get() används för att hämta texten som användaren har skrivit in i ett Entry-fält. Detta returnerar texten som en sträng.
    python
    def get_data():
    text = entry.get()           # Hämtar texten från Entry-widgeten
    print("Inmatad text:", text)

entry = tk.Entry(root)
button = tk.Button(root, text="Hämta text", command=get_data)
  9. delete(): Används för att tömma textfältet. Denna metod tar två argument: start- och slutindex för det textområde som ska tas bort. För att tömma hela fältet kan du använda startindex 0 och slutindex tk.END (som refererar till slutet av texten).
    python
    def clean_entry():
    entry.delete(0, tk.END)  # Tömmer hela textfältet

entry = tk.Entry(root)
button = tk.Button(root, text="Töm fält", command=clean_entry)
  10. validate: Används för att specificera en valideringsfunktion som körs när texten i textfältet ändras. Det gör att du kan säkerställa att användaren skriver in korrekt information.
    python
    def validate_input(input_value):
    if input_value.isdigit():
        return True
    return False

entry = tk.Entry(root, validate="key", 
                 validatecommand=(root.register(validate_input), "%P"))
  11. show: Gör så att texten som skrivs in inte visas i klartext, utan istället visas som t.ex. asterisker (*). Detta används ofta för lösenordfält.
    python
    def show_password():
    password = entry.get()
    label.config(text=f"Lösenordet är: {password}")

entry = tk.Entry(root, show="*")   
entry.pack(pady=(30, 15))

# Skapa en knapp som visar det inmatade lösenordet i en etikett
tk.Button(root, text="Visa Lösenord", command=show_password).pack()

# Skapa en etikett för att visa lösenordet
label = tk.Label(root, text="Lösenordet kommer att visas här")
label.pack(pady=10)

Entry demo

python
import tkinter as tk
from tkinter import messagebox

root = tk.Tk()
root.title("Entry (Textruta) demo")
root.geometry("500x300")
root.configure(bg="#454545")
root.iconbitmap("favicon.ico")

def show_info():
    if entry1.get().strip() == "" or entry2.get().strip() == "":      
        messagebox.showerror("Ej ifylld registrering", "Ange namn och e-post, försök igen!")
    else:
        messagebox.showinfo("Registrering", f"Namn: {entry1.get()} \n\nE-post: {entry2.get()}")
    entry1.delete(0, 'end')      
    entry2.delete(0, 'end')      
    entry1.focus_set()           

# Skapa etiketter och textrutor
label1 = tk.Label(root, text="namn:", bg="#454545", fg="white")
label2 = tk.Label(root, text="E-post:", bg="#454545", fg="white")
entry1 = tk.Entry(root)                 
entry2 = tk.Entry(root, width=35)       
button = tk.Button(root, text="Registrera dig", command=show_info, width=15, bg="#656565", fg="white")

# Placera dem i grid med vänsterjustering
label1.grid(row=0, column=0, sticky="w", padx=(40, 0), pady=(50,5))
label2.grid(row=1, column=0, sticky="w", padx=(40, 0), pady=5)
entry1.grid(row=0, column=1, sticky="w", padx=10, pady=(50, 5))     
entry2.grid(row=1, column=1, sticky="w", padx=10, pady=5)           
button.grid(row=2, column=1, sticky="w", padx=10, pady=(15, 5))

root.mainloop()

Sammanfattning ​

Tkinter är ett enkelt men kraftfullt verktyg för att skapa grafiska gränssnitt i Python. Det ger dig möjlighet att bygga allt från enkla fönster med några få widgets till mer avancerade applikationer med interaktivitet och komplex layout.

I den här sidan har vi gått igenom:

  • Hur man skapar ett grundläggande fönster med Tkinter.
  • Hur man lägger till och använder några widgets.

Med dessa kunskaper har du en bra grund för att fortsätta utforska Tkinter och skapa dina egna GUI-applikationer.

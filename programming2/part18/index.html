Skapande av användarvänliga gränssnitt, Tkinter ​

När vi bygger program som användare ska köra är det viktigt att tänka på hur gränssnittet ser ut och fungerar. Ett användarvänligt gränssnitt gör det enklare för användare att förstå och använda programmet.

I detta avsnitt kommer vi att gå igenom hur man skapar ett användarvänligt grafiskt användargränssnitt (GUI) med hjälp av Tkinter, ett bibliotek i Python. Vi kommer att titta på grundläggande komponenter som fönster, knappar, etiketter, textrutor och hur man gör dessa komponenter (widgets) enkla att använda och förstå.

Några viktiga steg för ett användarvänligt gränssnitt ​

  • Designprinciper för användargränssnitt: Hur man skapar ett användarvänligt gränssnitt, till exempel genom att hålla det enkelt, tydligt och lätt att navigera.
  • Interaktivitet: Hur man lägger till funktionalitet som gör att användaren kan interagera med programmet, till exempel genom att klicka på knappar eller skriva text i fält.
  • Funktionalitet: Att programmet fungerar smidigt när användaren interagerar med det, utan fördröjning eller oväntade beteenden.
  • Tillgänglighet: Att säkerställa att programmet är användbart för så många som möjligt, till exempel genom att använda tydlig text och kontraster, samt erbjuda olika sätt att interagera med gränssnittet.

Vad är Tkinter? ​

Tkinter är ett av de enklaste och mest populära sätten att skapa grafiska användargränssnitt (GUI) i Python, skrivbordsapplikationer. Det är en inbyggd modul i Python, vilket betyder att du inte behöver installera något extra för att använda det.

Tkinter erbjuder en mängd olika widgets (komponenter/element) som knappar, etiketter, textrutor, menyer och mer som kan användas för att skapa interaktiva användargränssnitt.

Interaktiva användargränssnitt bygger på händelsedriven programmering, vilket innebär att programmet reagerar på olika händelser som användaren utför, till exempel att klicka på en knapp, skriva text i en textruta eller trycka på en tangent. I stället för att programmet körs sekventiellt rad för rad, väntar det på dessa händelser och utför specifika funktioner (så kallade callbacks) när en händelse inträffar.
I Tkinter används en händelse-loop,root.mainloop(), som kontinuerligt lyssnar efter användarinteraktioner. När en händelse inträffar, t.ex. ett knappklick, anropas en fördefinierad funktion som hanterar händelsen, vilket gör gränssnittet interaktivt och dynamiskt.

De viktigaste komponenterna:

  • Root: Huvudfönster där allt skapas.
  • Widgets: Dessa är element som knappar, textfält, etiketter osv.
  • Layout: Hur widgets placeras i fönstret, används det följande funktioner: pack(), grid(), place().
  • Händelser: Knappar och andra element kan få funktioner kopplade till sig för att reagera på användarens handlingar.

Komma igång med Tkinter ​

Skapa ditt första fönster ​

Först och främst måste man importera Tkinter modulen:

  • import tkinter as tk

Och det finns två huvudsakliga metoder som du behöver komma ihåg när du skapar Python-applikationen med GUI:

  • root = tk.Tk(): för att skapa en instans av tk.Tk klassen som skapar programfönstret.
  • root.mainloop(): metoden används för att köra applikationen när den är klar. Det är en oändlig loop som håller applikationen igång, väntar på att händelser inträffar (som knappklick) och bearbetar dessa händelser så länge fönstret inte är stängt.

Följande program visar hur man skapar det enklaste huvudfönstret i Tkinter:

python
import tkinter as tk 
root = tk.Tk()        
root.mainloop()

Om man kör programmet får man följande fönster:


Ja, Det finns flera attribut och metoder som gör det möjligt att styra huvudfönstrets egenskaper. Här är några av de vanligaste attributen och metoderna för att ändra huvudfönstret i Tkinter:

  • title(): sätter titeln på huvudfönstret.
    • Exempel: root.title("Mitt första GUI")
  • geometry(): används för att definiera fönstrets storlek och position.
    • Exempel: root.geometry("500x300+100+100"). Detta ställer in fönstrets storlek till 500x300 pixlar och placerar det på positionen (100, 100) på skärmen.
  • configure(): kan användas för att ändra flera attribut på en gång, såsom fönstrets storlek, färger, och mer.
    • Exempel: root.configure(bg="#C5DBF7"), ärndrar bakgrundsfärgen på huvudfönstret till ljusblå.
    • Färgen kan anges som hexadecimal eller text t.ex, 'red' eller '#FF0000', 'green' eller '#00FF00'.
  • resizable(): anger om fönstret kan ändra storlek eller inte.
    • Exempel: root.resizable(False, False), fönstret blir inte ändringsbart i storlek (varken horisontellt eller vertikalt).
  • iconbitmap(): sätter fönstrets ikon (det lilla bilden som visas i fönstrets övre vänstra hörn).
    • Exempel: root.iconbitmap("path_to_icon.ico"), anger en egen ikon för fönstret, här används en .ico-fil.

import tkinter as tk

root.geometry("500x300")         
root.configure(bg="#C5DBF7")     
root.resizable(False, False)

Lägg till Widgets ​

I Tkinter är widgets de byggstenar du använder för att skapa ett grafiskt användargränssnitt (GUI). Tänk på widgets som olika delar eller verktyg som du lägger in i ditt fönster för att användaren ska kunna se och göra saker. Det kan vara allt från knappar och textrutor till menyer och rullgardiner.

Här är några av de vanligaste widgets och vad de används till:

Label (Etikett) ​

Används för att visa text eller bilder i ett fönster. Det är en av de enklaste och mest grundläggande widgets i Tkinter, och den används ofta för att visa rubriker, meddelanden, instruktioner eller annan statisk information.
Man kan ändra textens färg, storlek, typsnitt och bakgrundsfärg.

Label demo

python
import tkinter as tk
root = tk.Tk()
root.title("Label demo")
root.geometry("500x300")
root.config(bg="#C5DBF7")
root.iconbitmap("favicon.ico")

# Skapar en Label och visar en text
tk.Label( root,                             
          text="Välkommen till Tkinter",    
          font=("Arial", 28, "bold"),       
          fg="#2A669A",                     
          bg="#C5DBF7"
        ).pack(pady=10)                     

# Skapar en Label och visar en bild
image = tk.PhotoImage(file="bild.png")   # Laddar en bild med PhotoImage-klass
tk.Label( root, image=image, bg="#C5DBF7" ).pack(pady=10)   

root.mainloop()

import tkinter as tk

Entry (Textruta) ​

Används för att skapa ett textruta där användaren kan skriva in information, t.ex. ett namn, lösenord eller ett tal. Den används när du vill ha en enkel, enradig inmatning från användaren.

  • Hämta data: Du kan läsa av vad användaren har skrivit genom att använda get()-metoden.
  • Ange data: Du kan sätta en standardtext i textfältet med insert()-metoden.
  • Tömma fältet: Du kan rensa innehållet i textfältet med delete()-metoden.

Entry demo

python
import tkinter as tk
from tkinter import messagebox    

root = tk.Tk()
root.title("Entry (Textruta) demo")
root.geometry("500x300")
root.configure(bg="#454545")
root.iconbitmap("favicon.ico")

# Skapa etiketter och textrutor
label1 = tk.Label(root, text="Förnamn:", bg="#454545", fg="white")
entry1 = tk.Entry(root)         

label2 = tk.Label(root, text="Efternamn:", bg="#454545", fg="white")
entry2 = tk.Entry(root)         

label3 = tk.Label(root, text="E-post:", bg="#454545", fg="white")
entry3 = tk.Entry(root, width=35)   

def show_message():
    if entry1.get().strip() == "" or entry2.get().strip() == "" or entry3.get().strip() == "":     
        messagebox.showerror("Ej Fullständigt", "Du har inte angett förnamn, efterman eller e-post!")
    else:
        messagebox.showinfo("Genomförd Registrering", f"Namn: {entry1.get()} {entry2.get()}\nE-post: {entry3.get()}")  
        if messagebox.OK:
            entry1.delete(0, 'end')   
            entry2.delete(0, 'end')   
            entry3.delete(0, 'end')   
            entry1.focus_set()        

button = tk.Button(root, text="Registrera dig", command=show_message, width=15, bg="#656565", fg="white")

# Placera dem i grid med vänsterjustering
label1.grid(row=0, column=0, sticky="w", padx=(40, 0), pady=(30,5))
entry1.grid(row=0, column=1, sticky="w", padx=10, pady=(30, 5))

label2.grid(row=1, column=0, sticky="w", padx=(40, 0), pady=5)
entry2.grid(row=1, column=1, sticky="w", padx=10, pady=5)

label3.grid(row=2, column=0, sticky="w", padx=(40, 0), pady=5)
entry3.grid(row=2, column=1, sticky="w", padx=10, pady=5)

button.grid(row=3, column=1, sticky="w", padx=10, pady=(15, 5))

root.mainloop()

Text (Textruta för flera rader) ​

Används för att skapa ett textfält där användaren kan skriva in eller visa längre texter. Till skillnad från Entry, som bara klarar en rad text, kan Text hantera flera rader och stora mängder text. Det gör den perfekt för anteckningar, dokument, eller längre texter.

  • Man kan ändra textens färg, teckensnitt och bakgrundsfärg.
  • Man kan lägga till en rullningslist (scrollbar) för att bläddra i texten om den är för lång för att visas i fönstret
  • Man kan enkelt lägga till, hämta, eller ta bort text med hjälp av metoder.

Text Demo

python
import tkinter as tk
from tkinter import messagebox

root = tk.Tk()
root.title("Text demo")
root.geometry("500x300")
root.config(bg="RoyalBlue")
root.iconbitmap("favicon.ico")

# Skapa en Text-widget
text_widget = tk.Text(root, font=("Arial", 14), height=8, width=32, bg="lightyellow") 
text_widget.pack(pady=(35, 15)) 

# Funktion för att hämta text
def show_text():
    text_content = text_widget.get("1.0", "end").strip()  # Hämtar text från rad 1, kolumn 0 till slutet
    if text_content != "": 
        messagebox.showinfo("Information", f"{text_content}")
        if messagebox.OK:
            text_widget.delete("1.0", "end") 

# Knapp för att visa text
button = tk.Button(root, text="Visa text", command=show_text, font=("Ariel", 12), width=15, bg="LightCyan")  
button.pack()  

root.mainloop()

Checkbutton (avkryssningsruta) ​

Används för att skapa en avkryssningsruta (checkbox) och den illåter användaren att välja eller avmarkera ett alternativ, vilket representeras av ett av två tillstånd:

  • markerad (checked=1) eller
  • omarkerad (unchecked=0).

Den används ofta för att tillåta användaren att välja mellan flera olika alternativ.

Checkbutton demo

python
import tkinter as tk
root = tk.Tk()
root.title("Checkbutton demo (avkryssningsruta)")
root.geometry("500x300")
root.configure(bg="gold")
root.iconbitmap("favicon.ico")

tk.Text(root, height=6, width=40).grid(row=0, padx=40, pady=(40, 5), sticky="w")

## Skapa metod för checkbutton markering
def check_action():                                                 
    if var.get() == 1:                                              
        label.config(text="(Checkbutton är markerad)", fg="green")  
    else:                                                           
        label.config(text="(Checkbutton är avmarkerad)", fg="red")  

# Definiera en variabel för att hålla koll på tillståndet
# och skapa en Checkbutton
var = tk.IntVar()           
checkbutton = tk.Checkbutton(root, text="Acceptera villkoren", variable=var, command=check_action, bg="gold") 
checkbutton.grid(row=1, padx=40, pady=(20, 0), sticky="w") 

label = tk.Label(root, text="Checkbutton är avmarkerad", bg="gold", fg="red")
label.grid(row=2, padx=60, pady=(1, 5), sticky="w")

root.mainloop()

Radiobutton (Radioknapp) ​

Används för att skapa en uppsättning val där endast ett alternativ kan väljas åt gången. Radioknappar är ofta grupperade tillsammans, och alla knappar i samma grupp är kopplade till samma variabel.

När användaren klickar på en radioknapp, uppdateras värdet på den variabel som knapparna är kopplade till.
Radioknappar används ofta när ett användarval måste göras från en lista av alternativ där bara ett val är möjligt.

Radiobutton demo

python
import tkinter as tk
root = tk.Tk()
root.title("Radiobutton demo (Radioknapp)")
root.geometry("500x300")
root.configure(bg="orange")

# Skapa metod för vald checkbutton
def radiobutton_action():
    label.config(text=f"Valt alternativ: {var.get()}", fg="DodgerBlue")

# Definiera en variabel för att hålla koll på radiobutton
# och skapa radiobuttons.
var = tk.IntVar()
tk.Radiobutton(root, text='Man',    variable=var, value="1", command=radiobutton_action, bg="orange", font=("Arial", 12)).grid(row=0, padx=40, pady=(30, 5), sticky="w")
tk.Radiobutton(root, text='Kvinna', variable=var, value="2", command=radiobutton_action, bg="orange", font=("Arial", 12)).grid(row=1, padx=40, pady=(5, 5), sticky="w")
tk.Radiobutton(root, text='Annat',  variable=var, value="3", command=radiobutton_action, bg="orange", font=("Arial", 12)).grid(row=2, padx=40, pady=(5, 5), sticky="w")

label = tk.Label(root, text=None, bg="orange", font=("Arial", 12))
label.grid(row=3, padx=60, pady=(5, 5), sticky="w")

root.mainloop()

Combobox (Rullgardinsmeny – från ttk) ​

Används för att skapa en rullgardinsmeny (dropdown) där användaren kan välja ett alternativ från en lista. Comboboxen gör det möjligt för användaren att välja ett alternativ från fördefinierade alternativ, men användaren kan också skriva in ett eget alternativ om så önskas.

Den kombinerar funktionaliteten hos både en Listbox och ett Entry-fält.

En händelsehanterare on_select-funktion är bunden till Comboboxen med bindningsmetoden bind(), som uppdaterar en etikett med det valda objektet när ett objekt väljs.

Combobox demo

python
import tkinter as tk
from tkinter import ttk     # Importera ttk-modulen för Combobox

root = tk.Tk()
root.title("Combobox demo (Rullgardinsmeny)")
root.geometry("500x300")
root.configure(bg="grey")

def on_select(event):
    selected_item = combo_box.get()
    label.config(text="Valt objekt: " + selected_item)

# Skapa en Combobox widget
combo_box = ttk.Combobox(root, values=["Alternativ 1", "Alternativ 2", "Alternativ 3"])     
combo_box.pack(pady=40)                                                                     
combo_box.set("Alternativ 1")   # Ställ in standardvärde
combo_box.bind("<<ComboboxSelected>>", on_select) # Bind händelse till on_select

# Skapa en label
label = tk.Label(root, text="Valt objekt: ", font=9, bg="grey")
label.pack(pady=20)

root.mainloop()

Listbox (Lista) ​

Används för att skapa en lista med alternativ där användaren kan välja ett eller flera objekt.

Den kan vara mycket användbar för att presentera en uppsättning alternativ eller för att tillåta användaren att välja flera objekt.

Listbox demo

python
import tkinter as tk
root = tk.Tk()
root.title("Listbox demo")
root.geometry("500x300")
root.config(bg="peru")
root.iconbitmap("favicon.ico")

# Funktion som körs när ett objekt väljs i Listboxen
def on_select(event):
    selected_item = listbox.get(listbox.curselection())  # Hämta det valda objektet
    label.config(text= f"Valt alternativ: {selected_item}")  # Uppdatera etiketten

# Skapa en Listbox
listbox = tk.Listbox(root, height=12, width=30, selectmode=tk.SINGLE)  # Tillåter ett val i taget
listbox.pack(pady=(30, 10)) 
# Binda händelsen <<ListboxSelect>> till funktionen on_select
listbox.bind("<<ListboxSelect>>", on_select)     

# Lägg till objekt i Listbox
for x in range(1, 13):
    listbox.insert(tk.END, f"   Alternativ  {x}")

# Skapa en etikett för att visa det valda objektet
label = tk.Label(root, text=None, font=("Arial", 11), bg="Peru")
label.pack(pady=15)

root.mainloop()

Frame (Ram) ​

Frame-widgeten är en behållare (container) som används för att gruppera andra widgets (som knappar, etiketter, textfält osv.) i ett visuellt block. Det är särskilt användbart för att strukturera layouten i en applikation och organisera olika delar av användargränssnittet.

I denna demo nedan delas huvudfönstret i tre sektioner: topp, mitten och botten. Varje sektion innehåller widgets för att demonstrera hur frames fungerar.

Frame demo -flera frames i huvudfönstret

python
import tkinter as tk
import random
root = tk.Tk()
root.title("Frame demo (flera frames i huvudfänstret)")
root.geometry("500x300")
root.config(bg="#565656")
root.iconbitmap("favicon.ico")

# Skapa topp-frame (tar 20% av höjden)
top_frame = tk.Frame(root, bg="lightblue", borderwidth=2, relief="ridge")   
top_frame.place(relx=0, rely=0, relwidth=1, relheight=0.2)                  

# Skapa mitten-frame (tar 60% av höjden)
middle_frame = tk.Frame(root, bg="lightgreen", borderwidth=2, relief="ridge")

# Funktion för att flytta objektet baserat på pil-tangenterna
def move_object(event):
    # Hämta cirkelns nuvarande koordinater
    bbox = canvas.bbox(circle)  # bbox ger oss koordinaterna för objektets bounding box
    left, top, right, bottom = bbox  # Extrahera koordinaterna för vänster, topp, höger och botten

    # Kontrollera om cirkeln är vid kanten och förhindra att den går utanför
    if event.keysym == "Left" and left > 0:        # Pil vänster
        canvas.move(circle, -5, 0)
    elif event.keysym == "Right" and right < 450:  # Pil höger (Canvas bredd = 450)
        canvas.move(circle, 5, 0)
    elif event.keysym == "Up" and top > 0:         # Pil upp
        canvas.move(circle, 0, -5)
    elif event.keysym == "Down" and bottom < 400:  # Pil ner (Canvas höjd = 400)
        canvas.move(circle, 0, 5)

canvas.pack(pady=15, padx=15)

circle = canvas.create_oval(175, 130, 275, 230, fill="red")     
canvas.create_text(220, 30, text="Välkommen till Canvas!", font=("Arial", 16, "bold"))  
canvas.create_text(220, 50, text="Flytta cirkeln med pil-tangenterna", font=("Arial", 11))  

# Binda pil-tangenterna till funktionen som flyttar objektet
root.bind("<Left>",  move_object)   # Pil vänster

Layout i Tkinter (pack(), grid(), place()) ​

För att placera och arrangera olika element (widgets) i ett fönster eller en ram använder vi layouthanterare. De tre vanligaste layouthanterarna i Tkinter är:

  • pack(): Placerar widgets i ordning (uppifrån och ned).
  • grid(): Använder ett rutnät för att placera widgets.
  • place(): Tillåter dig att exakt positionera widgets med koordinater.

Här förklarar vi hur de fungerar och när man bör använda dem.

1. pack() ​

pack() är den mest grundläggande layouthanteraren. Den används för att placera widgets vertikalt eller horisontellt inom en container (t.ex. ett fönster eller en ram). Widgets placeras automatiskt baserat på ordningen de läggs till i koden.

Parametrar i pack() ​

  • padx, pady: Lägger till utrymme (padding) runt widgeten horisontellt (x) och vertikalt (y).
  • side: Bestämmer vilken sida av fönstret widgeten ska placeras (t.ex. top, bottom, left, right). Standard är top.
  • fill: Fyller widgeten horisontellt (X), vertikalt (Y), eller båda (BOTH).
  • expand: Om True, får widgeten mer utrymme om fönstret ändrar storlek.

Exempel med padx, pady:

  • pady och padx är parametrar i Tkinter som används för att ge extra utrymme runt en widget, både horisontellt och vertikalt.
  • padx: Lägger till ett extra horisontellt utrymme (mellan widgeten och andra objekt på vänster och höger sida).
  • pady: Lägger till ett extra vertikalt utrymme (mellan widgeten och andra objekt ovanför och under).

De används ofta i layouthanterare som pack(), grid(), eller place() för att skapa luftiga och lättlästa gränssnitt.

Exempel

Exempel med side:
'side' är en parameter i Tkinter's pack() layouthanterare som anger vilken riktning en widget ska packas i förhållande till andra widgets.

  • side="top": Placerar widgeten överst (standardläge).
  • side="bottom": Placerar widgeten längst ner.
  • side="left": Placerar widgeten till vänster.
  • side="right": Placerar widgeten till höger.

Det bestämmer alltså ordningen och placeringen av widgeten i förhållande till de andra element som packas i samma container.

Exempel

python
import tkinter as tk

# Skapa ett fönster
root = tk.Tk()
root.title("Layouthanterare pack() demo med parametern 'side'")
root.geometry("500x300")
root.configure(bg="#C5DBF7")

# Skapa widgets
label1 = tk.Label(root, text="Detta är label 1", bg="lightcoral")
label2 = tk.Label(root, text="Detta är label 2", bg="lightyellow")
button = tk.Button(root,text="Klicka här", bg="lightgreen", width=11, relief="raised", borderwidth=3)

# Packa widgets
label1.pack(side="top", pady=(15, 0))      # Packas på toppen
label2.pack(side="left", padx=10 )         # Packas på vänster
button.pack(side ="bottom", pady=(0, 15))  # Packas till botten

# Starta huvudloope
root.mainloop()

Exempel med fill:
'fill' är en parameter i Tkinter's pack() layouthanterare som styr hur en widget ska fylla utrymmet i den riktning som anges.

  • fill="x": Widgeten fyller hela bredden horisontellt (över hela fönstret eller behållaren).
  • fill="y": Widgeten fyller hela höjden vertikalt.
  • fill="both": Widgeten fyller både bredden och höjden, alltså hela utrymmet.

Om fill inte specificeras, kommer widgeten endast att ta upp så mycket utrymme som behövs för sitt innehåll.

Exempel

python
import tkinter as tk

# Skapa ett fönster
root = tk.Tk()
root.title("pack() demo med parametern 'fill'")
root.geometry("500x300")
root.configure(bg="#C5DBF7")

# Skapa widgets
label1 = tk.Label(root, text="Detta är en etikett")
label2 = tk.Label(root, text="En annan etikett")
button = tk.Button(root, text="Klicka här", bg="lightgreen",  relief="raised", borderwidth=5)

# Packa widgets
label1.pack(pady=(20, 10))
label2.pack(pady=(10, 20))
button.pack(fill="x", padx=10)  # Fyll hela bredden

# Starta huvudloopen
root.mainloop()

Exempel expand:
'expand' är en parameter i Tkinter's pack() layouthanterare som styr om en widget ska ta upp extra utrymme om det finns ledigt utrymme i containerfönstret.

  • xpand=True: Widgeten får extra utrymme och växer för att fylla det lediga utrymmet i containerfönstret.
  • expand=False (standard): Widgeten växer inte och tar bara upp det utrymme som behövs för sitt innehåll.

Detta gör det möjligt att skapa flexibla layouter där vissa widgets kan växa för att fylla tomma utrymmen.

Exempel

python
import tkinter as tk

# Skapa ett fönster
root = tk.Tk()
root.title("Layouthanterare pack() demo med parametern 'expand'")
root.geometry("500x300")
root.configure(bg="#C5DBF7")

# Skapa widgets
label1 = tk.Label(root, text="Detta är label 1", bg="lightcoral")
label2 = tk.Label(root, text="Detta är label 2", bg="lightyellow")
button = tk.Button(root,text="Klicka här", bg="lightgreen", width=11, relief="raised", borderwidth=3)

# Packa widgets
label1.pack(fill="both", expand=True, padx=10, pady=6)  # 'expand' växer för att fylla utrymmet
label2.pack(fill="both", padx=10, pady=(3, 3) )  # Fyller bara sin storlek
button.pack(fill="both", expand=True, padx=10, pady=(3, 6))  # 'expand' växer för att fylla utrymmet

# Starta huvudloope
root.mainloop()

2. grid() ​

grid() är mer avancerad än pack() och används för att placera widgets i ett rutnät, med rader och kolumner. Den här layouthanteraren gör det enklare att skapa mer strukturerade och flexibla användargränssnitt.

Parametrar i grid() ​

  • row: Radnummer (startar från 0).
  • column: Kolumnnummer (startar från 0).
  • padx, pady: Lägger till utrymme runt widgeten horisontellt och vertikalt.
  • sticky: Förankrar widgeten i en viss riktning (t.ex. N, S, E, W för nord, syd, öst, väst).
  • rowspan, columnspan: Hur många rader eller kolumner widgeten ska sträcka sig över.


Exempel med row, column, padx och pady

  • row: Anger vilken rad (från 0) widgeten ska placeras i. Rader numreras uppifrån och ner.
  • column: Anger vilken kolumn (från 0) widgeten ska placeras i. Kolumner numreras från vänster till höger.
  • padx: Lägger till horisontellt mellanrum (padding) runt widgeten, både till vänster och höger, i pixlar.
  • pady: Lägger till vertikalt mellanrum (padding) runt widgeten, både ovanför och under, i pixlar.

Exempel

python
import tkinter as tk

root = tk.Tk()
root.title("Layouthanterare grid() demo")
root.geometry("500x300")
root.configure(bg="#C5DBF7")

# Skapa etiketter och textrutor
label1 = tk.Label(root, text="namn:", bg="#C5DBF7")
label2 = tk.Label(root, text="E-postadress:", bg="#C5DBF7")
entry1 = tk.Entry(root)
entry2 = tk.Entry(root, width=25)
button = tk.Button(root, text="Register", width=15, bg="lightgreen", relief="raised", borderwidth=2)

# Placera dem i grid med vänsterjustering
label1.grid(row=0, column=0, padx=(40,10), pady=(35, 5))    
label2.grid(row=1, column=0, padx=(40,10), pady=5)          
entry1.grid(row=0, column=1, padx=10, pady=(35, 5))         
entry2.grid(row=1, column=1, padx=10, pady=5)               
button.grid(row=3, column=1, padx=(0,5), pady=5)            

root.mainloop()

Exempel med sticky, rowspan, och columnspan

  1. sticky: Bestämmer hur widgeten ska sträckas eller förankras inom sin cell.
    • Värden: Kombinera riktningar som N (nord), S (syd), E (öst), W (väst).
    • Exempel: sticky="nsew" gör att widgeten fyller hela cellen; sticky="w" förankrar widgeten till vänster.
  2. rowspan: Anger hur många rader widgeten ska sträcka sig över.
    • Exempel: Om rowspan=2, täcker widgeten två rader nedåt från sin startposition.
  3. columnspan: Anger hur många kolumner widgeten ska sträcka sig över.
    • Exempel: Om columnspan=3, täcker widgeten tre kolumner åt höger från sin startposition.

Exempel

python
import tkinter as tk

root = tk.Tk()
root.title("Layouthanterare grid() demo")
root.geometry("500x300")
root.configure(bg="#C5DBF7")

# Skapa etiketter och textrutor
label1 = tk.Label(root, text="namn:", bg="#C5DBF7")
label2 = tk.Label(root, text="E-postadress:", bg="#C5DBF7")
entry1 = tk.Entry(root)
entry2 = tk.Entry(root, width=25)
button = tk.Button(root, text="Register", width=15, bg="lightgreen", relief="raised", borderwidth=2)

# Placera dem i grid med vänsterjustering
label1.grid(row=0, column=0, sticky="e", padx=(40,10), pady=(35,5))
label2.grid(row=1, column=0, sticky="w", padx=(40,10), pady=5)
entry1.grid(row=0, column=1, sticky="w", padx=10, pady=(35, 5))
entry2.grid(row=1, column=1, sticky="w", padx=10, pady=10)
button.grid(row=3, column=0, columnspan=2, sticky="nsew",padx=(40,10), pady=5)

root.mainloop()

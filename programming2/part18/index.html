Skapande av användarvänliga gränssnitt, Tkinter ​

När vi bygger program som användare ska använda är det viktigt att tänka på hur gränssnittet ser ut och fungerar. Ett användarvänligt gränssnitt gör det enklare för användare att förstå och använda programmet.

I detta avsnitt kommer vi att gå igenom hur man skapar ett användarvänligt grafiskt användargränssnitt (GUI) med hjälp av Tkinter, ett bibliotek i Python. Vi kommer att titta på grundläggande element som fönster, knappar, etiketter, textrutor och hur man gör dessa komponent (widgets) enkla att använda och förstå.

Några viktiga delar i design-användargränssnitt ​

  • Designprinciper för användargränssnitt: Hur man skapar ett användarvänligt gränssnitt, till exempel genom att hålla det enkelt, tydligt och lätt att navigera.
  • Interaktivitet: Hur man lägger till funktionalitet som gör att användaren kan interagera med programmet, till exempel genom att klicka på knappar eller skriva text i fält.
  • Funktionalitet: Att programmet fungerar smidigt när användaren interagerar med det, utan fördröjning eller oväntade beteenden.
  • Tillgänglighet: Att säkerställa att programmet är användbart för så många som möjligt, till exempel genom att använda tydlig text och kontraster, samt erbjuda olika sätt att interagera med gränssnittet.

Vad är Tkinter? ​

Tkinter är en inbyggd modul i Python som används för att skapa grafiska användargränssnitt (GUI). Det är ett gränssnitt till verktyget Tcl/Tk, som är ett ramverk för att bygga applikationer med fönster och interaktiva komponent. Tkinter är enkelt att använda och passar perfekt för nybörjare som vill lära sig grunderna i GUI-programmering.

Några vanliga komponenter i Tkinter inkluderar:

  • Fönster (Window): Själva ramen där ditt program visas.
  • Widgets: Byggstenar som knappar, etiketter, textrutor, osv.
  • Händelser (Events): Saker som händer i programmet, t.ex. när en knapp klickas.

Komma igång med Tkinter ​

För att börja använda Tkinter behöver du importera modulen. Detta gör du genom att skriva:

python
import tkinter as tk

Detta är allt som behövs för att komma igång! Låt oss nu skapa ett enkelt fönster.

Exempel: Ett mall för Tkinter-fönster ​

Exempel

python
import tkinter as tk

root = tk.Tk()                # Skapa huvudfönster
root.title("Tkinter Mall")    # Ge fönstret en titel
root.geometry("800x600")      # Ställ in fönsterstorlek (bredd x höjd) 
root.configure(bg="lightblue")  #  Ändra bakgrundsfärgen på fönstret till ljusblå

label = tk.Label(     # Skapa en etikett (Label) med text
    root,               
    text="Välkommen till Tkinter!",  
    font=("Arial", 24),  
    fg="white",          
    bg="lightblue"      
)
label.pack(pady=20)  # Sätt etikett med 20 pixlars marginal uppifrån och ned

root.mainloop()   # Starta applikationen

Kod-förklaring rad för rad: ​

  1. import tkinter as tk
    • Importerar Tkinter-biblioteket och förkortar det som tk. Detta låter dig använda Tkinter-funktioner med prefixet tk.
  2. root = tk.Tk()
    • Skapar huvudfönstret för applikationen. root är variabeln som representerar detta fönster.
  3. root.title("Tkinter Mall med Färger")
    • Sätter en titel på fönstret, som visas i dess översta kant (titelfältet).
  4. root.geometry("800x600")
    • Ställer in fönstrets storlek till 800 pixlar i bredd och 600 pixlar i höjd. Formatet är "widthxheight".
  5. root.configure(bg="lightblue")
    • Ändrar bakgrundsfärgen på fönstret till ljusblå. Här använder vi färgens namn (lightblue), men du kan även använda hexadecimala färgkoder som #87CEEB.
  6. label = tk.Label(...)
    • Skapar en etikett (Label) som innehåller texten "Välkommen till Tkinter!". Parametrarna som används är:
      • root: Anger att etiketten ska placeras i fönstret root.
      • text="Välkommen till Tkinter!": Texten som visas i etiketten.
      • font=("Arial", 24): Fonten är Arial med storlek 24.
      • fg="white": Textfärgen (foreground) är vit.
      • bg="lightblue": Bakgrundsfärgen på etiketten är ljusblå, samma som fönstret.
  7. label.pack(pady=20)
    • Placerar etiketten i fönstret och lägger till 20 pixlars marginal ovanför och nedanför etiketten.
  8. root.mainloop()
    • Startar en händelseloop som håller fönstret öppet och lyssnar på användarens interaktioner (t.ex. klicka på knappar eller stänga fönstret). Programmet avslutas när fönstret stängs.

Lägga till Widgets ​

Widgets är de byggstenar som du använder för att skapa innehåll i ditt fönster. Några av de vanligaste widgets är:

  • Label (Etikett): Visar text eller bilder.
  • Button (Knapp): Används för att trigga händelser.
  • Entry (Textfält): Används för att skriva in text.

Låt oss titta på hur vi kan lägga till widgets i vårt mall.

Exempel

python
import tkinter as tk  

# Funktion för att visa text från Entry
def on_button_click():
    text = entry.get()  # Hämta text från Entry
    label_output.config(text=f"Du skrev: {text}")  # Uppdatera etiketten

root = tk.Tk()
root.title("Tkinter Mall med Färger")
root.geometry("800x600") 
root.configure(bg="lightblue")  

# Skapa en etikett (Label) med text
label = tk.Label(
    root,                
    text="Välkommen till Tkinter!",  
    font=("Arial", 24), 
    fg="white",         
    bg="lightblue"       
)
label.pack(pady=20) 

# Skapa en Label (etikett)
label_1 = tk.Label(
   root, 
   text="Skriv något nedan:", 
   font=("Arial", 12)
)
label_1.pack(pady=10)  

# Skapa en Entry (textruta)
entry = tk.Entry(
   root, 
   width=30, 
   font=("Arial", 12)
)
entry.pack(pady=10)

# Skapa en Button (knapp)
button = tk.Button(
   root, 
   text="Visa text", 
   command=on_button_click, 
   font=("Arial", 12)
)
button.pack(pady=10)

# Skapa en Label för att visa resultatet
label_output = tk.Label(root, text="", font=("Arial", 12), fg="blue")
label_output.pack(pady=10)

root.mainloop()

Förklaring av koden: ​

  1. Label (etikett):
    • label_1 = tk.Label(root, text="Skriv något nedan:", font=("Arial", 12)):
      Skapar en etikett med text som förklarar vad användaren ska göra.
    • label_1.pack(pady=10):
      Packar etiketten i fönstret och lägger till lite vertikalt mellanrum med pady.
  2. Entry (textfält):
    • entry = tk.Entry(root, width=30, font=("Arial", 12)):
      Skapar ett textfält där användaren kan skriva något. Bredden på textfältet anges med width.
    • entry.get(): Hämtar texten som användaren har skrivit in.
  3. Button (knapp):
    • button = tk.Button(root, text="Visa text", command=on_button_click, font=("Arial", 12)):
      Skapar en knapp. När knappen klickas körs funktionen on_button_click.
    • command=on_button_click: Binder funktionen on_button_click till knappen.
  4. Label för resultat:
    • label_output = tk.Label(root, text="", font=("Arial", 12), fg="blue"):
      Skapar en etikett som visar resultatet (det användaren skrev i textfältet). Den börjar som tom (text="").
  5. Funktionen on_button_click:
    • entry.get(): Hämtar användarens inmatning från textfältet.
    • label_output.config(text=f"Du skrev: {text}"):
      Uppdaterar texten i resultatetiketten för att visa vad användaren skrev.
  6. Huvudloop:
    • root.mainloop(): Startar Tkinter-applikationens huvudloop, som håller fönstret öppet och reagerar på händelser.

Layout i Tkinter ​

För att placera widgets i fönstret på ett mer kontrollerat sätt kan du använda olika layout-metoder:

  • pack(): Placerar widgets i ordning (uppifrån och ned).
  • grid(): Använder ett rutnät för att placera widgets.
  • place(): Tillåter dig att exakt positionera widgets med koordinater.

Exempel: Kombinera pack() och grid() layout ​

Exempel

python
import tkinter as tk  

root = tk.Tk()
root.title("Grid Layout")
root.geometry("800x600")  

# Konfigurera radfördelning
root.grid_rowconfigure(0, weight=1)  # Första containern: 10% (1/10)
root.grid_rowconfigure(1, weight=9)  # Andra containern: 90% (9/10)
root.grid_columnconfigure(0, weight=1)  # Kolumnen täcker hela bredden

# Container 1 (10% av fönstret)
container1 = tk.Frame(root, bg="lightblue")
container1.grid(row=0, column=0, sticky="nsew")  # Fyll ut 30% av höjden

# Container 2 (90% av fönstret)
container2 = tk.Frame(root, bg="lightgreen")
container2.grid(row=1, column=0, sticky="nsew")  # Fyll ut 70% av höjden

# Skapa en etikett (Label) med text
label = tk.Label(
    container1,               
    text="Välkommen till Grid Layout!", 
    font=("Arial", 28),  
    fg="white",          
    bg="lightblue"      
)
label.pack(pady=30) 

# Skapa widgets
label1 = tk.Label(container2, text="Rad 0, Kolumn 0", font=("Arial", 18))
label2 = tk.Label(container2, text="Rad 1, Kolumn 1", font=("Arial", 18))
label3 = tk.Label(container2, text="Rad 2, Kolumn 3", font=("Arial", 18))

label1.grid(row=0, column=0)
label2.grid(row=1, column=1)
label3.grid(row=2, column=3)

root.mainloop()

Lägga till interaktivitet ​

Ett GUI-program är inte komplett utan interaktivitet. Du kan lägga till funktionalitet med händelser och koppla dessa till dina widgets.

Exempel

python
import tkinter as tk

# Funktion som ökar räknaren
count = 0
def increase_count():
    global count
    count += 1
    label.config(text=f"Räknare: {count}")

root = tk.Tk()
root.title("Räkneverk")
root.geometry("350x150")

# Skapa en etikett
label = tk.Label(root, text="Räknare: 0", font=("Arial", 16))
label.pack(pady=10)

# Skapa en knapp
button = tk.Button(root, text="Öka", command=increase_count, font=("Arial", 14))
button.pack(pady=10)

root.mainloop()

Sammanfattning ​

Tkinter är ett enkelt men kraftfullt verktyg för att skapa grafiska gränssnitt i Python. Det ger dig möjlighet att bygga allt från enkla fönster med några få widgets till mer avancerade applikationer med interaktivitet och komplex layout.

I den här delen har vi gått igenom:

  • Hur man skapar ett grundläggande fönster med Tkinter.
  • Hur man lägger till och använder widgets som etiketter, knappar och textfält.
  • Hur man använder olika layout-metoder som pack() och grid().
  • Hur man lägger till interaktivitet genom att koppla funktioner till widgets.

Med dessa kunskaper har du en bra grund för att fortsätta utforska Tkinter och skapa dina egna GUI-applikationer.

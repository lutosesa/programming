Tkinter widgetar ​

Förutom de tre widgetarna som vi har introducerat i föregående avsnitt, här kommer vi att visa ännu flera widgetar, hur de används och exempel på dem.

Canvas ​

Tkinter Canvas widget gör att du kan rita på ett område i ditt huvudfönster. Den fungerar som en "teckningstavla" där du kan göra följande:

  • Rita enkla former som linjer, rektanglar, cirklar och polygoner.
  • Lägg till bilder (t.ex. JPEG eller PNG).
  • Hantera text på skärmen.
  • Skapa animeringar.
  • Hantera objekt som kan flyttas eller interageras med.

Canvas demo - Flytta cirkeln med pil-tangenterna

python
import tkinter as tk
root = tk.Tk()
root.title("Canvas demo - Flytta cirkeln med pil-tangenterna")
root.geometry("500x440")
root.config(bg="#4682F9")

# Funktion för att flytta cirkeln med pil-tangenterna
def move_object(event):
    # Hämta cirkelns nuvarande koordinater
    bbox = canvas.bbox(circle)  # bbox ger oss koordinaterna för cirkelns bounding box
    left, top, right, bottom = bbox  # Extrahera koordinaterna för vänster, topp, höger och botten

    # Kontrollera om cirkeln är vid kanten och förhindra att den går utanför
    if event.keysym == "Left" and left > 0:        # Pil vänster
        canvas.move(circle, -5, 0)
    elif event.keysym == "Right" and right < 450:  # Pil höger (Canvas bredd = 450)
        canvas.move(circle, 5, 0)
    elif event.keysym == "Up" and top > 0:         # Pil upp
        canvas.move(circle, 0, -5)
    elif event.keysym == "Down" and bottom < 400:  # Pil ner (Canvas höjd = 400)
        canvas.move(circle, 0, 5)

# Skapar en canvas-widget
canvas = tk.Canvas(root, width=450, height=400, bg="lightyellow")   
canvas.pack(pady=15, padx=15)                                       

canvas.create_line(75, 350, 375, 350, fill="blue", width=4)  
canvas.create_rectangle(120, 130, 330, 230, outline="black", fill="yellow", width=4)    
circle = canvas.create_oval(175, 130, 275, 230, fill="red")     
canvas.create_text(220, 30, text="Välkommen till Canvas!", font=("Arial", 16, "bold"))  
canvas.create_text(220, 50, text="Flytta cirkeln med pil-tangenterna", font=("Arial", 11))  

# Binder pil-tangenterna till funktionen som flyttar cirkeln
root.bind("<Left>",  move_object)   # Pil vänster
root.bind("<Right>", move_object)   # Pil höger
root.bind("<Up>",    move_object)   # Pil upp
root.bind("<Down>",  move_object)   # Pil ner

root.mainloop()

Text (Textruta för flera rader) ​

Används för att skapa ett textfält där användaren kan skriva in eller visa längre texter. Till skillnad från Entry, som bara klarar en rad text, kan Text hantera flera rader och stora mängder text. Det gör den perfekt för anteckningar, dokument, eller längre texter.

  • Man kan ändra textens färg, teckensnitt och bakgrundsfärg.
  • Man kan lägga till en rullningslist (scrollbar) för att bläddra i texten om den är för lång för att visas i fönstret
  • Man kan enkelt lägga till, hämta, eller ta bort text med hjälp av metoder.

Text Demo

python
import tkinter as tk
from tkinter import messagebox

root = tk.Tk()
root.title("Text demo")
root.geometry("500x300")
root.config(bg="RoyalBlue")
root.iconbitmap("favicon.ico")

# Skapa en Text-widget
text_widget = tk.Text(root, font=("Arial", 14), height=8, width=32, bg="lightyellow") 
text_widget.pack(pady=(35, 15)) 

# Funktion för att hämta text
def show_text():
    text_content = text_widget.get("1.0", "end").strip()  # Hämtar text från rad 1, kolumn 0 till slutet
    if text_content != "": 
        messagebox.showinfo("Hämta information", f"{text_content}")
        if messagebox.OK:
            text_widget.delete("1.0", "end") 

# Knapp för att visa text
button = tk.Button(root, text="Visa text", command=show_text, font=("Ariel", 12), width=15, bg="LightCyan")  
button.pack()  

root.mainloop()

Checkbutton (avkryssningsruta) ​

Används för att skapa en avkryssningsruta (checkbox) och den illåter användaren att välja eller avmarkera ett alternativ, vilket representeras av ett av två tillstånd:

  • markerad (checked=1) eller
  • omarkerad (unchecked=0).

Den används ofta för att tillåta användaren att välja mellan flera olika alternativ.

Checkbutton demo

python
import tkinter as tk
root = tk.Tk()
root.title("Checkbutton demo (avkryssningsruta)")
root.geometry("500x300")
root.configure(bg="gold")
root.iconbitmap("favicon.ico")

tk.Text(root, height=6, width=40).grid(row=0, padx=40, pady=(40, 5), sticky="w")

## Skapa metod för checkbutton markering
def check_action():                                                 
    if var.get() == 1:                                              
        label.config(text="(Checkbutton är markerad)", fg="green")  
    else:                                                           
        label.config(text="(Checkbutton är avmarkerad)", fg="red")  

# Definiera en variabel för att hålla koll på tillståndet
# och skapa en Checkbutton
var = tk.IntVar()           
checkbutton = tk.Checkbutton(root, text="Acceptera villkoren", variable=var, command=check_action, bg="gold") 
checkbutton.grid(row=1, padx=40, pady=(20, 0), sticky="w") 

label = tk.Label(root, text="Checkbutton är avmarkerad", bg="gold", fg="red")
label.grid(row=2, padx=60, pady=(1, 5), sticky="w")

root.mainloop()

Radiobutton (Radioknapp) ​

Används för att skapa en uppsättning val där endast ett alternativ kan väljas åt gången. Radioknappar är ofta grupperade tillsammans, och alla knappar i samma grupp är kopplade till samma variabel.

När användaren klickar på en radioknapp, uppdateras värdet på den variabel som knapparna är kopplade till.
Radioknappar används ofta när ett användarval måste göras från en lista av alternativ där bara ett val är möjligt.

Radiobutton demo

python
import tkinter as tk
root = tk.Tk()
root.title("Radiobutton demo (Radioknapp)")
root.geometry("500x300")
root.configure(bg="orange")

# Skapa metod för vald checkbutton
def radiobutton_action():
    label.config(text=f"Valt alternativ: {var.get()}", fg="DodgerBlue")

# Definiera en variabel för att hålla koll på radiobutton
# och skapa radiobuttons.
var = tk.IntVar()
tk.Radiobutton(root, text='Man',    variable=var, value="1", command=radiobutton_action, bg="orange", font=("Arial", 12)).grid(row=0, padx=40, pady=(30, 5), sticky="w")
tk.Radiobutton(root, text='Kvinna', variable=var, value="2", command=radiobutton_action, bg="orange", font=("Arial", 12)).grid(row=1, padx=40, pady=(5, 5), sticky="w")
tk.Radiobutton(root, text='Annat',  variable=var, value="3", command=radiobutton_action, bg="orange", font=("Arial", 12)).grid(row=2, padx=40, pady=(5, 5), sticky="w")

label = tk.Label(root, text=None, bg="orange", font=("Arial", 12))
label.grid(row=3, padx=60, pady=(5, 5), sticky="w")

root.mainloop()

Combobox (Rullgardinsmeny – från ttk) ​

Används för att skapa en rullgardinsmeny (dropdown) där användaren kan välja ett alternativ från en lista. Comboboxen gör det möjligt för användaren att välja ett alternativ från fördefinierade alternativ, men användaren kan också skriva in ett eget alternativ om så önskas.

Den kombinerar funktionaliteten hos både en Listbox och ett Entry-fält.

En händelsehanterare on_select-funktion är bunden till Comboboxen med bindningsmetoden bind(), som uppdaterar en etikett med det valda objektet när ett objekt väljs.

Combobox demo

python
import tkinter as tk
from tkinter import ttk     # Importera ttk-modulen för Combobox

root = tk.Tk()
root.title("Combobox demo (Rullgardinsmeny)")
root.geometry("500x300")
root.configure(bg="grey")

def on_select(event):
    selected_item = combo_box.get()
    label.config(text="Valt objekt: " + selected_item)

# Skapa en Combobox widget
combo_box = ttk.Combobox(root, values=["Alternativ 1", "Alternativ 2", "Alternativ 3"])     
combo_box.pack(pady=40)                                                                     
combo_box.set("Alternativ 1")   # Ställ in standardvärde
combo_box.bind("<<ComboboxSelected>>", on_select) # Bind händelse till on_select

# Skapa en label
label = tk.Label(root, text="Valt objekt: ", font=9, bg="grey")
label.pack(pady=20)

root.mainloop()

Listbox (Lista) ​

Används för att skapa en lista med alternativ där användaren kan välja ett eller flera objekt.

Den kan vara mycket användbar för att presentera en uppsättning alternativ eller för att tillåta användaren att välja flera objekt.

Listbox demo

python
import tkinter as tk
root = tk.Tk()
root.title("Listbox demo")
root.geometry("500x300")
root.config(bg="peru")
root.iconbitmap("favicon.ico")

# Funktion som körs när ett objekt väljs i Listboxen
def on_select(event):
    selected_item = listbox.get(listbox.curselection())  # Hämta det valda objektet
    label.config(text= f"Valt alternativ: {selected_item}")  # Uppdatera etiketten

# Skapa en Listbox
listbox = tk.Listbox(root, height=12, width=30, selectmode=tk.SINGLE)  # Tillåter ett val i taget
listbox.pack(pady=(30, 10)) 
# Binda händelsen <<ListboxSelect>> till funktionen on_select
listbox.bind("<<ListboxSelect>>", on_select)     

# Lägg till objekt i Listbox
for x in range(1, 13):
    listbox.insert(tk.END, f"   Alternativ  {x}")

# Skapa en etikett för att visa det valda objektet
label = tk.Label(root, text=None, font=("Arial", 11), bg="Peru")
label.pack(pady=15)

root.mainloop()

Frame (Ram) ​

Frame-widgeten är en behållare (container) som används för att gruppera andra widgets (som knappar, etiketter, textfält osv.) i ett visuellt block. Det är särskilt användbart för att strukturera layouten i en applikation och organisera olika delar av användargränssnittet.

I denna demo nedan delas huvudfönstret i tre sektioner: topp, mitten och botten. Varje sektion innehåller widgets för att demonstrera hur frames fungerar.

Frame demo -flera frames i huvudfönstret

python
import tkinter as tk
import random
root = tk.Tk()
root.title("Frame demo (flera frames i huvudfänstret)")
root.geometry("500x300")
root.config(bg="#565656")
root.iconbitmap("favicon.ico")

# Skapa topp-frame (tar 20% av höjden)
top_frame = tk.Frame(root, bg="lightblue", borderwidth=2, relief="ridge")   
top_frame.place(relx=0, rely=0, relwidth=1, relheight=0.2)                  

# Skapa mitten-frame (tar 60% av höjden)
middle_frame = tk.Frame(root, bg="lightgreen", borderwidth=2, relief="ridge")   
middle_frame.place(relx=0, rely=0.2, relwidth=1, relheight=0.6)                 

# Skapa botten-frame (tar 20% av höjden)
bottom_frame = tk.Frame(root, bg="lightcoral", borderwidth=2, relief="ridge")   
bottom_frame.place(relx=0, rely=0.8, relwidth=1, relheight=0.2)                 

# Funktion för att slumpa bakgrundsfärg
new_color = "lightgreen"
def random_color():
    colors = ["red", "blue", "green", "yellow", "pink", "orange", "purple", "cyan"]
    new_color = random.choice(colors)
    middle_frame.config(bg=new_color)
    middle_label.config(bg=new_color)
    middle_button.config(bg=new_color)

# Lägg till etiketter i varje frame
tk.Label(top_frame, text="Toppsektion", bg="lightblue", font=("Arial", 12)).pack(pady=10)
middle_label = tk.Label(middle_frame, text="Mittensektion", bg=new_color, font=("Arial", 12))
middle_label.pack(pady=10)
tk.Label(bottom_frame, text="Bottensektion", bg="lightcoral", font=("Arial", 12)).pack(pady=15)

middle_button = tk.Button(middle_frame, text="Klicka här", command=random_color, bg=new_color, font=("Arial", 12), borderwidth=5, relief="ridge")
middle_button.pack(pady=10)

root.mainloop()

Scrollbar (Rullningslist) ​

Används för att lägga till rullningsfunktionalitet (scroll) i andra widgets som till exempel Text, Canvas, Listbox, eller andra widgets som har mycket innehåll som inte får plats i ett fönster.
Scrollbars kan placeras vertikalt (längs höger sida) eller horisontellt (längs nedre sidan) av en widget.

Scrollbars hjälper användaren att navigera i en widget när innehållet är större än det visuella området.

Scrollbar demo

python
import tkinter as tk
root = tk.Tk()
root.title("Scrollbar demo (Rullningslist)")
root.geometry("500x300")
root.configure(bg="#FFE4B5")
root.iconbitmap("favicon.ico")

# Skapa en Listbox
listbox = tk.Listbox(root, width=60, height=20)
listbox.pack(side=tk.LEFT, fill=tk.BOTH, expand=True, padx=100, pady=20)

# Skapa en vertikal Scrollbar
scrollbar = tk.Scrollbar(listbox, orient="vertical", command=listbox.yview)  
scrollbar.pack(side=tk.RIGHT, fill=tk.Y)                                     

# Koppla Scrollbar till Listbox
listbox.config(yscrollcommand=scrollbar.set)

# Lägg till objekt i Listbox
for i in range(50):
    listbox.insert(tk.END, f" Objekt {i+1}")

root.mainloop()

Separator (Avdelare – från ttk) ​

Används för att visuellt separera olika delar av ett gränssnitt, vilket förbättrar struktur och användarupplevelse.

Separator-widgeten kommer från ttk-modulen, som är en del av Tkinter, och den används för att rita en horisontell eller vertikal linje beroende på vad du behöver.

Separator demo

python
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("Separator demo")
root.geometry("500x300")
root.configure(bg="Navy")
root.iconbitmap("favicon.ico")

# Skapa etiketter för att visa avdelningar
label1 = ttk.Label(root, text="Sektion 1")
label1.pack(pady=10)

# Skapa en horisontell separator
ttk.Separator(root, orient="horizontal").pack(fill="x", padx=10, pady=10)  

# Skapa en andra sektion med en etikett
label2 = ttk.Label(root, text="Sektion 2")
label2.pack(pady=10)

ttk.Separator(root, orient="horizontal").pack(fill="x", padx=10, pady=10)  

# Skapa en vertikal separator
frame = tk.Frame(root, width=400, height=140,  borderwidth=2, relief="ridge")
frame.place(relx=0.10, rely=0.5, relwidth=0.8, relheight=0.3)

label3 = ttk.Label(frame, text="Sektion 3 - Vänster")
label3.pack(side="left", padx=10)

ttk.Separator(frame, orient="vertical").pack(side="left", fill="y", padx=(80, 5))  

label4 = ttk.Label(frame, text="Sektion 4 - Höger")
label4.pack(side="right", padx=10)

ttk.Separator(root, orient="horizontal").place(relx=0.02, rely=0.9, relwidth=0.96)

Menu (Meny) ​

Används för att skapa menyer.

  • En meny är en lista med alternativ som visas när du klickar på en rubrik, t.ex. "Arkiv".
  • Varje meny innehåller menyalternativ (exempelvis "Öppna", "Spara", "Avsluta").
  • Menyalternativen kan kopplas till funktioner, så när användaren klickar på ett alternativ händer något.

Meny demo

python
import tkinter as tk
root = tk.Tk()
root.title("Menu demo")
root.geometry("500x300")
root.config(bg="MidnightBlue")
root.iconbitmap("favicon.ico")

# Skapa en huvudmeny
meny = tk.Menu(root)    

# Skapa en undermeny (Arkiv)
arkiv_meny = tk.Menu(meny, tearoff=0)  # tearoff=0 tar bort det streckade "rivet" högst upp
arkiv_meny.add_command(label="Öppna", command=lambda: print("Öppna klickat"))  
arkiv_meny.add_command(label="Spara", command=lambda: print("Spara klickat"))  
arkiv_meny.add_separator()  # Lägg till en separatorlinje
arkiv_meny.add_command(label="Avsluta", command=root.quit)     

# Lägg till undermenyn "Arkiv" i huvudmenyn
meny.add_cascade(label="Arkiv", menu=arkiv_meny)        

# Skapa en undermeny (Redigera)
redigera_meny = tk.Menu(meny, tearoff=0)
redigera_meny.add_command(label="Kopiera", command=lambda: print("Kopiera klickat"))
redigera_meny.add_command(label="Klistra in", command=lambda: print("Klistra in klickat"))

# Lägg till undermenyn "Redigera" i huvudmenyn
meny.add_cascade(label="Redigera", menu=redigera_meny)

root.config(menu=meny)  # Koppla huvudmenyn till fönstret

root.mainloop()

Message (Meddelanderuta) ​

Används för att visa text i ett fönster. Den liknar en Label, men den är speciellt bra för längre texter eftersom den automatiskt kan bryta texten (radbrytning) och anpassa sig till fönstrets storlek. Man kan ändra saker som:

  • Font (teckensnitt)
  • Bakgrundsfärg
  • Textfärg
  • Justering (t.ex. vänster, center eller höger)

Message demo

python
import tkinter as tk
root = tk.Tk()
root.title("Message demo")
root.geometry("500x300")
root.config(bg="#4169E1")

# Skapa Message-widget
message_text = ("Detta är en Tkinter Message-widget.\nMeddelandet kommer att tas bort efter 5 sekunder!")
message = tk.Message(root, text=message_text, width=450, font=("Arial", 12), bg="#483D8B", fg="white")
message.pack(pady=20)

# Funktion för att ta bort Message-widgeten efter 5 sekunder
def remove_message():
    message.pack_forget()  # Tar bort widgeten från fönstret

# Använd after() för att anropa remove_message efter 5000 ms (5 sekunder)
root.after(5000, remove_message)

root.mainloop()

Spinbox ​

Spinbox-widgeten fungerar som en ruta där användaren kan skriva ett numeriskt värde eller använda upp- och nedpilar för att välja ett värde inom ett angivet intervall.

Spinbox

python
import tkinter as tk
root = tk.Tk()
root.title("Spinbox")
root.geometry("500x300")
root.config(bg="#32CD32")

# Skapa en Spinbox-widget för att välja mellan 1 och 10
spinbox = tk.Spinbox(root, from_=1, to=10, width=5, font=("Arial", 12))  
spinbox.pack(pady=20)

button.pack()

# Skapa en label
label = tk.Label(root, text="Valt värde: ", font=("Arial", 12), bg="#32CD32")
label.pack(pady=20)

root.mainloop()

Table (tabell) ​

I Tkinter finns det inte en direkt inbyggd widget för att skapa tabeller, men du kan skapa tabell-liknande strukturer med hjälp av olika widgets och layouter. Ett vanligt sätt att skapa en tabell i Tkinter är att använda grid()-layouten tillsammans med Label eller Entry för att visa data i ett rutnät.

Exempel på att skapa en tabell med grid() och labels

python
import tkinter as tk
root = tk.Tk()
root.title("Tabell demo")
root.geometry("500x300")
root.configure(bg="#454545")
root.iconbitmap("favicon.ico")

# Skapa en Frame-widget för att hålla tabellen
frame = tk.Frame(root)
frame.pack(padx=10, pady=50)

# Skapa exempeldata
data = [
    ["ID", "Namn", "Kurs", "Betyg"],
    [1, "Alfred Popeye", "Programmering 2", "D"],
    [2, "Allan Parson",  "Programmering 2", "B"],
    [3, "Emil Markoolio",  "Programmering 2", "C"],
    [4, "Axel Manning",   "Programmering 2", "C"],
    [5, "Luke Lucky",    "Programmering 2", "D"]
]

# Skapa tabellen med grid()
for row_index, row in enumerate(data):
    for col_index, value in enumerate(row):
        if row_index == 0:
            # Första raden, rubriker
            label = tk.Label(frame, text=value, borderwidth=1, relief="solid",
                             width=15, height=2, bg="lightblue", fg="black", font=("Arial", 10, "bold"))
        else:
            # Vanliga rader
            label = tk.Label(frame, text=value, borderwidth=1, relief="solid",
                             width=15, height=1, bg="white", fg="black", font=("Arial", 10))
        if col_index == 0:
            label.config(width=4)
        if col_index == 3:
            label.config(width=6)

        label.grid(row=row_index, column=col_index, padx=1, pady=1)

root.mainloop()

Exempel på att skapa en tabell med grid() och Entry-widgetar

python
import tkinter as tk
root = tk.Tk()
root.title("Tabell demo")
root.geometry("500x300")
root.configure(bg="#454545")
root.iconbitmap("favicon.ico")

# Skapa en Frame-widget för att hålla tabellen
frame = tk.Frame(root)
frame.pack(padx=10, pady=50)

# Skapa exempeldata
data = [
    ["ID", "Namn", "Kurs", "Betyg"],
    [1, "Anton Marvel", "Programmering 2", "C"],
    [2, "Emil Smart", "Programmering 2", "B"],
    [3, "Josef Clever", "Programmering 2", "B"],
    [4, "Hugo Cabret", "Programmering 2", "D"],
    [5, "Papi Santana", "Programmering 2", "A"]
]
# Skapa en lista för att hålla på Entry-widgetarna
entries = []

# Skapa tabellen med Entry-widgetar
for row_index, row in enumerate(data):
    row_entries = []   # För att hålla på Entry-widgetarna för varje rad
    for col_index, value in enumerate(row):
        if row_index == 0:
            # Första raden (rubriker), ge annan bakgrundsfärg
            entry = tk.Entry(frame, justify="center", font=("Arial", 10, "bold"),
                             bg="lightgreen", fg="black", borderwidth=1, relief="solid")
        else:
            # Vanliga rader, med standard bakgrund
            entry = tk.Entry(frame, justify="center", font=("Arial", 10),
                             bg="white", fg="black", borderwidth=1, relief="solid")
        if col_index == 0:
            entry.config(width=4)
        if col_index == 3:
            entry.config(width=6)

        entry.insert(0, value)  # Fyll Entry med data
        entry.grid(row=row_index, column=col_index, padx=1, pady=1)  # Placera Entry i grid
        row_entries.append(entry)  # Lägg till Entry i raden

    entries.append(row_entries)  # Lägg till raden i listan över entries
root.mainloop()

Treeview ​

Används för att visa data i en trädstruktur som en lista med förgreningar, ungefär som mappar i en filhanterare, eller som en tabell med kolumner, men med möjlighet att skapa "grenar" och "blad" (trädstrukturer).

Treeview

python
import tkinter as tk

root = tk.Tk()

Scale (skjutreglage) ​

Tkinter Scale är ett kraftfullt verktyg för att skapa interaktiva reglage där användare kan justera värden.

Den är väldigt användbar när du vill ha en visuell representation av ett intervall som användaren kan interagera med, exempelvis för att ställa in volym, ljusstyrka eller liknande.

Scale demo

python
import tkinter as tk
root = tk.Tk()
root.title("Scale demo (skjutreglage)")
root.geometry("500x300")
root.config(bg="DarkKhaki")

# Funktion för att visa det valda värdet från skalan
def update_label(val):
    label.config(text=f"Värde: {val}")

# Skapa en Scale-widget (horisontell)
scale = tk.Scale(root, from_=0, to=100, orient="horizontal",    
                 length=300,        # Längd på skalan
                 width=20,          # Bredd på skalan
                 sliderlength=30,   # Längd på reglaget
                 command=update_label)                          
scale.pack(pady=40)                                             

# Skapa en etikett för att visa det valda värdet
label = tk.Label(root, text="Värde: 0", 
                 font=("Arial", 14, "bold"), 
                 bg="DarkKhaki")
label.pack()

root.mainloop()

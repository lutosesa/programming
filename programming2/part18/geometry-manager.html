Tkinter Geometrihanterare (Geometry manager) ​

För att placera och arrangera olika element (widgets) i ett fönster eller en ram använder vi geometrihanterare. De tre vanligaste geometrihanterare i Tkinter är:

  • pack(): Placerar widgets i ordning (uppifrån och ned).
  • grid(): Använder ett rutnät för att placera widgets.
  • place(): Tillåter dig att exakt positionera widgets med koordinater.

Här förklarar vi hur de fungerar och när man bör använda dem.

pack() ​

pack() är den mest grundläggande geometrihanterare. Den används för att placera widgets vertikalt eller horisontellt inom en container (t.ex. ett fönster eller en ram). Widgets placeras automatiskt baserat på ordningen de läggs till i koden.

Parametrar i pack() ​

  • padx, pady: Lägger till tom utrymme (padding) runt widgeten horisontellt (x) och vertikalt (y).
  • side: Bestämmer vilken sida av fönstret widgeten ska placeras (t.ex. top, bottom, left, right). Standard är top.
  • fill: Fyller widgeten horisontellt (X), vertikalt (Y), eller båda (BOTH).
  • expand: Om True, får widgeten mer utrymme om fönstret ändrar storlek.

Innan vi går in in i varje parametern måste du förstå huvudfönstrets koordinater x och y:

  • Det övre vänstra hörnet av fönstret är origo med koordinaten (0,0).
  • X-koordinaten ökar från vänster till höger.
  • Y-koordinaten ökar från topp till botten.

Exempel med padx, pady:

  • padx: Lägger till ett extra horisontellt tom utrymme (mellan widgeten och andra objekt på vänster och höger sida).
  • pady: Lägger till ett extra vertikalt tom utrymme (mellan widgeten och andra objekt ovanför och under).
  • De används ofta i geometrihanterare som pack(), grid(), eller place().

Exempel

Geometrihanterare pack() placerar tre Label-widgets vertikalt, uppifrån nedåt och parametern pady skapar tom utrymme mellan dessa både ovanför och under widgetarna.

python
import tkinter as tk

# Skapa huvudfönster
root = tk.Tk()
root.title("Geometrihanterare pack() med 'pady'")
root.geometry("500x300")

# Skapa etiketter widgets
label1 = tk.Label(root, text="Detta är label 1", bg="lightcoral")
label2 = tk.Label(root, text="Detta är label 2", bg="lightyellow")
label3 = tk.Label(root, text="Detta är label 3", bg="lightgreen")

# Placera widgets
label1.pack(pady=(60, 30))  
label2.pack(pady=30)        
label3.pack(pady=(30, 0))   

# Starta huvudloopen
root.mainloop()

Exempel med side:
'side' anger vilken riktning en widget ska packas i förhållande till andra widgets.

  • side="top": Placerar widgeten överst (standardläge).
  • side="bottom": Placerar widgeten längst ner.
  • side="left": Placerar widgeten till vänster.
  • side="right": Placerar widgeten till höger.

Det bestämmer alltså ordningen och placeringen av widgeten i förhållande till de andra element som packas i samma container.

Exempel

python
import tkinter as tk

# Skapa huvudfönster
root = tk.Tk()
root.title("Geometrihanterare pack() med 'side'")
root.geometry("500x300")

# Skapa etiketter widgets
label1 = tk.Label(root, text="Detta är label 1", bg="lightcoral")
label2 = tk.Label(root, text="Detta är label 2", bg="lightyellow")
label3 = tk.Label(root, text="Detta är label 3", bg="lightgreen")

# Packa widgets med parametern 'side'
label1.pack(side="top")      # Packas på toppen
label2.pack(side="left")     # Packas på vänster
label3.pack(side ="bottom")  # Packas till botten

# Starta huvudloopen
root.mainloop()

Exempel med fill:
'fill' styr hur en widget ska fylla utrymmet i den riktning som anges.

  • fill="x": Widgeten fyller hela bredden horisontellt (över hela fönstret eller behållaren).
  • fill="y": Widgeten fyller hela höjden vertikalt.
  • fill="both": Widgeten fyller både bredden och höjden, alltså hela utrymmet.

Om fill inte specificeras, kommer widgeten endast att ta upp så mycket utrymme som behövs för sitt innehåll.

Exempel

python
import tkinter as tk

# Skapa huvudfönster
root = tk.Tk()
root.title("Geometrihanterare pack() med 'fill'")
root.geometry("500x300")

# Skapa etiketter widgets
label1 = tk.Label(root, text="Detta är label 1", bg="red", fg="white")
label2 = tk.Label(root, text="Detta är label 2", bg="green", fg="white")
label3 = tk.Label(root, text="Detta är label 3", bg="blue", fg="white")

# Packa widgets med parametern 'fill'
label1.pack(fill="x")    # Fyll hela bredden
label2.pack(fill="x", padx=20)  
label3.pack(fill="x", padx=40)  

# Starta huvudloopen
root.mainloop()

Exempel expand:
'expand' styr om en widget ska ta upp extra utrymme om det finns ledigt utrymme i containerfönstret.

  • expand=True: Widgeten får extra utrymme och växer för att fylla det lediga utrymmet i containerfönstret.
  • expand=False (standard): Widgeten växer inte och tar bara upp det utrymme som behövs för sitt innehåll.

Detta gör det möjligt att skapa flexibla layouter där vissa widgets kan växa för att fylla tomma utrymmen.

Exempel

python
import tkinter as tk

# Skapa huvudfönster
root = tk.Tk()
root.title("Geometrihanterare pack() med 'expand'")
root.geometry("500x300")

# Skapa etiketter widgets
label1 = tk.Label(root, text="Detta är label 1", bg="red", fg="white")
label2 = tk.Label(root, text="Detta är label 2", bg="green", fg="white")
label3 = tk.Label(root, text="Detta är label 3", bg="blue", fg="white")

# Packa widgets
label1.pack(expand=True, fill="both")  # 'expand' växer för att fylla utrymmet
label2.pack(fill="both")  # Fyller bara sin storlek
label3.pack(expand=True, fill="both")  # 'expand' växer för att fylla utrymmet

# Starta huvudloopen
root.mainloop()

grid() ​

grid() är mer avancerad än pack() och används för att placera widgets i ett rutnät, med rader och kolumner. Den här geometrihanteraren gör det enklare att skapa mer strukturerade och flexibla användargränssnitt.

Följande visar ett rutnät som består av fyra rader och tre kolumner:

  • Varje rad och kolumn i rutnätet identifieras av ett index.
  • Som standard har den första raden ett index på noll, den andra raden har ett index på ett och så vidare.
  • På samma sätt har kolumnerna i rutnätet index på noll, ett, två osv.
  • Indexen för rader och kolumner i ett rutnät behöver inte börja på noll. Dessutom kan rad- och kolumnindexen ha luckor.
  • Skärningspunkten mellan en rad och en kolumn kallas en cell.
  • En cell är ett område där du kan placera en widget.
  • En cell kan bara innehålla en widget

Parametrar i grid() ​

  • row: radnummer (startar från 0). Rader numreras uppifrån och ner.
  • column: kolumnnummer (startar från 0). Kolumner numreras från vänster till höger.
  • padx, pady: lägger till utrymme/mellanrum (padding) i pixlar runt widgeten horisontellt och vertikalt.
  • sticky: förankrar widgeten i en viss riktning (t.ex. N, S, E, W för nord, syd, öst, väst).
  • rowspan, columnspan: hur många rader eller kolumner widgeten ska sträcka sig över.

Exempel med med row, column, sticky och columnspan

Exempel

python
import tkinter as tk

root = tk.Tk()
root.title("Geometrihanterare grid() demo")
root.geometry("500x300")

# Skapa etiketter och textrutor
label1 = tk.Label(root, text="namn:")
label2 = tk.Label(root, text="E-postadress:")
entry1 = tk.Entry(root)
entry2 = tk.Entry(root, width=25)
button = tk.Button(root, text="Register", width=15, bg="lightgreen", 
                   relief="raised", borderwidth=2)

# Placera dem i grid med vänsterjustering
label1.grid(column=0, row=0, sticky="e", padx=(40,10), pady=(35,5))
label2.grid(column=0, row=1, sticky="w", padx=(40,10), pady=5)
entry1.grid(column=1, row=0, sticky="w", padx=10, pady=(35, 5))
entry2.grid(column=1, row=1, sticky="w", padx=10, pady=10)  
button.grid(column=0, row=2, columnspan=2, sticky="nsew",
            padx=(40,10), pady=5)

root.mainloop()

place() ​

Med place() kan man ange positionen för en widget i fönstret med hjälp av koordinater. Det kan göras med absolut placering eller relativ placering beroende på hur man definierar positionen. Med andra ord får vi mer kontroll över var widgetarna ska vara.

Parametrar (alternativ) för place() ​

  1. x och y

    • Dessa anger de exakta absoluta pixelpositionerna för widgeten i förhållande till fönstrets övre vänstra hörn.
    • x är horisontell position, och y är vertikal position.

    Exempel med x och y parametrar

    python
    import tkinter as tk

root = tk.Tk()
root.title("Geometrihanterare place() med x och y")
root.geometry("500x300")

# Skapa etiketter och textrutor som ska placeras med place()
label1 = tk.Label(root, text="Namn:", bg="lightblue")
label2 = tk.Label(root, text="E-postadress:", bg="lightcoral")
entry1 = tk.Entry(root)
entry2 = tk.Entry(root, width=25)
button = tk.Button(root, text="Register", width=15, bg="lightgreen", 
                   relief="raised", 
                   borderwidth=2)

# Används x och y parametrar för absolut placering
label1.place(x=30, y=30)     
label2.place(x=30, y=70)     
entry1.place(x=120, y=30)    
entry2.place(x=120, y=70)    
button.place(x=120, y=110)   

root.mainloop()

  1. anchor:
    • Bestämmer vilken punkt av widgeten som ska placeras på de angivna koordinaterna. Vanligtvis är det övre vänstra hörnet som används, men du kan också använda t.ex. "center" för att placera widgeten så att dess mittpunkt är vid de angivna koordinaterna.
    python
    widget.place(x=100, y=100, anchor="center")
    Detta placerar widgetens mittpunkt på (100, 100) istället för övre vänstra hörnet.

Sammanfattning ​

Sammanfattningsvis erbjuder Tkinter tre huvudsakliga geometrihanterare för att placera och arrangera widgets i fönster: pack(), grid() och place().

  • pack() är den enklaste och mest grundläggande geometrihanteraren, som placerar widgets i ordning antingen vertikalt eller horisontellt och erbjuder parametrar för att justera padding, placering och expansion av widgetar.
  • grid() tillhandahåller ett mer strukturerat och flexibelt alternativ, där widgets placeras i ett rutnät av rader och kolumner. Detta gör det lättare att skapa komplexa och organiserade användargränssnitt.
  • place() ger fullständig kontroll över widgetarnas placering med hjälp av exakta koordinater, antingen absolut eller relativt i förhållande till fönstrets storlek.

Varje geometrihanterare har sina egna fördelar beroende på det specifika behovet av layout, vilket gör att du kan skapa både enkla och avancerade användargränssnitt med Tkinter.

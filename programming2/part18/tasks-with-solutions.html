Uppgift 1: Skapa ett grundläggande Tkinter fönster ​

Skapa ett Tkinter-program som skapar ett fönster med:

  • titeln "Uppgift 1 - Mitt första program",
  • en storlek på 400x220 pixlar.
  • en bakgrundsfärg som du väljer själv.
  • en storlek som inte blir ändringsbart varken horisontellt eller vertikalt.
  • En egen ikon (det lilla bilden som visas i fönstrets övre vänstra hörn).
  • Ladda ner ikon-bilden 'favicon.ico' i mappen där du har din Python fil

Lösning:

python
import tkinter as tk

# Skapar huvudfönstret
root = tk.Tk()
root.title("Uppgift 1 - Mitt första program")
root.geometry("400x220")
root.configure(bg="lightblue")
root.resizable(False, False)
root.iconbitmap("favicon.ico")

# Kör mainloop för att visa fönstret
root.mainloop()

Uppgift 2: Lägga till en etikett och en bild ​

Bygg vidare på uppgift 1 men ta bort backgrundsfärgen!

  1. Lägg till fönstret en etikett (Label) med följande atributt:
    • den visar texten "Välkommen till Tkinter!"
    • den har teckensnitt "Ariel", storleken 18 och fet-stil.
    • den placeras med 5 pixel både ovanför och under, med geometrihanteraren pack(pady=5)
  2. Lägg till en bild under etiketten (en etikett kan också innehålla en bild).
    • Använd en bildfil som heter bild.png och lägg den i samma map/katalog som din python fil.
    • Ladda ner bilden 'bild.png' i mappen där du har din Python fil
  3. Se output-bilden nedan!

python
import tkinter as tk

# Skapar huvudfönstret
root = tk.Tk()
root.title("Uppgift 2 - Etikett och bild")

root.resizable(False, False)
root.iconbitmap("favicon.ico")

# Skapar en etikett
tk.Label(root, text="Välkommen till Tkinter!", font=("Ariel", 18, "bold")).pack(pady=5)

# Laddar och visar en bild
image = tk.PhotoImage(file="bild.png")  # Se till att du har en bild som heter bild.png
tk.Label(root, image=image).pack()

# Kör mainloop för att visa fönstret
root.mainloop()

Uppgift 3: Textruta och knapp ​

Skapa en applikation med en textruta där användaren kan skriva sitt namn och visa det i en etikett när användaren klickar på en knapp.

Vi bygger vidare på uppgift 2:

  1. Vi har samma etikett från uppgift 2 med texten "Välkommen till Tkinter!" placeras med 10 pixel både ovanför och under, med geometrihanteraren pack(pady=10)
  2. Ta bort bilden och lägg till en textruta (Entry) där användaren kan skriva sitt namn.
    • Textruta placeras med 10 pixel både ovanför och under, med geometrihanteraren pack(pady=10)
    • Textrutan har en bredd på 25
    • set fokus på textrutan med funktionen: entry.focus_set()
  3. Lägg till en knapp (Button) under textruta (Entry) och döp den til "Visa namn".
    • Knappen placeras med 10 pixel både ovanför och under, med geometrihanteraren pack(pady=10)
    • Knappen har en bredd på 20
    • När knappen trycks på ska dess namn ändras till "Rensa", så att användaren kan rensa textrutan.
  4. Se output-bilderna nedan!

Lösning:

python
import tkinter as tk

# Skapar huvudfönstret
root = tk.Tk()
root.title("Uppgift 3 - Entry och Button")
root.geometry("400x220")
root.resizable(False, False)

# Funktion för namn-visning vid knapptryckning
def show_name():
    name = entry.get()  # Hämtar texten från textrutan
    if name != "":
        if button.cget("text") == "Visa namn":
            label.config(text=f"Välkommen {name}!")
            button.config(text="Rensa", bg="lightsalmon")
        else:
            entry.delete(0, tk.END)  # Tömmer textrutan
            button.config(text="Visa namn", bg="lightgreen")
            label.config(text="Välkommen till Tkinter!")

# Skapar en etikett
label = tk.Label(root, text="Välkommen till Tkinter!", font=("Ariel", 18, "bold"))
label.pack(pady=10)

# Skapar en textruta med fokus på den
entry = tk.Entry(root, width=25)
entry.pack(pady=10)
entry.focus_set()

# Skapar en knapp
button = tk.Button(root, text="Visa namn", command=show_name, width=20, bg="lightgreen")
button.pack(pady=10)

root.mainloop()

Uppgift 4: Skapa ett lösenordsfält ​

Skapa en inmatningsrutan där användaren ska skriva in sitt lösenord. Texten i textrutan (Entry) ska visas som asterisker (*) och när knappen trycks ska lösenordet visas i en etikett.
Användaren ska kunna rensa inmatningsrutan med samma knapp.

  • Se output-bilderna nedan!

Lösning:

python
import tkinter as tk

# Skapar huvudfönstret
root = tk.Tk()
root.title("Uppgift 4")
root.geometry("300x150")

# Funktion för att visa lösenordet
def show_password():
    password = entry.get()  # Hämtar lösenordet
    if password != "":
        if button.cget("text") == "Visa lösenord":
            label.config(text=f"Lösenordet är: {password}")
            button.config(text="Rensa", bg="lightsalmon")
        else:
            entry.delete(0, tk.END)  # Tömmer textfältet
            button.config(text="Visa lösenord", bg="lightgreen")
            label.config(text="Lösenordet kommer att visas här")

# Skapar textrutan för lösenord (med asterisker)
entry = tk.Entry(root, show="*")
entry.pack(pady=(20, 20))
entry.focus_set()

# Skapar en knapp för att visa lösenordet
button = tk.Button(root, text="Visa lösenord", command=show_password, width=15, bg="lightgreen")
button.pack()

# Skapar en etikett för att visa lösenordet
label = tk.Label(root, text="Lösenordet kommer att visas här")
label.pack(pady=20)

root.mainloop()

Uppgift 5: Ändrar bakgrundsfärgen slumpmässigt ​

Skapa en knapp som ändrar bakgrundsfärgen på huvudfönstret till en slumpmässig färg varje gång knappen trycks, utan att använda en fördefinierad lista med färger.

Tips:

  • Använd random.randint(0, 255) för att skapa slumpmässiga värden för röd, grön och blå komponenter (RGB).
  • Sedan omvandla de slumpmässiga RGB-värdena till en hex-sträng med hjälp av f"#{r:02X}{g:02X}{b:02X}", vilket formaterar varje komponent till en tvåsiffrig hex-siffra.

Se output-bilderna nedan!

Lösning:

python
import tkinter as tk
import random

# Skapar huvudfönstret
root = tk.Tk()
root.title("Uppgift 5")
root.geometry("350x200")

def change_bg_color():
    # Generera slumpmässiga värden för röd, grön och blå (RGB)
    r = random.randint(0, 255)
    g = random.randint(0, 255)
    b = random.randint(0, 255)
    random_color = f"#{r:02X}{g:02X}{b:02X}"   # Omvandla RGB-värdena till en hex-sträng
    root.config(bg=random_color)   # Ändra bakgrundsfärgen på huvudfönstret

# Skapar en knapp för att ändra bakgrundsfärgen
tk.Button(root, text="Ändra bakgrundsfärg", command=change_bg_color, width=30, relief="raised", bg="lightgreen", ).pack(expand=True)

root.mainloop()

Uppgift 7: Använda grid() för att skapa en enkel kalkylator ​

Skapa ett fönster som innehåller en enkel kalkylator med hjälp av grid() för att placera knapparna. Kalkylatorn ska ha:

  1. En textruta (Entry) för att visa resultatet.
  2. Knappfältet (Buttons) ska innehålla siffrorna 0-9 och grundläggande operatorer (addition, subtraktion, multiplikation, division).
  3. Knappen "C" ska rensa textrutan (Entry).
  4. Knappen "=" ska beräkna resultatet och visa det i textrutan.
  5. Om användaren råkar trycka på fel knapp, visas det ett meddelande "Fel inmatning" i textrutan.

Tips: Använd row och column för att ordna knapparna i ett rutnät.

Lösning:

python
import tkinter as tk

root = tk.Tk()
root.title("Uppgift 7 - Kalkylator")
root.geometry("350x222")
root.iconbitmap("favicon.ico")

# funktionen beräknar matematiskt uttryck i entry-widgeten
def calculate():
    try:
        result = eval(entry.get())
        entry.insert(tk.END, f" = {result}")
    except Exception as e:
        entry.config(fg="red")
        entry.insert(tk.END, "     Fel inmatning")

# funktionen tar bort text i entry-widgeten
def clear_entry():
    entry.delete(0, tk.END)
    entry.config(fg="black")

# funktionen lägger till text i entry-widgeten
def add_to_entry(value):
    entry.insert(tk.END, value + " ")
 
# Behållare som innehåller hela kalkylatorn
frame = tk.Frame(root, bg="DimGray")
frame.pack(padx=4, pady=4)

# Skapa widgets
entry = tk.Entry(frame, font=("Arial", 16))
button_clear = tk.Button(frame, text="C",
                         #command=lambda: (entry.delete(0, tk.END), entry.config(fg="black"))
                         command=clear_entry,
                         font=("Arial", 16, "bold"), 
                         relief="sunken", borderwidth=3, 
                         bg="darkred", fg="white")
button_calculate = tk.Button(frame, text="=",
                             command=calculate,
                             font=("Arial", 16, "bold"), 
                             relief="sunken", borderwidth=3, 
                             bg="darkgreen", fg="white")

# Placera widgets med grid()
entry.grid(row=0, column=0, columnspan=4, sticky="nsew", pady=3, padx=3)
button_clear.grid(row=5, column=0, sticky="nsew")
button_calculate.grid(row=5, column=2, sticky="nsew")

# Skapa knappar för siffror och operationer (en lista med tupler)
buttons = [
    ("7", 2, 0), ("8", 2, 1), ("9", 2, 2), ("+", 2, 3),
    ("4", 3, 0), ("5", 3, 1), ("6", 3, 2), ("-", 3, 3),
    ("1", 4, 0), ("2", 4, 1), ("3", 4, 2), ("*", 4, 3),
    ("0", 5, 1), ("/", 5, 3)
]
# För varje tuple i buttons listan skapas en knapp med tk.Button()
for (text, row, col) in buttons:
    button = tk.Button(frame, text=text,
                       # command=lambda value=text: entry.insert(tk.END, value),
                       command=lambda value=text: add_to_entry(value),
                       font=("Arial", 16), width=6,
                       relief="sunken", bg="DimGray", fg="white" )
    button.grid(row=row, column=col)  # Placeringen av knappen

root.mainloop()

Uppgift 8: Använda place() för att placera widgets på exakta positioner ​

Skapa ett fönster med följande funktionalitet med hjälp av place():

  1. Placera en etikett (Label) i fönstret med texten "Vänligen välj ditt favoritdjur".
  2. Placera tre alternativknappar (RadioButtons) för att välja mellan "Hund", "Katt" eller "Fisk".
  3. När användaren väljer ett alternativ ska ett resultat (Label) visas under knapparna som säger "Du valde: [ditt val]".

Tips: Använd x och y för att placera widgets på exakta koordinater i fönstret.

Lösning:

python
import tkinter as tk

root = tk.Tk()
root.title("Uppgift 8")
root.geometry("300x160")

# Skapa metod för vald radiobutton
def show_choice():
    label_choice.config(text=f"Du valde: {var.get()}")

# Definiera en variabel för att hålla koll på radiobutton
var = tk.StringVar()
var.set(None)   # Inga knappar är markerade från början

# Skapa widgets
label = tk.Label(root, text="Vänligen välj ditt favoritdjur:")
radio_hund = tk.Radiobutton(root, text="Hund", variable=var, value="Hund", command=show_choice)
radio_katt = tk.Radiobutton(root, text="Katt", variable=var, value="Katt", command=show_choice)
radio_fisk = tk.Radiobutton(root, text="Fisk", variable=var, value="Fisk", command=show_choice)
label_choice = tk.Label(root, font=("Ariel", 10, 'bold'))

# Används x och y parametrar för absolut placering
label.place(x=30, y=10)
radio_hund.place(x=30, y=35)
radio_katt.place(x=30, y=60)
radio_fisk.place(x=30, y=85)
label_choice.place(x=30, y=115)

root.mainloop()

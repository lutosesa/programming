Laboration: RGB-lysdiod ​

Inledning ​

Vi ska göra så att en RGB lysdiod lyser en regnbåge av färger med hjälp konstanta variabler och en funktion som anropas för att styra och skapa alla färger. RGB står för Red, Green, Blue.

Syfte med labbet ​

Du kommer att lära dig om:

  • hur konstanta variabler deklareras, tilldelas och används.
  • hur de huvudfunktionerna används och att skapa funktioner.
  • hur man kopplar in en RGB lysdiod i en krets.
  • hur man kan styra dessa elektroniska komponenter genom att koda fram en algoritm på utvecklingsmiljön Arduino IDE.

Vad är RGB lysdiod? ​

En RGB lysdiod är en speciell typ av lysdiod som kan lysa i olika färger. Den består av tre små lysdioder i en enda enhet – en röd (R), en grön (G) och en blå (B). Genom att blanda dessa tre färger i olika intensiteter kan man få fram nästan alla färger, ungefär som på en TV eller datorskärm.

Med Arduino kan du styra varje färg individuellt genom att skicka signaler till lysdiodens tre ben, så att du kan skapa olika färgeffekter eller ändra färg efter behov.

Övning 1 ​

Vi ska skapa ett program som styr en RGB-lysdiod och slumpmässigt ändrar dess färg varje sekund, samtidigt ska de aktuella RGB-värdena skrivas ut i seriellmonitorn.

Elektroniska delar som behövs:

  • (1) Arduino Uno
  • (1) USB A-to-B kabel
  • (1) Kopplingsplatta
  • (1)RGB lysdiod
  • (3) 330 Ω resistorer
  • sladdar

Kopplings ritning ​

Programkod ​

cpp
/*********************************************************
 * Labb - övning 1 - RGB LED
 * Programmet styr en RGB-lysdiod och visar slumpmässiga 
 * färger varje sekund. Den gör en RGB-lysdioden till 
 * en regnbåge av färger!   
 *********************************************************/
const int RED_PIN   = 12;
const int GREEN_PIN = 10;
const int BLUE_PIN  =  9;

const int DISPLAY_TIME = 1000;

void setup()
{
    digitalWrite(RED_PIN, OUTPUT);
    digitalWrite(GREEN_PIN, OUTPUT);
    digitalWrite(BLUE_PIN, OUTPUT);
    
    Serial.begin(9600);
}

void loop()
{
    int r = random(255);
    int g = random(255);
    int b = random(255);
    
    Serial.println(String(r) + "\t" + String(g) + "\t" + String(b) );
    
    analogWrite(RED_PIN, r);
    analogWrite(GREEN_PIN, g);
    analogWrite(BLUE_PIN,  b);  
    delay(DISPLAY_TIME);
}

Här är en enkel förklaring av vad programmet gör:

  1. Konstantdeklarationer:
    • RED_PIN, GREEN_PIN och BLUE_PIN bestämmer vilka pinnar på Arduino som är kopplade till den röda, gröna och blå delen av RGB-lysdioden.
    • DISPLAY_TIME är tiden i millisekunder (1000 ms = 1 sekund) som varje färg visas.
  2. setup():
    • digitalWrite() sätter pinnar till OUTPUT, så Arduino kan styra lysdioden.
    • Serial.begin(9600) startar seriell kommunikation, så att värden kan visas på datorn (t.ex. i Serial Monitor).
  3. loop():
    • Tre slumpmässiga värden (r, g, b) mellan 0 och 255 skapas, ett för varje färgkomponent (röd, grön och blå).
    • Dessa värden skrivs ut i Serial Monitor med Serial.println(), så du kan se vilka färger som genereras.
    • analogWrite() används för att sätta intensiteten på varje färg (röd, grön och blå), vilket skapar en slumpmässig färg på lysdioden.
    • Programmet pausar i 1 sekund med delay(DISPLAY_TIME) innan en ny färg genereras.

Sammanfattning: Programmet visar slumpmässiga färger på en RGB-lysdiod och skriver ut de slumpmässiga värdena i datorns Serial Monitor.

Övning 2 ​

Vi ska ha samma anslutningskomponenter och kopplingsritning, men ett helt annat program. Detta program visar hur en RGB-lysdiod kan skapa olika färger genom att tända och släcka de röda, gröna och blå lysdioderna i olika kombinationer. Programmet går igenom sju huvudfärger (röd, grön, blå, gul, cyan, lila, vit) samt ett avstängt läge (alla lysdioder avstängda).

Kopplings ritning ​

Programkod ​

cpp
/***********************************************
 * Labb - övning 2 - RGB LED
 * Gör en RGB LED till en regnbåge av färger!   
 **********************************************/

const int RED_PIN   = 12;
const int GREEN_PIN = 10;
const int BLUE_PIN  =  9;

const int DISPLAY_TIME = 1000;

void setup()
{
    pinMode(RED_PIN,   OUTPUT);
    pinMode(GREEN_PIN, OUTPUT);
    pinMode(BLUE_PIN,  OUTPUT);
}

void loop()
{
    mainColors();    // Röd, grön, blå, gul, cyan, lila, vit
}

/****************************************************************
 * Egen funtion visar "huvudfärger" som RGB-lysdioden kan avge.
/****************************************************************/
void mainColors()
{
    // all LEDs off
    digitalWrite(RED_PIN,   LOW);
    digitalWrite(GREEN_PIN, LOW);
    digitalWrite(BLUE_PIN,  LOW);
    delay(DISPLAY_TIME);

    // Röd
    digitalWrite(RED_PIN,   HIGH);
    digitalWrite(GREEN_PIN, LOW);
    digitalWrite(BLUE_PIN,  LOW);
    delay(DISPLAY_TIME);

    // Grön
    digitalWrite(RED_PIN,   LOW);
    digitalWrite(GREEN_PIN, HIGH);
    digitalWrite(BLUE_PIN,  LOW);
    delay(DISPLAY_TIME);

    // Blå
    digitalWrite(RED_PIN,   LOW);
    digitalWrite(GREEN_PIN, LOW);
    digitalWrite(BLUE_PIN,  HIGH);
    delay(DISPLAY_TIME);

    // Gul (Röd och Grön)
    digitalWrite(RED_PIN,   HIGH);
    digitalWrite(GREEN_PIN, HIGH);
    digitalWrite(BLUE_PIN,  LOW);
    delay(DISPLAY_TIME);

    // Cyan (Grön och Blå)
    digitalWrite(RED_PIN,   LOW);
    digitalWrite(GREEN_PIN, HIGH);
    digitalWrite(BLUE_PIN,  HIGH);
    delay(DISPLAY_TIME);

    // lila (Röd och Blå)
    digitalWrite(RED_PIN,   HIGH);
    digitalWrite(GREEN_PIN, LOW);
    digitalWrite(BLUE_PIN,  HIGH);
    delay(DISPLAY_TIME);

    // Vit (slå PÅ alla lysdioder)
    digitalWrite(RED_PIN,   HIGH);
    digitalWrite(GREEN_PIN, HIGH);
    digitalWrite(BLUE_PIN,  HIGH);
    delay(DISPLAY_TIME);
}

Du kan göra ditt program (Övning 2) mer effektivt och minska antalet kodrader genom att använda en array för att lagra färgkombinationerna och en loop för att gå igenom dem. På så sätt undviker du upprepade digitalWrite- och delay anrop.

Här är en förbättrad version av Övning 2:

cpp
const int RED_PIN   = 12;
const int GREEN_PIN = 9;
const int BLUE_PIN  = 10; 

const int DISPLAY_TIME = 1000;

// Array för färgkombinationer (Röd, Grön, Blå)
const int colors[][3] = {
    {LOW, LOW, LOW},      // Av
    {HIGH, LOW, LOW},     // Röd
    {LOW, HIGH, LOW},     // Grön
    {LOW, LOW, HIGH},     // Blå
    {HIGH, HIGH, LOW},    // Gul
    {LOW, HIGH, HIGH},    // Cyan
    {HIGH, LOW, HIGH},    // Lila
    {HIGH, HIGH, HIGH}    // Vit
};

void setup() {
    pinMode(RED_PIN, OUTPUT);
    pinMode(GREEN_PIN, OUTPUT);
    pinMode(BLUE_PIN, OUTPUT);
}

void loop() {
    mainColors();
}

void mainColors() {
    for (int i = 0; i < 8; i++) {       // Loopa genom alla färger
        digitalWrite(RED_PIN,   colors[i][0]);
        digitalWrite(GREEN_PIN, colors[i][1]);
        digitalWrite(BLUE_PIN,  colors[i][2]);
        delay(DISPLAY_TIME);
    }
}

Förbättringar:

  • Array för färger: Vi lagrar alla kombinationer av färger (LOW/HIGH) i en 2D-array, vilket minskar upprepning.
  • Loop: Vi använder en loop för att gå igenom varje färgkombination och ställer in respektive pin.

Den här versionen gör koden både mer kompakt och lättare att underhålla.

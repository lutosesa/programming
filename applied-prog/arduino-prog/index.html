Programmering med Arduino ​

Inledning ​

Att programmera med Arduino öppnar dörren till en värld där teknik och kreativitet möts. För gymnasieelever erbjuder Arduino en tillgänglig och engagerande väg in i både programmering och elektronik.

Genom att skriva kod och se den omedelbara effekten på fysiska komponenter får du en praktisk och direkt upplevelse av hur programmering kan användas för att påverka den verkliga världen.


Vad är C++? ​

C++ är ett allmänt programmeringsspråk som används för att skapa allt från datorspel till operativsystem. Det är ett språk som är snabbt och effektivt, vilket gör det idealiskt för programmering nära hårdvaran, som med Arduino.

När vi programmerar en Arduino, skriver vi kod som bygger på programmerinsspråket C++, som sedan laddas upp till mikrokontrollern på Arduino-kortet för att styra olika komponenter som LED-lampor, motorer och sensorer.


Minimalt program ​

Varje Arduino-program (kallas "sketch") består av två huvudfunktioner:

  • setup() : Körs en gång när programmet startar. Här initialiseras variabler, ställer in pin-lägen, etc.
  • loop() : Körs om och om igen tills programmet avslutas. Här sker huvudlogiken för ditt program.
  • Nyckelord void : betyder att funktionen inte returnerar någonting.

Exempel

cpp
void setup()
{
   // ställer in pinlägen
}

void loop()
{
  // Huvudlogiken
}

Seriell monitor ​

Vi kommer att använda den seriella monitorn för att testa på exemplen som finns på detta avsnitt!

Den seriella monitorn i Arduino är ett inbyggt verktyg i Arduino IDE (Integrated Development Environment) som gör det möjligt för användaren att kommunicera med sitt Arduino-kort genom att skicka och ta emot textmeddelanden över en seriell anslutning (vanligtvis via USB).

Exempel på en ENKEL UTSKRIFT:

cpp
void setup() {
  Serial.begin(9600);  // Startar monitorn
  Serial.println("Hej på dig!");  // Skriver ut till monitorn
}

void loop() {
  // Här körs koden om och om igen!
}

Huvudfunktioner av seriella monitorn är följande
  1. Skicka data till Arduino: du kan skriva in text eller siffror i ett fält i seriella monitorn och skicka det till Arduino-kortet.
  2. Ta emot och visa data från Arduino: arduino-kortet kan skicka text eller numeriska data tillbaka till datorn, som sedan visas i den seriella monitorn.
  3. Felsökning: eftersom du kan se data som skickas från Arduino-kortet i realtid, är seriella monitorn ett kraftfullt verktyg för att felsöka din kod.
  4. Testning av programlogik: genom att använda seriella monitorn kan du testa hur ditt program reagerar på olika typer av inmatningar utan att behöva koppla upp extra hårdvara eller använda avancerade verktyg.

Variabler, datatyper och kommentarer ​

En variabel är som en låda där du kan lagra data. I Arduino-programmering måste du först deklarera vilken datatyp av data som ska lagras i variabeln.

Datatyper ​

De vanligaste datatyperna som används i Arduino-programmering är:

  • int : Heltal (t.ex. -2, 2, 7, 13)
  • float : Decimaltal (t.ex. 3.14, -0.001)
  • char : Enskilda tecken (t.ex. 'a', '9')
  • bool eller boolean : Sanna eller falska värden (true, false). Standarden i språket är bool, men arduino vill gärna att vi använder icke-standarden boolean.
  • byte : 8 bitar unsigned, dvs från 0 till 255
  • unsigned char : samma som byte, representerar 0 till 255
  • String : en samling av tecken som kan innehålla ord eller meningar. (t.ex "Hej Arduino")

Exempel på variabler med datatyper int, float, char, bool, String.

cpp
// deklarerar och tilldelar ett värde till olika typer av variabler
int ledPin = 13;                    // heltal
float temperatur = 25.5;            // decimaltal 
char tecken = 'A';                  // ett enda tecken
bool status = true;                 // sant eller falskt
String halsning = "Hej Arduino!";   // en sträng eller text

void setup() 
{
    Serial.begin(9600);  // Startar monitorn
    
    Serial.println(halsning);
    Serial.println("ledPin = " + String(ledPin));
    Serial.println("temperatur = " + String(temperatur));
    Serial.println("tecken = " + String(tecken));
    Serial.println("status = " + String(status));
}

void loop() 
{
    // Tom loop eftersom vi bara demonstrerar en gång i setup()
}

Array ​

En array (lista) i Arduino är en samling av variabler av samma datatyp som lagras under ett och samma namn. Istället för att skapa flera enskilda variabler för att lagra flera värden, kan man använda en array för att effektivt hantera och komma åt dessa värden.

  • En array är som en lista av element (variabler/värde), där varje element har en specifik plats, eller index.
  • Alla element (värden) i arrayen har samma datatyp, såsom int, float, char.
  • Indexet för arrayen börjar alltid från 0, vilket betyder att det första elementet i arrayen finns på position 0.

Exempel på int, float, char, bool

cpp
// Deklarera och initiera en array med pinnar för tre lysdioder
//          index =>  0   1   2   
int lysdiodPins[3] = {7, 10, 13}; 

void setup() 
{
    Serial.begin(9600); // Startar monitorn

    Serial.println("lysdiodPin[0] = " + String(lysdiodPins[0]));
    Serial.println("lysdiodPin[1] = " + String(lysdiodPins[1]));
    Serial.println("lysdiodPin[2] = " + String(lysdiodPins[2]));
}

void loop() 
{  
}

Villkorssatser ​

Arduino-villkorssatser används för att fatta beslut i koden. De gör att programmet kan utföra olika saker beroende på om ett villkor är sant eller falskt.

De vanligaste villkorssatserna i Arduino är:

  • if – Om villkoret är sant, körs koden som står under den.
  • else if – Om det första villkoret inte är sant, kollar Python nästa villkor.
  • else – Om inget av de tidigare villkoren är sant, körs den koden.

if () ​

Vad if gör är att ställa frågan om någonting är sant. Om det är sant, då utförs det som följer inom klammer { ... }. Om falskt så händer ingenting.

Exempel

cpp
int value = 7;

void setup() {
  Serial.begin(9600);  // Startar seriell kommunikation

  if (value > 5) {
    Serial.println("Värdet är större än 5.");
  }
}

void loop() {}

Loopar ​

Loopar används för att repetera kodblock.

for(... ; ... ; ...) ​

Denna konstruktion skapar en loop. Det finns 3 stycken fack/satser här:

  • i det första sätter man ett startvärde.
  • i den andra villkoret för att fortsätta och
  • i den tredje vad som skall hända efter att ett varv är avslutat.

Exempel

cpp
void setup() {
  Serial.begin(9600);  // Startar seriell kommunikation

  // Skriv ut värden från 0 till 9
  for (int i = 0; i < 10; i++) {
    Serial.println(i);
    delay(500);  // Vänta 500 ms mellan varje utskrift
  }
}

void loop() {}

while () ​

Ibland vill man att något skall upprepas så länge något är sant. While utför det inom klammer i en evig loop så länge uttrycket inuti while-parenteser är sant.

I detta exempel väntar man på att användaren skriver ett visst antal tecken i den seriella monitorn innan man avslutar loopen

cpp
void setup() 
{
  Serial.begin(9600);  // Startar seriell kommunikation
  Serial.println("Skriv något i den seriella monitorn.");
  Serial.println("När du har skrivit 10 tecken, avslutas loopen.");

  int charCount = 0;  // Variabel för att hålla räkningen av tecken

  while (charCount < 10) 
  {
    if (Serial.available() > 0) {
      char incomingChar = Serial.read();  // Läs det inkommande tecknet
      Serial.println("Du skrev: " + String(incomingChar));
      charCount++;  // Öka teckenräknaren
    }
  }
  Serial.println("Du har skrivit 10 tecken, loopen är klar.");
}

void loop() {}

do ... while () ​

I detta exempel använder man en do-while-loop för att läsa tecken från den seriella monitorn och upprepa utskriften tills användaren skriver bokstaven 'x'. Eftersom det är en do-while-loop, kommer den att köras minst en gång.

Exempel

cpp
void setup() 
{
  Serial.begin(9600);  // Startar seriell kommunikation
  Serial.println("Skriv tecken i den seriella monitorn.");
  Serial.println("Skriv 'x' för att avsluta loopen.");

  char incomingChar;
  do 
  {
    if (Serial.available() > 0) 
    {
      incomingChar = Serial.read();  // Läs det inkommande tecknet
      Serial.print("Du skrev: ");
      Serial.println(incomingChar);
    }
  } while (incomingChar != 'x');  // Fortsätt loopen tills 'x' skrivs

  Serial.println("Du skrev 'x', loopen är klar.");
}

void loop() {}

#define ​

#define är ett nyckelord i Arduino som används för att skapa egna namn eller etiketter för värden eller saker som du ofta använder i din kod. Det kallas också för en makro.

Med #define kan du ge ett namn åt ett värde, så att det blir lättare att läsa och ändra i koden. När programmet körs, byts alla förekomster av namnet ut mot det värde som du har definierat.

Exempel

cpp
#define LED_PIN 13
1

I det här exemplet säger vi att LED_PIN är lika med 13. Det betyder att vi kan använda LED_PIN istället för att skriva siffran 13 varje gång vi vill referera till pinne 13.

Så här använder du det i koden:

Exempel

cpp
#define LED_PIN 13

void setup() {
  pinMode(LED_PIN, OUTPUT);  // Pin 13 används för LED
}

void loop() {
  digitalWrite(LED_PIN, HIGH);  // Tänder LED
  delay(1000);  // Vänta 1 sekund
  digitalWrite(LED_PIN, LOW);   // Släcker LED
  delay(1000);  // Vänta 1 sekund
}

  if (Serial.available() > 0) {

 // Läs/ta bort eventuella radbrytningar
void clearBuffer() {
    while (Serial.available() > 0) {

      if (c == '\n' || c == '\r') {
        continue;    // Ignorera radbrytningarna
      }
    }

    clearBuffer();
  }

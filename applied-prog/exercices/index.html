Övningsuppgifter ​

I dessa övningar ska du utforska viktiga programmeringsbegrepp, såsom:

  • variabler och datatyper, som hjälper dig att lagra och hantera information i dina program,
  • med inmatning och utmatning lär dig att interagera med användaren via sensorer och monitor,
  • villkorssatser används för att fatta beslut baserat på olika förhållanden,
  • for-loopar gör det möjligt att upprepa kodblock ett antal gånger,
  • med arrays för att lagra flera värden i en och samma variabel,
  • och funktioner som gör din kod mer strukturerad och återanvändbar.

1. Variabler och Datatyper ​

I Arduino handlar variabler och datatyper om att lagra och hantera information som din Arduino ska använda för att göra olika saker.

Variabler
En variabel är som en "låda" där du kan lagra information som Arduino kan använda. Du kan ge lådan ett namn och lägga in ett värde i den. Sedan kan du använda värdet i programmet när du behöver det.

Datatyper
En datatyp säger vilken typ av information som ska lagras i variabeln. Det finns olika datatyper beroende på vilken sorts värde du vill spara.
Några vanliga datatyper i Arduino är:

  • int – För heltal (t.ex. 10, -5, 300).
  • float – För decimaler eller flyttal (t.ex. 3.14, 0.5, -2.7).
  • char – För enstaka tecken eller bokstäver (t.ex. 'a', '1', 'B').
  • bool – För värden som bara kan vara sant (true) eller falskt (false).
  • String: för textsträngar.

Uppgifter med lösningar ​

Du ska testa övningsuppgifterna på Tinkercad

  1. Skapa en variabel som heter ledPin och sätt dess värde till 13 (använd int som datatyp).

  2. Skapa en float-variabel som heter temperature och sätt dess värde till 25.5.

  3. Deklarera en boolean-variabel som heter isButtonPressed och sätt den till false.

  4. Skapa två heltalsvariabler, a och b, sätt värdena till 5 respektive 10 och beräkna deras summa i en tredje variabel sum.

  5. Skapa en konstant LED_PIN och sätt dess värde till 7.

Lösningar

cpp
// 1. Skapa en variabel
int ledPin = 13;

// 2. Skapa en float-variabel
float temperature = 25.5;

// 3. Deklarera en boolean-variabel
bool isButtonPressed = false;

// 4. Skapa två heltalsvariabler och beräkna deras summa
int a = 5;
int b = 10;
int sum = a + b;

// 5. Skapa en konstant
const int LED_PIN = 7;

void setup() {
  Serial.begin(9600);

  Serial.println("ledPin = " + String(ledPin));
  Serial.println("temperatur = " + String(temperature));
  Serial.println("isButtonPressed= " + String(isButtonPressed));
  Serial.println("a + b = " + String(sum));
  Serial.println("LED_PIN = " + String(LED_PIN));
}

void loop() {}

2. Utmatning och Inmatning ​

I Arduino handlar "Utmatning" och "Inmatning" om att kommunicera med olika saker, som sensorer och elektroniska komponenter (t.ex. LED-lampor eller motorer).

  • Inmatning (Input): Detta betyder att Arduino får information från omvärlden. Till exempel:

    • En sensor som mäter temperaturen.
    • En knapp som man trycker på.
    • En potentiometer som styr ljusstyrka.
      Arduino får dessa signaler och använder dem för att ta beslut eller reagera på något.

  • Utmatning (Output): Detta betyder att Arduino skickar ut information eller styr något baserat på inmatningen. Till exempel:

    • En LED-lampa som tänds eller släcks.
    • En motor som börjar snurra.
    • En skärm som visar text eller siffror.

Så, sammanfattningsvis:

  • Inmatning = När Arduino får information.
  • Utmatning = När Arduino skickar eller visar information.

Exempel:
Om du trycker på en knapp (inmatning), kan Arduino tända en lampa (utmatning).

  1. Ställ in ett PWM-värde (Pulse Width Modulation) på pin 9 för att kontrollera ljusstyrkan på en LED.

På Arduino kan du generera en PWM-signal med hjälp av funktionen analogWrite(pin, värde), där:

  • pin: är det specifika stiftet som stöder PWM (märkt med ~ på de flesta Arduino-modeller).
  • värde: är ett tal mellan 0 och 255

Lösning:

PWM är ett sätt för Arduino att skapa en slags "falsk" analog signal med digitala utsignaler. Arduino skickar värde som går från 0 (helt AV) till 255 (helt PÅ).

cpp
int ledPin = 9;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  analogWrite(ledPin, 255); // Hel ljusstyrka
  delay(1000);
  analogWrite(ledPin, 128); // Halv ljusstyrka
  delay(1000);
  analogWrite(ledPin, 64);  // en fjärde ljusstyrka
  delay(1000);
  analogWrite(ledPin, 0);   // Släckt LED
  delay(1000);
}

3. Villkorssatser ​

Arduino-villkorssatser används för att fatta beslut i koden. De gör att programmet kan utföra olika saker beroende på om ett villkor är sant eller falskt.

De vanligaste villkorssatserna i Arduino är:

  • if: Om villkoret är sant, körs koden som står under den.

  • else if: Om det första villkoret inte är sant, kollar Python nästa villkor.

  • else: Om inget av de tidigare villkoren är sant, körs den koden.


Uppgifter med lösningar ​

Du ska testa övningsuppgifterna på Tinkercad

  1. Läs in en knapp och skriv ut om den är intryckt eller ej.

Lösning

cpp
int buttonPin = 2;

void setup() {
  pinMode(buttonPin, INPUT);
  Serial.begin(9600);
}

void loop() {
  if (digitalRead(buttonPin) == HIGH) {
    Serial.println("Knappen intryck");
  } else {
    Serial.println("Kanppen INTE intryck");
  }
  delay(500);
}

4. For-loopar ​

En for-loop i Arduino (och i programmering generellt) är en kontrollstruktur som används för att upprepa en kodsnutt ett bestämt antal gånger. Den är mycket användbar när du vet på förhand hur många gånger en uppgift ska utföras.

En for-loop i Arduino har följande syntax:

cpp
for (initiering; villkor; uppdatering) {
  // Kod att köra vid varje iteration
}


1
2
3

Förklaring:

  • Initiering: Detta är den första operationen som körs innan loopen startar. Vanligtvis används den för att sätta en räknare (t.ex. int i = 0).
  • Villkor: Detta är ett uttryck som utvärderas innan varje iteration av loopen. Om det är sant, fortsätter loopen att köras. Om det är falskt, avslutas loopen. Vanligtvis kontrollerar detta om räknaren har nått ett visst värde.
  • Uppdatering: Detta är en operation som körs efter varje iteration, och används ofta för att ändra räknaren (t.ex. i++ för att öka värdet av i med 1).

Uppgifter med lösningar ​

Du ska testa övningsuppgifterna på Tinkercad

  1. Blinka en LED 10 gånger med hjälp av en for-loop.

Lösning

cpp
int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
  
  for (int i = 0; i < 10; i++) {
    digitalWrite(ledPin, HIGH);
    delay(500);
    digitalWrite(ledPin, LOW);
    delay(500);
  }
}

void loop() {}

5. Arrays (Listor) ​

En array (lista) i Arduino är en samling av variabler av samma datatyp som lagras under ett och samma namn. Istället för att skapa flera enskilda variabler för att lagra flera värden, kan man använda en array för att effektivt hantera och komma åt dessa värden.

  • En array är som en lista av element (variabler/värde), där varje element har en specifik plats, eller index.
  • Alla element (värden) i arrayen har samma datatyp, såsom int, float, char.
  • Indexet för arrayen börjar alltid från 0, vilket betyder att det första elementet i arrayen finns på position 0.

Du ska testa övningsuppgifterna på Tinkercad

      digitalWrite(ledPins[i], LOW);
    }
  }
}

void loop() {}

  1. Ändra värdena i en array med hjälp av en loop.

Lösning

cpp
int ledPins[] = {2, 3, 4, 5};       // LED-pinnar
bool ledStatus[] = {true, false, true, false}; // Array med status

void setup() {
  for (int i = 0; i < 4; i++) {
    pinMode(ledPins[i], OUTPUT);
    digitalWrite(ledPins[i], ledStatus[i] ? HIGH : LOW);
  }
}

void loop() {
  // Vänta 1 sekund innan status ändras
  delay(1000);

  // Ändra varje värde i ledStatus arrayen
  for (int i = 0; i < 4; i++) {
    ledStatus[i] = !ledStatus[i]; // Vänd statusen för varje LED
    digitalWrite(ledPins[i], ledStatus[i] ? HIGH : LOW); // Uppdatera LED
  }
}

6. Funktioner ​

  • Funktioner är kodblock (instruktioner) som gör en speciell uppgift.
  • De anropas från andra delar av programmet.
  • De används för att undvika att skriva samma kod flera gånger.

När du använder funktioner slipper du skriva samma kod flera gånger. Istället kan du bara "anropa" (säga till) funktionen att göra jobbet för dig när du behöver det.

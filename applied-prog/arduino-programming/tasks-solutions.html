Övningsuppgifter ​

Här är fem enkla övningar för varje begrepp inom Arduinos programmering.

1. Variabler och Datatyper ​

Övningar: ​

  1. Skapa en variabel som heter ledPin och sätt dess värde till 13 (använd int som datatyp).

  2. Skapa en float-variabel som heter temperature och sätt dess värde till 25.5.

  3. Deklarera en boolean-variabel som heter isButtonPressed och sätt den till false.

  4. Skapa två heltalsvariabler, a och b, sätt värdena till 5 respektive 10 och beräkna deras summa i en tredje variabel sum.

  5. Skapa en konstant LED_PIN och sätt dess värde till 7.

Lösningar: ​

cpp
// 1. Skapa en variabel
int ledPin = 13;


// 2. Skapa en float-variabel
float temperature = 25.5;


// 3. Deklarera en boolean-variabel
bool isButtonPressed = false;


// 4. Skapa två heltalsvariabler och beräkna deras summa
int a = 5;
int b = 10;
int sum = a + b;


// 5. Skapa en konstant
const int LED_PIN = 7;

2. Utmatning och Inmatning ​

Övningar: ​

  1. Sätt upp en LED på pin 13 som du kan tända och släcka i koden.

  2. Läs ett värde från en knapp ansluten till pin 2.

  3. Använd analogRead för att läsa värdet från en potentiometer kopplad till analog pin A0.

  4. Använd Serial.print för att skriva "Hello, Arduino!" till Serial Monitor.

Lösningar: ​

cpp
// 1. Sätt upp en LED på pin 13
int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
  digitalWrite(ledPin, HIGH); // Tänd LED
  delay(1000); // Vänta 1 sekund
  digitalWrite(ledPin, LOW);  // Släck LED
}


// 2. Läs ett värde från en knapp på pin 2
int buttonPin = 2;

void setup() {
  pinMode(buttonPin, INPUT);
  int buttonState = digitalRead(buttonPin);
}


// 3. Använd analogRead för att läsa från A0
int potPin = A0;
int potValue;

void setup() {
  Serial.begin(9600);
}

void loop() {
  potValue = analogRead(potPin);
  Serial.println(potValue);
  delay(500);
}


// 4. Använd Serial.print
void setup() {
  Serial.begin(9600);
  Serial.print("Hello, Arduino!");
}

void loop() {
  // Tomt
}

3. Villkorssatser ​

Övningar: ​

  1. Läs in en knapp och skriv ut om den är intryckt eller ej.

  2. Läs ett potentiometer-värde och tänd en LED om värdet är över 512.

  3. Använd ett villkor för att kontrollera om en variabel temperature är över 30, och skriv ut "Hot!" om så är fallet.

  4. Kombinera två villkor för att kolla om både a är större än 5 och b är mindre än 10.

  5. Använd else if för att skriva ut olika meddelanden beroende på lightLevel variabelns värde.

Lösningar: ​

cpp
// 1. Läs en knapp och skriv ut om den är intryckt eller ej
int buttonPin = 2;

void setup() {
  pinMode(buttonPin, INPUT);
  Serial.begin(9600);
}

void loop() {
  if (digitalRead(buttonPin) == HIGH) {
    Serial.println("Button pressed");
  } else {
    Serial.println("Button not pressed");
  }
  delay(500);
}


// 2. Läs ett potentiometer-värde och tänd LED om över 512
int potPin = A0;
int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  int potValue = analogRead(potPin);
  if (potValue > 512) {
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
}


// 3. Kontrollera om temperature är över 30
float temperature = 32.5;

void setup() {
  Serial.begin(9600);
  if (temperature > 30) {
    Serial.println("Hot!");
  }
}


// 4. Kombinera två villkor
int a = 6;
int b = 8;

void setup() {
  if (a > 5 && b < 10) {
    Serial.println("Condition met!");
  }
}


// 5. Använd else if för olika ljusnivåer
int lightLevel = 600;

void setup() {
  Serial.begin(9600);
  if (lightLevel > 800) {
    Serial.println("Very bright");
  } else if (lightLevel > 500) {
    Serial.println("Bright");
  } else {
    Serial.println("Dim");
  }
}

4. For-loopar ​

Övningar: ​

  1. Blinka en LED 10 gånger med hjälp av en for-loop.

  2. Räkna uppåt från 1 till 5 och skriv ut varje siffra till Serial Monitor.

  3. Använd en for-loop för att ändra PWM värdet på en LED från 0 till 255.

  4. Skapa en loop som räknar ner från 10 till 0.

  5. Läs från en array och skriv ut varje värde till Serial Monitor.

Lösningar: ​

cpp
// 1. Blinka en LED 10 gånger
int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
  for (int i = 0; i < 10; i++) {
    digitalWrite(ledPin, HIGH);
    delay(500);
    digitalWrite(ledPin, LOW);
    delay(500);
  }
}


// 2. Räkna upp från 1 till 5
void setup() {
  Serial.begin(9600);
  for (int i = 1; i <= 5; i++) {
    Serial.println(i);
  }
}


// 3. Ändra PWM-värdet på en LED
int ledPin = 9;

void setup() {
  pinMode(ledPin, OUTPUT);
  for (int i = 0; i <= 255; i++) {
    analogWrite(ledPin, i);
    delay(10);
  }
}


// 4. Räkna ner från 10 till 0
void setup() {
  Serial.begin(9600);
  for (int i = 10; i >= 0; i--) {
    Serial.println(i);
    delay(500);
  }
}


// 5. Läs från en array och skriv ut varje värde
int numbers[] = {10, 20, 30, 40, 50};

void setup() {
  Serial.begin(9600);
  for (int i = 0; i < 5; i++) {
    Serial.println(numbers[i]);
  }
}

5. Arrays (Listor) ​

Övningar: ​

  1. Skapa en array med heltalen 5, 10, 15, 20.

  2. Använd en for-loop för att skriva ut alla värden i en array.

  3. Beräkna summan av alla värden i en array.

  4. Skapa en array med booleans som indikerar om en LED är på eller av.

  5. Ändra värdena i en array med hjälp av en loop.

Lösningar: ​

cpp
// 1. Skapa en array
int numbers[] = {5, 10, 15, 20};


// 2. Använd en for-loop för att skriva ut alla värden
void setup() {
  Serial.begin(9600);
  for (int i = 0; i < 4; i++) {
    Serial.println(numbers[i]);
  }
}



// 3. Beräkna summan av alla värden i en array
int sum = 0;
void setup() {
  for (int i = 0; i < 4; i++) {
    sum += numbers[i];
  }
  Serial.println(sum);
}



// 4. Skapa en array med booleans som indikerar om en LED är på eller av.

// Anta att vi har fyra LED-lampor anslutna till pinnar 2, 3, 4 och 5.
int ledPins[] = {2, 3, 4, 5}; // LED-pinnar
bool ledStatus[] = {true, false, true, false}; // Array med status (på eller av)

void setup() {
  // Sätt upp LED-pins som utgångar
  for (int i = 0; i < 4; i++) {
    pinMode(ledPins[i], OUTPUT);
    // Ställ in varje LED efter dess status i ledStatus-arrayen
    digitalWrite(ledPins[i], ledStatus[i] ? HIGH : LOW);
  }
}

void loop() {
  // Inga åtgärder i loop
}



// 5. Ändra värdena i en array med hjälp av en loop.

int ledPins[] = {2, 3, 4, 5};       // LED-pinnar
bool ledStatus[] = {true, false, true, false}; // Array med status

void setup() {
  for (int i = 0; i < 4; i++) {
    pinMode(ledPins[i], OUTPUT);
    digitalWrite(ledPins[i], ledStatus[i] ? HIGH : LOW);
  }
}

void loop() {
  // Vänta 1 sekund innan status ändras
  delay(1000);

  // Ändra varje värde i ledStatus arrayen
  for (int i = 0; i < 4; i++) {
    ledStatus[i] = !ledStatus[i]; // Vänd statusen för varje LED
    digitalWrite(ledPins[i], ledStatus[i] ? HIGH : LOW); // Uppdatera LED
  }
}

6. Funktioner ​

Övningar: ​

  1. Skapa en funktion som tänder en LED ansluten till en specifik pin. Anropa funktionen i loop.

  2. Skapa en funktion som räknar ut summan av två tal och returnerar resultatet. Skriv ut summan i loop.

  3. Skapa en funktion som blinkar en LED ett antal gånger som du skickar in som argument.

  4. Skapa en funktion som kontrollerar om en temperatur är över 30 grader och returnerar true om det är sant, annars false.

  5. Skapa en funktion som tar emot ett PWM-värde som parameter och styr ljusstyrkan på en LED baserat på detta värde.

Lösningar: ​

cpp
// 1. Funktion som tänder en LED på en viss pin
void turnOnLED(int pin) {
  pinMode(pin, OUTPUT);
  digitalWrite(pin, HIGH); // Tänd LED
}

void setup() {
  turnOnLED(13); // Tänd LED på pin 13
}

void loop() {
  // Tomt
}


// 2. Funktion som räknar ut summan av två tal
int add(int a, int b) {
  return a + b;
}

void setup() {
  Serial.begin(9600);
  int sum = add(5, 10); // Beräkna summan av 5 och 10
  Serial.println(sum);   // Skriv ut summan i Serial Monitor
}

void loop() {
  // Tomt
}


// 3. Funktion som blinkar en LED ett antal gånger
void blinkLED(int pin, int times) {
  pinMode(pin, OUTPUT);
  for (int i = 0; i < times; i++) {
    digitalWrite(pin, HIGH); // Tänd LED
    delay(500);
    digitalWrite(pin, LOW);  // Släck LED
    delay(500);
  }
}

void setup() {
  blinkLED(13, 5); // Blinka LED på pin 13 fem gånger
}

void loop() {
  // Tomt
}


// 4. Funktion som kontrollerar om temperaturen är över 30 grader
bool isHot(float temperature) {
  return temperature > 30;
}

void setup() {
  Serial.begin(9600);
  float temp = 32.5;
  if (isHot(temp)) {
    Serial.println("It's hot!");
  } else {
    Serial.println("It's not hot.");
  }
}

void loop() {
  // Tomt
}


// 5. Funktion som tar emot ett PWM-värde och styr ljusstyrkan på en LED
void setLEDBrightness(int pin, int brightness) {
  pinMode(pin, OUTPUT);
  analogWrite(pin, brightness); // Sätt ljusstyrkan på LED
}

void setup() {
  // Sätt ljusstyrkan på LED på pin 9 till halvljus (128)
  setLEDBrightness(9, 128);
}

void loop() {
  // Tomt
}

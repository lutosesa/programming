Laboration: Temperatur Sensor ​

Inledning ​

En temperatursensor (TMP36 ) i Arduino är en liten elektronisk komponent som mäter temperaturen och skickar den informationen till Arduino-kortet. Den kan känna av hur varmt eller kallt det är och omvandla det till en signal som Arduino kan läsa av.
I detta labb kommer vi att visa temperaturen i den seriella monitorn på Arduino IDE.

Syfte med labbet ​

Du kommer att lära dig om:

  • hur man kopplar in en temperatursensor i en krets.
  • hur konstanta variabler deklareras, tilldelas och används.
  • hur används de huvudfunktionerna och skapar egna funktioner.
  • Hur man mäter spänningen vi det analoga stiftet.
  • Hur man omvandlar spänningen till Celsiusgrader.
  • Hur man omvandlar Celsiusgrader till Fahrenheit
  • hur man kan styra dess elektronisk komponent genom att koda fram en algoritm på utvecklingsmiljön Arduino IDE.

Vad är TMP36 temperatursensor? ​

En TMP36 är en temperatursensor som används med Arduino för att mäta temperatur. Den är enkel att använda och ger en analog signal som motsvarar temperaturen i Celsius.

Viktiga egenskaper: ​

  • Analog sensor: TMP36 skickar ut en spänning (analog signal) som Arduino kan läsa av och omvandla till en temperatur.
  • Temperaturområde: Den kan mäta temperaturer från -40°C till +125°C.
  • Enkel anslutning: TMP36 har tre ben:
    • VCC – kopplas till ström (vanligtvis 5V eller 3.3V).
    • GND – kopplas till jord (GND på Arduino).
    • VOUT – skickar ut en spänning som motsvarar temperaturen, och denna signal läses av en analog ingång på Arduino.

Hur den fungerar med Arduino: ​

TMP36 utgångsspänning ökar med temperaturen. Till exempel, vid 0°C ger den cirka 0,5V, och för varje grad Celsius ökar spänningen med 10mV (0,01V). Arduino läser denna spänning och räknar om det till en temperatur.

Exempel på användning: ​

Genom att koppla TMP36 till en analog pinne på Arduino kan du skriva en enkel kod för att läsa av temperaturen och använda den i olika projekt, till exempel för att skapa en termometer eller temperaturstyrda system.

Elektroniska delar som behövs ​

  • (1) Arduino Uno
  • (1) USB A-to-B kabel
  • (1) Kopplingsplatta
  • (1) Temperatur Sensor – TMP36
  • (3) Lysdioder
  • (3) resistorer 220 Ω
  • sladdar

Övning 1: Temperaturmätning ​

Denna övning går ut på att mäta temperuturen med hjälp av en TMP36-sensorn och sedan konvertera det analoga värdet till spänning, grader Celsius och Fahrenheit.Syfte med övningen är att läsa och beräkna temperaturen från sensorn samt visa dessa värden via seriell monitorn.

Kopplings ritning ​

Programkod ​

cpp
/******************************************************
* Laboration 6 - övning 1 
* Temperaturmätning med temperatur-sensorn TMP36 
******************************************************/

int sensorPin = A0;  // TMP36 är kopplad till analog pin A0
float voltage, degreesCelsius, degreesFahrenheit;

void setup()
{
   Serial.begin(9600);   // Starta seriell kommunikation
}

void loop()
{

   int sensorValue = analogRead(sensorPin);  // Läs analogt värde
   voltage = sensorValue * (5.0 / 1023.0);   // Omvandla värdet till spänning

   degreesCelsius = (voltage - 0.5) * 100.0;  // Omvandlar spänningen till grader Celsius

   // Onvandlar grader Celsius till Fahrenheit
   degreesFahrenheit = degreesCelsius * (9.0 / 5.0) + 32.0;
   
   Serial.print("voltage: " + String(voltage));
   Serial.print("  degrees celsius: " + String(round(degreesCelsius)) );
   Serial.println("  degrees Fahrenheit: " + String(round(degreesFahrenheit)));

   delay(1000); //upprepa en gång per sekund (ändra som du vill!) 
}

Förklaring av programmet: ​

  1. Anslutning av TMP36-sensorn:

    • TMP36-temperatursensorn är ansluten till Arduino på den analoga ingången A0.

  2. Variabler:

    • Tre decimaltalsvariabler (datatypen float) används för att lagra:
      • voltage : Sensorns spänning.
      • degreesCelsius : Temperaturen i Celsius.
      • degreesFahrenheit : Temperaturen i Fahrenheit.

  3. Setup-funktionen:

    • Serial.begin(9600); : Startar seriell kommunikation med en baud rate på 9600, vilket gör det möjligt att skicka data från Arduino till en dator och visa resultaten i Arduino IDE serielmonitor.

  4. Loop-funktionen:

    • Läsning av sensorvärde:
      • analogRead(sensorPin); : Läser det analoga värdet från TMP36-sensorn (som omvandlas till en spänning mellan 0 och 5 V beroende på temperaturen).
    • Beräkning av spänning:
      • voltage = sensorValue * (5.0 / 1023.0); : Omvandlar det analoga värdet till en motsvarande spänning (Arduino har 10-bitars upplösning, vilket ger värden mellan 0 och 1023).
    • Beräkning av temperatur i Celsius:
      • degreesCelsius = (voltage - 0.5) * 100.0; : TMP36 genererar 0,5 V vid 0°C och ökar med 10 mV per grad Celsius, så här omvandlas spänningen till grader Celsius.
    • Beräkning av temperatur i Fahrenheit:
      • degreesFahrenheit = degreesCelsius * (9.0 / 5.0) + 32.0; : Omvandlar temperaturen från Celsius till Fahrenheit med hjälp av den standardiserade formeln.
    • Seriell utskrift:
      • Programmet skriver ut spänningen, temperaturen i Celsius och Fahrenheit till serielmonitorn så att användaren kan se mätningarna i realtid.

  5. Fördröjning:

    • delay(1000); : Programmet pausar i en sekund innan det läser sensorn och skriver ut värdena igen, vilket innebär att temperaturdata uppdateras var sekund.

Övning 2: ett enkelt temperaturlarm ​

Vi ska skapa ett program som fungerar som ett enkelt temperaturlarm, där tre LED-lampor och ljud indikerar olika temperaturtrösklar.

Ja, vi använder tre lysdioder, som tänds i olika kombinationer beroende på om temperaturen överstiger vissa tröskelvärden och en buzzer som avger ett ljud när det blir för varmt. Detta ger oss en visuell och hörbar indikation av temperaturen.

Kopplings ritning ​

Programkod ​

cpp
/*************************************************************
* Laboration 6 - övning 2 
* Programmet fungerar som ett enkelt temperaturlarm, 
* där LED-lampor och ljud indikerar olika temperaturtrösklar.
**************************************************************/
// Definiera analog pin för temperaturgivaren (LM35)
int sensorPin = A0;

// Definiera buzzer pinne
int buzzerPin = 12;

// Definiera  LED-pinnar
int redPin4 = 4;
int redPin3 = 3;
int redPin2 = 2;

int startTemperature = 20; 
int averageTemperature = 30; 
int hightemperature = 40;
int shortTimer = 300;
int longTimer = 1500;

float voltage, degreesCelsius;

void setup()
{
   Serial.begin(9600);   // Starta seriell kommunikation
      
   // Sätt LED-pinnarna som utgångar
   pinMode(redPin4, OUTPUT);
   pinMode(redPin3, OUTPUT);
   pinMode(redPin2, OUTPUT);

   // Sätt buzzer pin som utgång
   pinMode(buzzerPin, OUTPUT);
}

void loop()
{  
   int sensorValue = analogRead(sensorPin); // Läs analogt värde
   voltage = sensorValue * (5.0 / 1023.0);  // Omvandla värdet till spänning

   degreesCelsius = (voltage - 0.5) * 100.0;  // Omvandlar spänningen till grader Celsius
      
   // Skriver ut värdena i seriellmonitor  
   Serial.print("Volts: " + String(voltage));
   Serial.println(", degrees Celsius: " + String(round(degreesCelsius)));

   turnOnLEDsBasedOnTemperature(degreesCelsius);  
   delay(1000);
} 

void turnOnLEDsBasedOnTemperature(float temperature) {
   if( temperature <= startTemperature) {
      turnOnLED(LOW, LOW,LOW);
   }
   else if( temperature > startTemperature && temperature <= averageTemperature) { 
     playSoundAlarm(10); 
     turnOnLED(HIGH, LOW,LOW);     
   }
   else if( temperature > averageTemperature && temperature <= hightemperature) 
   {
      playSoundAlarm(100);
      turnOnLED(HIGH, HIGH,LOW); 
   }
   else if( temperature > hightemperature )
   {
      playSoundAlarm(1000);
      turnOnLED(HIGH, HIGH, HIGH); 
   }
}

void turnOnLED(int state4, int state3, int state2) {
   digitalWrite(redPin4, state4);
   digitalWrite(redPin3, state3);
   digitalWrite(redPin2, state2);
}

void playSoundAlarm(int note) {
   tone(buzzerPin, note); //Skapar en ton(ljud)
   delay(longTimer);
   noTone(buzzerPin);    //stänger av ljudet.
   delay(shortTimer);
}

Förklaring av vissa delar av programmet: ​

Variabler:

  • sensorPin: Definierar den analoga pinnen (A0) där TMP36-sensorn är ansluten.
  • buzzerPin: Definierar pinnen (12) som är ansluten till en buzzer för ljud.
  • startTemperature, averageTemperature, hightemperature: Dessa är gränsvärden för temperaturer (i grader Celsius) som används för att bestämma när LED-lamporna ska tändas och när larmet ska ljudas.
  • shortTimer och longTimer: Tidsintervall (i millisekunder) som styr hur länge ljudet från buzzern ska vara på eller av.
  • voltage och degreesCelsius: Variabler för att lagra spänningen (i volt) som omvandlas från sensorvärdet, samt den beräknade temperaturen i grader Celsius.

Setup-funktionen:

  • Serial.begin(9600) : Startar seriell kommunikation med en baudrate på 9600 för att skicka data till datorn, exempelvis för att visa temperaturvärden i serial monitor.

  • pinMode() och digitalWrite(): Sätter upp tre digitala pinnar (2, 3 och 4) som utgångar och stänger av dem initialt genom att sätta dem på LOW (av).

Loop-funktionen:

  • analogRead(sensorPin) : Läser det analoga värdet från TMP36-sensorn som är ansluten till pinne A0. Detta ger ett värde mellan 0 och 1023.
  • voltage = sensorValue * (5.0 / 1023.0) : Omvandlar sensorvärdet till en spänning (mellan 0 och 5 volt), eftersom Arduino använder en 10-bitars ADC (Analog-to-Digital Converter) för att läsa analoga värden.
  • degreesCelsius = (voltage - 0.5) * 100.0 : TMP36-sensorn ger ett spänning mellan 0.5V (vid 0°C) och 1.5V (vid 100°C), så denna formel omvandlar spänningen till en temperatur i Celsius.

Temperaturhantering:
Programmet delar in temperaturen i olika intervall och styr LED-lamporna och buzzern baserat på dessa värden:

  • Om temperaturen är mindre än eller lika med startTemperature (20°C):
    • Alla LED-lampor (4, 3, 2) stängs av (LOW).
  • Om temperaturen är mellan startTemperature och averageTemperature (30°C):
    • Endast LED 4 tänds för att indikera en måttlig temperatur.
  • Om temperaturen är mellan averageTemperature och hightemperature (40°C):
    • LED 4 och LED 3 tänds, och en kort ljudsignal spelas upp från buzzern.
  • Om temperaturen är över hightemperature (40°C):
    • Alla tre LED-lampor tänds och en högre ljudsignal spelas från buzzern.

Ljudhantering:

  • playSoundAlarm(int note) : Den här funktionen styr buzzern. När temperaturen når ett visst tröskelvärde spelas en ton med en viss frekvens (note) på buzzern. Sedan stängs ljudet av och pausas för en kort period.

Övning 3: Temperaturlarm med RGB-lysdiod ​

Vi skapar samma program som föregående, temperaturlarm, men med en RGB-lysdiod istället som indikerar olika temperaturtrösklar.

Ja, vi använder en RGB-lysdiod, som tänds i olika kombinationer beroende på om temperaturen överstiger vissa tröskelvärden och en buzzer som avger ett ljud när det blir för varmt. Detta ger oss en visuell och hörbar indikation av temperaturen.

Kopplings ritning ​

Programkod ​

cpp
/******************************************************
* Laboration 6 - övning 3 
* Programmet fungerar som ett enkelt temperaturlarm, 
* där en RGP-lysdiod och ljud indikerar olika 
* temperaturtrösklar.
******************************************************/
int startTemperature   = 20; 
int averageTemperature = 30; 
int highTemperature    = 40;
int shortTimer =  300;
int longTimer  = 1500;

// Deklarerar volt och temperatur som float-datatyp.
float voltage, temperature;

// Definiera RGB LED-pinnar
int redPin   = 6;
int greenPin = 3;
int bluePin  = 5;

// Definiera buzzer pinne
int buzzerPin = 12;

// Definiera analog pin för temperaturgivaren (LM35)
int tempPin = A0;

void setup() {
  // Sätt RGB LED-pinnarna som utgångar
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);

  // Sätt buzzer pin som utgång
  pinMode(buzzerPin, OUTPUT);

  // Sätt upp seriell kommunikation för att skriva ut temperatur
  Serial.begin(9600);
}

void loop() {
  // Läs temperatur från LM35 (värdet kommer att vara mellan 0-1023)
  int sensorValue = analogRead(tempPin);
  
  // Omvandla den analoga värdet till temperatur (Celsius)
  voltage = sensorValue * (5.0 / 1023.0);  // Omvandla till spänning
  temperature = (voltage - 0.5) * 100.0;   // Omvandla till Celsius för LM35
  
  // Skriv temperatur till seriell monitor för felsökning
  Serial.println("Temperatur: " + String(round(temperature)) + " C");

  // Temperaturbaserad färgändring och ljudsignal
  setColorBasedOnTemperature(temperature);

  delay(100); // Fördröjning mellan varje iteration
}


void setColorBasedOnTemperature(float temp) {
  if (temp < startTemperature) {
    // Lagom temperatur, blå färg
    setRGB(0, 0, 255);
  } 
  else if (temp >= startTemperature && temp < averageTemperature) {
    // Milt temperatur, grön färg
    setRGB(0, 255, 0);
    playSoundAlarm(100);
  } 
  else if (temp >= averageTemperature && temp < highTemperature) {
    // hög temperatur gul färg
    setRGB(255, 255, 0);
    playSoundAlarm(500);
  } 
  else {
    // Välidigt hög temperatur, röd färg
    setRGB(255, 0, 0);
    playSoundAlarm(1200);
  }
}


// Funktion för att sätta RGB LED-färg
void setRGB(int red, int green, int blue) {
  analogWrite(redPin, red);
  analogWrite(greenPin, green);
  analogWrite(bluePin, blue);
}


// Funktion för att spela upp ljudsignal
void playSoundAlarm(int note){
  tone(buzzerPin, note); //Skapar en ton(ljud)
  delay(longTimer);
  noTone(buzzerPin);    //stänger av ljudet.
  delay(shortTimer);
}

Laboration: Fototransistor ​

Inledning ​

I detta labb kommer vi att koppla till Arduino Uno en fototransistor (ljussensor) och använda den seriella monitorn för att lära oss hur ljussensorn beter sig, sedan bygger vi en krets som automatiskt tänder ett ljus när det blir mörkt.

Syfte med labbet ​

Du kommer att lära dig om:

  • Hur man använder en ljussensor
  • hur man kan styra dessa elektroniska komponenter genom att koda fram en algoritm på utvecklingsmiljön Arduino IDE.
  • hur används de huvudfunktionerna, funktioner som ingår i programmet och skapa och anropa funktioner.

Vad är en fototransistor? ​

En fototransistor i Arduino är en sensor som mäter ljus. Den fungerar ungefär som ett öga för Arduino, eftersom den känner av hur mycket ljus som faller på den.

Hur fungerar en fototransistor? ​

  • Fototransistorn släpper igenom mer ström när det finns mycket ljus och mindre ström när det är mörkt.
  • Den är ansluten till en analog pin på Arduino (t.ex. A0), som kan läsa av ljusnivån som ett värde. Detta värde kan variera beroende på hur starkt ljuset är.

I ett Arduino-projekt kan du använda en fototransistor för att göra något beroende på ljuset, som att tända en lampa när det blir mörkt eller styra en motor när ljuset ändras.

Övning 1 ​

Vi ska undersöka hur en fototransistor fungerar och beter sig genom att läsa ljusstyrkan från fototransistorn ansluten till analog pinne A0, och beroende på ljusstyrkan klassificeras omgivningen som "Dark", "Dim", "Light", "Bright", eller "Very bright". Värdet skrivs både som ett numeriskt resultat och som en textklassificering i den seriella monitorn.

Kopplings ritning ​

Programkod ​

cpp
/*********************************************
* Laboration 7 - Övning 1 - Fototransistor
**********************************************/
int photoTransistorPin = A0;

void setup() {
  Serial.begin(9600);  // Startar monitorn
}

void loop() {
  // läser ingången på analog pinne A0
  int lightValue = analogRead(photoTransistorPin);

  // Skriv ut värdena som ska läsas i monitorn
  Serial.print("LightValue : ");
  Serial.print(lightValue);

  //Använd värdet för att avgöra hur mörkt det är
  // (Försök att justera dessa för att göra det mer exakt)
  if (lightValue < 250) {
    Serial.println(" - Dark");
  } 
  else if (lightValue < 500) {
    Serial.println(" - Dim");
  } 
  else if (lightValue < 700) {
    Serial.println(" - Light");
  } 
  else if (lightValue < 950) {
    Serial.println(" - Bright");
  } 
  else {
    Serial.println(" - Very bright");
  }
  
  delay(500);
}

Hur programmet fungerar: ​

  1. Deklaration av variabel:
    Här deklareras en variabel photoTransistorPin och sätts till A0. Detta innebär att den analoga ingången A0 används för att läsa signalen från fototransistorn, som ska vara ansluten till denna pinne.

  2. Setup-funktionen:
    I setup()-funktionen initieras seriell kommunikation med datorn med hjälp av Serial.begin(9600), vilket gör att vi kan skicka och ta emot data från datorn via USB-kabeln. Baudrate (överföringshastighet) sätts till 9600 bitar per sekund. Detta gör det möjligt att visa data i den seriella monitorn.

  3. Loop-funktionen:
    I loop()-funktionen sker själva mätningen och datautskriften. Denna funktion körs om och om igen så länge Arduino är påslagen.

    • Läsa fototransistorvärdet:
      Här läses värdet från den analoga pinnen A0, där fototransistorn är ansluten. analogRead() returnerar ett värde mellan 0 och 1023, där 0 motsvarar ingen ljusinsläpp (mörkt) och 1023 motsvarar maximal ljusstyrka (mycket ljust).

    • Skriva ut ljusvärdet:
      Dessa rader skickar ut ljusvärdet till den seriella monitorn, vilket gör att vi kan se det numeriska värdet som fototransistorn registrerar.

    • Klassificering av ljusnivåer:
      Sedan följer en serie if-satser som klassificerar ljusnivån baserat på det lästa värdet: Programmet delar upp ljusvärdena i fem kategorier:

      • Mörkt (Dark): Om värdet är under 250.
      • Dämpat ljus (Dim): Om värdet är mellan 250 och 500.
      • Ljust (Light): Om värdet är mellan 500 och 700.
      • Mycket ljust (Bright): Om värdet är mellan 700 och 950.
      • Extremt ljust (Very bright): Om värdet är över 950.

      Detta gör att användaren kan se ett ord som beskriver ljusstyrkan i omgivningen, förutom det numeriska värdet.

    • Fördröjning:
      delay(500) introducerar en paus på 500 millisekunder (0,5 sekunder) innan programmet gör om samma mätning och utskrift. Detta gör att data inte skrivs ut för snabbt och gör det enklare att läsa i den seriella monitorn.

Övning 2 ​

Vi ska ansluta en fototransistor (ljussensor) och en RGB-lysdiod. Vi skapar ett program som läser ljusstyrkan från fototransistorn och baserat på ljusnivån ändrar det färgen på RGB-lysdioden. Ljusnivån klassificeras i fem olika kategorier: mörkt, dimt, ljust, mycket ljust och extremt ljust. Varje kategori motsvarar en viss färg på lysdioden (blå, grön, gul eller röd). Samtidigt skrivs ljusvärdet och den tillhörande kategorin ut på den seriella monitorn.

Kopplings ritning ​

Programkod ​

cpp
/*********************************************
* Laboration 7 - Övning 2 - Fototransistor
**********************************************/
int photoTransistorPin = A0;

// Definiera RGB LED-pinnar
int redPin   = 9;
int greenPin = 10;
int bluePin  = 11;

void setup() {
  // Startar monitorn
  Serial.begin(9600);
  
  // Sätt RGB LED-pinnarna som utgångar
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);
}

void loop() {
  // läser ingången på analog pinne A0
  int lightValue = analogRead(photoTransistorPin);

  // Skriv ut värdena som ska läsas i monitorn
  Serial.print("LightValue : ");
  Serial.print(lightValue);

  //Använd värdet för att avgöra hur ljus det är
  if (lightValue < 250) {
    Serial.println(" - Dark");
    setRGB(0, 255, 0);
  } 
  else if (lightValue < 500) {
    Serial.println(" - Dim");
    setRGB(0, 0, 255);
  } 
  else if (lightValue < 700) {
    Serial.println(" - Light");
    setRGB(0, 255, 255);
  } 
  else if (lightValue < 950) {
    Serial.println(" - Bright");
    setRGB(255, 255, 0);
  } 
  else {
    Serial.println(" - Very bright");
    setRGB(255, 0, 0);
  }
  
  delay(500);
}

// Funktion för att sätta RGB LED-färg
void setRGB(int redValue, int greenValue, int blueValue) {
  analogWrite(redPin, redValue);
  analogWrite(greenPin, greenValue);
  analogWrite(bluePin, blueValue);
}

Hur programmet fungerar: ​

  1. Deklaration av variabler:
    Här deklareras variabeln photoTransistorPin, som används för att referera till den analoga ingången A0, där fototransistorn är ansluten.

    RGB-lysdiod-pinnar:
    Dessa variabler deklarerar de digitala pinnen (9, 10 och 11) som är anslutna till de röda, gröna respektive blå LED-anoderna på RGB LED

  2. Setup-funktionen:

    • Serial.begin(9600) startar seriell kommunikation vid 9600 baud för att kunna skriva ut data till den seriella monitorn.
    • pinMode(redPin, OUTPUT), pinMode(greenPin, OUTPUT), och pinMode(bluePin, OUTPUT) ställer in de digitala pinne 9, 10 och 11 som utgångar, så att vi kan styra färgerna på RGB LED

  3. Loop-funktionen:
    I loop()-funktionen sker själva ljusmätningen och färgändringen baserat på ljusnivån från fototransistorn.

    • Läsa ljusvärde från fototransistorn:
      Här läses ett värde från den analoga pinnen A0, där fototransistorn är ansluten. analogRead() returnerar ett värde mellan 0 och 1023, där 0 innebär totalt mörker och 1023 innebär maximalt ljus.

    • Skriva ut ljusvärde:
      Dessa rader skickar ljusvärdet till den seriella monitorn så att användaren kan se det numeriska värdet som läses från fototransistorn.

    • Baserat på ljusvärdet sätts olika färger på RGB LED:en:
      Här görs en klassificering av ljusnivån med hjälp av en serie if-satser:

      • Om ljusvärdet är mindre än 250 sätts färgen på RGB LED till blå (setRGB(0, 0, 255)), och meddelandet "Dark" skrivs ut.
      • Om ljusvärdet är mellan 250 och 499 sätts färgen till blå (setRGB(0, 255, 0)), och meddelandet "Dim" skrivs ut.
      • Om ljusvärdet är mellan 500 och 699 sätts färgen till blå (setRGB(0, 255, 255)) och meddelandet "Light" skrivs ut.
      • Om ljusvärdet är mellan 700 och 949 sätts färgen till lila (setRGB(255, 255, 0)), och meddelandet "Bright" skrivs ut.
      • Om ljusvärdet är över 950 sätts färgen till röd (setRGB(255, 0, 0)), och meddelandet "Very bright" skrivs ut.

    • Fördröjning:
      Programmet väntar i 500 millisekunder (0,5 sekunder) innan det gör nästa ljusmätning. Detta gör att programmet inte uppdaterar så snabbt och gör det lättare att läsa data i den seriella monitorn och observera förändringar i LED-färgen.

  4. Funktion för att sätta RGB lysdiod-färg:
    Denna funktion setRGB() tar tre argument (värden mellan 0 och 255 för röd, grön och blå) och styr RGB-lysdiodens färg genom att använda analogWrite() på de respektive pinnarna.

    • analogWrite() används för att sätta PWM-värden (pulse-width modulation) på varje LED. Ett värde på 0 betyder att lysdioden är avstängd, och ett värde på 255 betyder att lysdioden är på full intensitet.

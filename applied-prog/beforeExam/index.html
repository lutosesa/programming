Del 1: Flervalsfrågor (12 frågor, 12 poäng) ​

Instruktion: Markera det korrekta alternativet (endast ett svar är rätt). Varje fråga är värd 2 poäng.

1. Vad används en variabel till i Arduino-programmering?     (1 p) ​

a) För att köra loopar
b) För att styra LED-lampor
c) För att lagra och hantera data i programmet
d) För att starta programmet

2. Vilken datatyp används för att lagra heltal i Arduino?     (1 p) ​

a) float
b) int
c) bool
d) char

3. Vad gör funktionen digitalWrite(pin, HIGH)?     (1 p) ​

a) Läser av signalen från en sensor
b) Stänger av strömmen på pinnen
c) Sätter en pinne i input-läge
d) Sätter en pinne till hög signal (spänning)

4. Hur många värden kan en bool datatyp representera?     (1 p) ​

a) 1
b) 2
c) 255
d) Oändligt många

5. Vilket av följande används för att läsa av en potentiometer?     (1 p) ​

a) analogRead(pin)
b) digitalRead(pin)
c) analogWrite(pin, value)
d) delay(milliseconds)

6. Vad händer om villkoret i en if-sats inte är sant?     (1 p) ​

a) Koden fortsätter direkt till nästa rad
b) Ett felmeddelande visas
c) Programmet stannar
d) Villkoret körs igen

7. Vad är korrekt syntax för att skapa en array i Arduino?     (1 p) ​

a) int myArray[5] = {1, 2, 3, 4, 5};
b) array myArray = [1, 2, 3, 4, 5];
c) int myArray = {1, 2, 3, 4, 5};
d) int myArray[5];

8. Vilket kommando kan användas för att pausa ett program i 1 sekund?     (1 p) ​

a) pause(1000);
b) delay(1000);
c) stop(1000);
d) wait(1000);

9. Vilken funktion används för att ställa in en pin som in- eller utgång i Arduino?     (1 p) ​

a) inSetup()
b) pinType()
c) pinMode()
d) setPin()

10. Vilken funktion används för att läsa av ett digitalt värde från en pin?       (1 p) ​

a) digitalRead()
b) readPin()
c) readDigital()
d) inputRead()

11. Vad gör funktionen delay(1000); i ett Arduino-program?   (1 p) ​

a) Stoppar programmet helt.
b) Väntar 100 millisekunder.
c) Väntar 1 sekund.
d) Kör loopen snabbare.

12. Vad är en korrekt syntax för att deklarera en array i Arduino?     (1 p) ​

a) int myArray = {1, 2, 3};
b) int myArray[] = {1, 2, 3};
c) array myArray[] = {1, 2, 3};
d) int[3] myArray = {1, 2, 3};


Del 2: Sant eller falskt (12 frågor, 12 poäng) ​

  1. Arduino använder programmeringsspråket Python.

  2. En potentiometer kan användas för att justera ljusstyrkan på en LED-lysdiod.

  3. En float datatyp kan representera decimalvärden.

  4. En buzzer kan användas för att blinka en LED-lysdiod.

  5. Funktionen pinMode måste användas i setup() innan en pin kan användas.

  6. En for-loop körs exakt en gång.

  7. Funktionen analogWrite() kan användas på digitala pins som stöder PWM (Pulse Width Modulation).

  8. Du kan använda delay() för att pausa programmet medan du läser av sensorer.

  9. Funktionen pinMode() måste alltid kallas i loop() för att ställa in en pin som in- eller utgång.

  10. Du kan läsa ett analogt värde från en digital pin med funktionen analogRead().

  11. En potentiometer ger en analog signal som kan läsas med funktionen analogRead().

  12. En for-loop används för att repetera kod tills ett visst villkor är uppfyllt.

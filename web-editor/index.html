Information om Webb Editor

Detta är en kraftfull webb-editor som låter dig skapa och redigera webbsidor direkt i din webbläsare. Du kan använda den för att skriva HTML, CSS och JavaScript utan att behöva installera någon programvara.

Funktioner inkluderar:

- Live-preview (förhandvisning)
- Att köra koden på webbläsaren
- Syntax highlighting
- IntelliSense (kodförslag)
- Kod-formattering
- Möjlighet att fälla ihop kodblock för bättre överblick
- Mörk och ljus tema
- Öka och minska kod-textstorlek
- Stänger automatiskt HTML-taggar
- Stänger automatiskt parenteser och citattecken
- Markera matchande parenteser
- Kommentera med ctrl + '
- Sök- och ersättningsfunktion
- Felsökning och varningar för syntaxfel
Emmet-monaco
- Snabbskrivning av HTML och CSS genom korta uttryck
- Skriv ! och tryck Tab, så får du en komplett HTML5-struktur

Python Villkorsatser if-elif-else ​

Villkor och if-satser är grundläggande byggstenar i alla programmeringsspråk. De tillåter programmet att fatta beslut och styra flödet av exekveringen baserat på specifika viilkor. I Python används if-satser för att skapa dessa beslutspunkter.

Denna delen kommer att täcka allt från grundläggande syntax till mer avancerade användningar av if-satser , inklusive elif och else, samt inbäddade och sammansatta villkor.

1. Grundläggande If-sats syntax ​

Den mest grundläggande formen av en if-satser i Python använder nyckelordet if följt av ett villkor och ett kolon-tecken (:). Kodblocket som ska exekveras om villkoret är sant skrivs indenterat (indrag) under if-satsen.

python
if villkor:
    # kodblock nedan exekveras om villkoret är sant
    print("Villkoret är sant")

Exempel

python
x = 10

if x > 5:
    print(f"{x} är större än 5")

Indentation (Indrag) ​

Python använder sig av indrag (blanksteg i början av en rad) för att definiera ett kodblock. Andra programmeringsspråk använder ofta klammerparenteser (måsvingar) för detta ändamål.

Exempel

If-sats, utan indrag (kommer att ge ett fel):

python
a = 33
b = 200

if b > a:
print(f"{b} är större än {a}!") # får felmeddelande

2. Använda Elif och Else ​

För att hantera flera villkor används elif-satser (förkortning för else if) och else.

En if-sats kan ha:

  • noll eller flera elif-satser
  • och exakt en else-sats.
python
if villkor1:
    # kodblock för villkor1
elif villkor2:
    # kodblock för villkor2
else:
    # kodblock om inga av ovanstående villkor är sanna

elif x == 5:
    print(f"{x} är lika med 5!")
else:
    print(f"{x} är mindre 5 och 15!")

3. Inbäddade If-satser ​

if-satser kan vara inbäddade inom andra if-satser. Detta möjliggör mer komplexa beslutsträd.

python
if villkor1:
    if villkor2:
        # kodblock körs om båda villkor1 och villkor2 är sant
    else:
        # kodblock körs om villkor1 är sant men inte villkor2
else:
    # kodblock körs om villkor1 inte är sant

4. Sammansatta villkor med logiska operatorer ​

Man kan kombinera flera villkor med logiska operatorer som and (och), or (eller), och not (inte).

python
if villkor1 and villkor2:
    # kodblock körs om båda villkor1 och villkor2 är sanna.
if villkor1 or villkor2:
    # kodblock körs om minst ett av villkor1 eller villkor2 är sant.
if not villkor:
    # kodblockkörs om villkoret inte är sant.

5. Villkor med flera satser ​

Ibland vill man att flera satser ska exekveras om ett villkor är sant. Detta görs genom att alla satser indenteras på samma nivå under if-satsen.

python
if villkor:
    # Kodblocket (första och andra satsen) körs om villkor är sant.
    print("Första satsen")  # första satsen    
    print("Andra satsen")   # andra satsen

6. Pass satsen ​

if-satsen kan INTE vara tomma, men om du av någon anledning har en if-sats UTAN innehåll, lägg i satsen nyckelordet pass för att undvika att få ett fel.

Exempel med nyckelordet pass i en tom if-sats, gör att man får inget fel.

python
x = 18

if x >= 18:
  pass
else:
    print("Visa ditt legitimationen (id-kort)!")

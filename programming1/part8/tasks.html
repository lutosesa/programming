Uppgift 3: Simulering av gissningstalsspel ​

Skapa ett program som simulerar ett enkelt gissningstalsspel.

Instruktioner:

  • Programmet ska generera ett slumpmässigt tal mellan 1 och 100, använd en variabel som döps till slumptal för att slumpa ett tal.
  • Be användaren att gissa ett tal. Använd en variabel som döps till gissningstal för att gissa.
  • Med varje gissning ska programmet tala om för användaren följande: (använd f-format för att printa ut)
    • f"{gissningstal} är RÄTT tal, GRATTIS!!!"
    • f"{gissningstal} är för hög, försök igen!"
    • f"{gissningstal} för låg, försök igen!"
  • Loopen ska fortsätta tills användaren gissar rätt.

Tips: Klicka här för att komma till en ledtråd som är NÄSTAN LIK denna

Uppgift 4: Oändliga loopar och hur man undviker dem ​

Instruktioner:

  • Skriv ett program som använder en while-loop med villkoret True för att räkna ner från 10 till 1.
  • När while-loopen har kommit till 1 ska du avbryta loopen genoma att använda nyckelordet break.
  • När while-loopen är avslutad ska skrivas ut följande meddelande: "Loopen är avslutad!"
  • Se till att programmet inte fastnar i en oändlig loop.
  • Diskutera hur man kan undvika oändliga loopar.

Koden ska visa följande utskrift:

python

1

Uppgift 5: Break-sats ​

Instruktioner:

  • Skapa ett program som fortsätter att fråga användaren efter ett tal tills användaren matar in talet 0.
  • Använd en while-loop och en break-sats för att avsluta loopen om användaren matar in 0.

Koden ska visa följande utskrift:

python
<Ange ett tal, tryck på 0 för att avsluta> 9
Du matade in: 9

<Ange ett tal, tryck på 0 för att avsluta> 5
Du matade in: 5

<Ange ett tal, tryck på 0 för att avsluta> 0

Programmet är avslutat!

Hur skapas textbaserad RPG-berättelse på PyCharm terminal ​

Introduktion ​

Denna handledning hjälper dig att skapa ett textbaserat Python RPG-berättelse (rollspel) på PyCharm terminal (konsol-fönster). Berättelsen kommer att innehålla de grundläggande begreppen som du vu har gått igenom hitills, nämligen:

  • variabler för att lagra data/info,
  • utmatning, print(), för att skriva ut text,
  • inmatning, input(), för att interagera med användaren,
  • if-satser för valmöjligheter,
  • while-loopar för att styra och skapa spelkontroll och
  • for-loopar för att gå igenom bestämda iterationer.

Målet är att skapa en enkel interaktiv berättelse där spelaren gör val som påverkar spelets gång och leder till olika situationer eller utfall.


Steg 1: Planera ditt spel ​

Innan du börjar koda är det bra att planera spelets innehåll och logik. Här är några grundläggande delar att tänka på:

  1. Berättelse och miljö: Tänk ut en enkel berättelse och vilken värld spelet utspelar sig i (t.ex. ett slott, en skog eller en rymdstation).
  2. Karaktärens mål: Bestäm vad huvudpersonen (spelaren) försöker uppnå. Det kan vara att hitta en skatt, lösa ett mysterium eller fly från en fara.
  3. Interaktiva val: Skapa olika val som spelaren kan göra som påverkar berättelsen. Exempelvis kan spelaren välja att prata med en NPC (icke-spelbar karaktär) eller utforska en ny plats.
  4. Föremål, information, attributer: Bestäm om spelaren kan hitta föremål (som nycklar), få information som hjälper dem i berättelsen eller få attribut som styrka, mod, skönhet,visdom, osv.

Steg 2: Skapa grunden till spelet i Python ​

Öppna ditt Python-program och börja med att skapa grundstrukturen. Ett textbaserat RPG-spel kan byggas upp med olika sektioner eller scener där varje scen representerar en plats eller ett händelseförlopp.

Välkomstmeddelande

python
print(f"{'*' * 60}")
print("  VÄLKOMMEN till det textbaserade RPG-ÄVENTYRET!    ")
print("\n Ditt mål är att hitta vägen ut ur det mystiska slottet.")
print(f"{'*' * 60} \n")

Steg 4: Bygg berättelsen med if-satser och input ​

Med hjälp av if-satser och input()-funktionen kan spelaren göra val som påverkar spelet.

Början av spelet - Huvudhall

python
print("\nDu befinner dig i en stor hall med tre dörrar: vänster, höger och framåt.")
val = input("Vart vill du gå? (vänster/höger/framåt): ")

if val == "vänster":
    print("Du går in i ett mörkt rum och ser något glittra i hörnet.")
    val = input("Vill du undersöka hörnet? (ja/nej): ")
    if val == "ja":
        print("Du hittar en nyckel!")
        har_nyckel = True  # Spelaren har nu nyckeln
    else:
        print("Du lämnar rummet utan att undersöka hörnet.")

elif val == "höger":
    print("Du går in i ett rum där en vakt står.")
    val = input("Vill du prata med vakten? (ja/nej): ")
    if val == "ja":
        print("Vakten säger att du behöver en nyckel för att komma förbi den låsta dörren.")
        har_pratat_med_vakt = True  # Spelaren har nu pratat med vakten
    else:
        print("Du går ut ur rummet utan att prata med vakten.")

elif val == "framåt":
    if har_nyckel:
        print("Du använder nyckeln och öppnar dörren framför dig. Du har hittat vägen ut!")
    else:
        print("Dörren är låst. Det verkar som att du behöver en nyckel.")
else:
    print("Ogiltigt val. Försök igen.")

Steg 5: Skapa en loop för att låta spelaren göra flera val ​

Medan spelet pågår kan vi använda en while-loop för att spelaren ska kunna utforska olika rum tills de hittar vägen ut.

Exempel: start på spelet med while-loop

python
# Starta spelet
while True:
    print("\nDu är tillbaka i huvudhallen. Du kan välja att gå vänster, höger eller framåt.")
    val = input("Vart vill du gå? (vänster/höger/framåt): ")

    if val == "vänster":
        # Koden för vänster rum
        if not har_nyckel:
            print("\nDu HITTAR en NYCKEL!")
            har_nyckel = True
        else:
            print("Rummet är tomt, du har redan tagit nyckeln härifrån.")

    elif val == "höger":
        # Koden för höger rum
        if not har_pratat_med_vakt:
            print("\nVakten påminner dig om att du behöver en nyckel.")
            har_pratat_med_vakt = True
        else:
            print("\nVakten nickar åt dig, som om han redan berättat allt.")

    elif val == "framåt":
        if har_nyckel:
            print("\nDu använder nyckeln och öppnar dörren framför dig. Grattis! Du har hittat utvägen!")
            break
        else:
            print("\nDörren är låst, du behöver en nyckel för att öppna den.")

    else:
        print("\nOgiltigt val. Välj vänster, höger eller framåt.")

Steg 6: Lägg till ljudeffekter ​

Att lägga till ljud till en textbaserad RPG-berättelse på en terminal utan att använda funktioner eller klassser kan vara en intressant utmaning! Låt oss gå igenom hur du kan göra det.

Modulen pygame kan användas för att både spela längre ljudfiler (som bakgrundsmusik) och kortare ljudklipp (som ljudeffekter).

Vad är Pygame? ​

Pygame är ett populärt Python-bibliotek (modul) som används för att utveckla spel och multimedieapplikationer. Det erbjuder funktioner för:

  • Grafik: Skapa fönster, hantera sprites och rendering.
  • Händelser: Hantera tangentbord, mus och joystick-ingångar.
  • Tidsstyrning: Hantera spel-loopar och tidssteg.
  • Ljud: Spela upp ljud- och musikfiler.

Pygame har ett modulärt ljudsystem som låter dig spela upp ljudfiler med formatet .wav, .ogg och .mp3.

Här är stegen för att integrera ljud på ett sätt som passar ditt projekt:

1. Installera Pygame ​

Om du inte redan har Pygame installerat, installera det med pip:

python
pip install pygame

2.Initiera ljudsystemet ​

För att använda ljud i Pygame måste du först initiera mixermodulen:

python
import pygame

pygame.init()
pygame.mixer.init()

3. Ladda ljudfiler ​

Pygame har två huvudsakliga ljudfunktioner:

  • pygame.mixer.music: För att spela längre ljudfiler (som bakgrundsmusik).
  • pygame.mixer.Sound: För att spela kortare ljudklipp (som ljudeffekter).
python
import pygame

pygame.mixer.music.load("bg_supermario.wav")   # Ladda bakgrundmusik

door = pygame.mixer.Sound("door.mp3")       # Ladda kort ljud

4. Spela upp ljud ​

Du kan spela upp ljud eller musik med olika metoder:

python
pygame.mixer.music.play()   # Spela upp badgrundmusik

door.play()                 # Spela upp kort ljud

pygame.mixer.music.stop()   # Stoppa bakgrundmusik

5. Extra funktioner ​

Det finns olika funktioner för att hantera uppspelning av bakgrundmusik:

Looping: Loopa musik

python
pygame.mixer.music.play(loops=-1)  # Loopa oändligt

Volymkontroll:

python
sound.set_volume(0.5)  # Volym mellan 0.0 och 1.0
pygame.mixer.music.set_volume(0.8)

Pausa och återuppta:

python
pygame.mixer.music.pause()
pygame.mixer.music.unpause()

Hur skapas textbaserad RPG på konsol ​

Introduktion ​

Denna handledning hjälper dig att skapa ett textbaserat Python RPG-spel (rollspel) på konsol-fönstret. Den innehåller de grundläggande begreppen för att lagra data i variabler, använda if-satser för valmöjligheter, samt while- och for-loopar för att skapa spelkontroll.

Målet är att skapa en interaktiv berättelse där spelaren gör val som påverkar spelets gång och leder till olika situationer eller utfall.


Steg 1: Planera ditt spel ​

Innan du börjar koda är det bra att planera spelets innehåll och logik. Här är några grundläggande delar att tänka på:

  1. Berättelse och miljö: Tänk ut en enkel berättelse och vilken värld spelet utspelar sig i (t.ex. ett slott, en skog eller en rymdstation).
  2. Karaktärens mål: Bestäm vad huvudpersonen (spelaren) försöker uppnå. Det kan vara att hitta en skatt, lösa ett mysterium eller fly från en fara.
  3. Interaktiva val: Skapa olika val som spelaren kan göra som påverkar berättelsen. Exempelvis kan spelaren välja att prata med en NPC (icke-spelbar karaktär) eller utforska en ny plats.
  4. Föremål, information, attributer: Bestäm om spelaren kan hitta föremål (som nycklar), få information som hjälper dem i berättelsen eller få attribut som styrka, mod, skönhet,visdom, osv.

Steg 2: Skapa grunden till spelet i Python ​

Öppna ditt Python-program och börja med att skapa grundstrukturen. Ett textbaserat RPG-spel kan byggas upp med olika sektioner eller scener där varje scen representerar en plats eller ett händelseförlopp.

Välkomstmeddelande

print("********************************************************")

Steg 4: Bygg berättelsen med if-satser och input ​

Med hjälp av if-satser och input()-funktionen kan spelaren göra val som påverkar spelet.

Början av spelet - Huvudhall

python
print("\nDu befinner dig i en stor hall med tre dörrar: vänster, höger och framåt.")
val = input("Vart vill du gå? (vänster/höger/framåt): ")

if val == "vänster":
    print("Du går in i ett mörkt rum och ser något glittra i hörnet.")
    val = input("Vill du undersöka hörnet? (ja/nej): ")
    if val == "ja":
        print("Du hittar en nyckel!")
        har_nyckel = True  # Spelaren har nu nyckeln
    else:
        print("Du lämnar rummet utan att undersöka hörnet.")

elif val == "höger":
    print("Du går in i ett rum där en vakt står.")
    val = input("Vill du prata med vakten? (ja/nej): ")
    if val == "ja":
        print("Vakten säger att du behöver en nyckel för att komma förbi den låsta dörren.")
        har_pratat_med_vakt = True  # Spelaren har nu pratat med vakten
    else:
        print("Du går ut ur rummet utan att prata med vakten.")

elif val == "framåt":
    if har_nyckel:
        print("Du använder nyckeln och öppnar dörren framför dig. Du har hittat vägen ut!")
    else:
        print("Dörren är låst. Det verkar som att du behöver en nyckel.")
else:
    print("Ogiltigt val. Försök igen.")

Steg 5: Skapa en loop för att låta spelaren göra flera val ​

Medan spelet pågår kan vi använda en while-loop för att spelaren ska kunna utforska olika rum tills de hittar vägen ut.

Starta spelet

python
# Starta spelet
while True:
    print("\nDu är tillbaka i huvudhallen. Du kan välja att gå vänster, höger eller framåt.")
    val = input("Vart vill du gå? (vänster/höger/framåt): ")

    if val == "vänster":
        # Koden för vänster rum
        if not har_nyckel:
            print("\nDu HITTAR en NYCKEL!")
            har_nyckel = True
        else:
            print("Rummet är tomt, du har redan tagit nyckeln härifrån.")

    elif val == "höger":
        # Koden för höger rum
        if not har_pratat_med_vakt:
            print("\nVakten påminner dig om att du behöver en nyckel.")
            har_pratat_med_vakt = True
        else:
            print("\nVakten nickar åt dig, som om han redan berättat allt.")

    elif val == "framåt":
        if har_nyckel:
            print("\nDu använder nyckeln och öppnar dörren framför dig. Grattis! Du har hittat utvägen!")
            break
        else:
            print("\nDörren är låst, du behöver en nyckel för att öppna den.")

    else:
        print("\nOgiltigt val. Välj vänster, höger eller framåt.")

Steg 6: Lägg till ljudeffekter ​

Att lägga till ljud till en textbaserad RPG-berättelse på konsol utan att använda funktioner eller listor kan vara en intressant utmaning! Låt oss gå igenom hur du kan göra det.

Eftersom din uppgift är begransad till grundläggande begrepp som datalagring i variabler (datatyper), if-satser, while-loopar och for-loopar, kan du använda modulen playsound för att spela upp ljudfiler.

Playsound ​

playsound är enkel och kräver bara ljud-filnamnet som argument, men den saknar avancerade ljudkontroller som stoppa, pausa, eller spela om ett ljud. Varje gång du anropar playsound, startar den om och spelar ljudet från början men har ingen inbyggd funktion för att stoppa ljudet under uppspelning.

Här är stegen för att integrera ljud på ett sätt som passar ditt projekt:

  1. Installera playsound
    För att kunna använda playsound, behöver du installera modulen.
  2. Välj ljudfiler för olika händelser
    Välj eller skapa ljudfler för specifika händelser som kan inträffa i spelet, t.ex.:
    • Ett ljud för bakgrundsmusik eller omgivningsljud
    • Ett ljud för att öppna en dörr.
    • Ett ljud för när spelaren plockar upp en nyckel.

Ljudfilerna kan vara i .mp3 eller .wav format. Spara dem i samma katalog som ditt Python-skript för enkel åtkomst.

Webbplats där du kan ladda ner ljudeffekter:
pixabay.com

  1. Exempel på kod
python
from playsound import playsound

playsound("door.mp3")  # Spela ljud för rummet

Simpleaudio ​

simpleaudio är ett Python-bibliotek som används för att spela upp ljudfiler som exempelvis .wav. Det är ett relativt enkelt och lättanvänt bibliotek för ljuduppspelning som fungerar på flera plattformar.

Här är stegen för att integrera ljud på ett sätt som passar ditt projekt:

  1. Installera simpleaudio
    För att kunna använda simpleaudio. behöver du installera modulen.
  2. Ladda och spela upp en ljudfil
    För att spela upp en .wav-fil, använd simpleaudio.WaveObject.from_wave_file() för att ladda filen och sedan play() för att starta uppspelningen.
python
import simpleaudio 

# Ladda ljudfilen
ljud = simpleaudio.WaveObject.from_wave_file("bg_sound.wav")

# Spela upp ljudet
uppspelning = ljud.play()

Fullständig kod för spelet ​

python
import simpleaudio as sa
from playsound3 import playsound

# # Ladda ljudfilen
ljudfil = sa.WaveObject.from_wave_file("mysterious.wav")

# Välkomstmeddelande
print("********************************************************")
print("  VÄLKOMMEN till det textbaserade RPG-ÄVENTYRET!    ")
print("\nDitt mål är att hitta vägen ut ur det mystiska slottet.")
print("********************************************************\n")

# Spela upp ljudet
uppspelning = ljudfil.play()

# Spelarens statusvariabler
har_nyckel = False
har_pratat_med_vakt = False

# Huvudloop
while True:
    print("\nDu är i huvudhallen med tre dörrar: vänster, höger och framåt.")
    val = input("Vart vill du gå? (vänster/höger/framåt): ")

    if val == "vänster":
        playsound("door.mp3")
        if not har_nyckel:
            print("Du hittar en nyckel!")
            har_nyckel = True
            playsound("key.mp3")
        else:
            print("Det finns inget mer här.")

    elif val == "höger":
        playsound("door.mp3")
        if not har_pratat_med_vakt:
            print("nVakten säger att du behöver en nyckel för att öppna den låsta dörren framåt.")
            har_pratat_med_vakt = True
        else:
            print("Vakten nickar åt dig.")

    elif val == "framåt":
        if har_nyckel:
            playsound("door.mp3")
            print("\nDu använder nyckeln och öppnar dörren. Du har klarat spelet!")
            break
        else:
            print("Dörren är låst. Du behöver en nyckel.")

    else:
        print("Ogiltigt val, försök igen.")

playsound("laugh.mp3")
print("\n****************************")
print("Tack för att du spelade!")
print("****************************\n")

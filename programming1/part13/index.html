Pyhton Moduler ​

Vad är en modul ? ​

En modul i Python är en fil som kan innehålla funktioner, variabler och klasser. Man kan se en modul som en verktygslåda där varje verktyg är en färdig funktion eller variabel. Genom att använda moduler kan man undvika att skriva om kod som redan finns tillgänglig och istället lägga till den i sitt program.

Exempel på moduler: ​

  • math: En modul som innehåller funktioner för matematiska operationer, som t.ex. kvadratrötter och trigonometri.
  • random: En modul som innehåller funktioner för att generera slumpmässiga tal.
  • datetime: En modul som hanterar datum och tid.

Hur använder man en modul? ​

För att använda en modul måste vi först importera den. Att importera betyder att vi säger till Python att vi vill använda kod från en specifik modul. Vi gör detta med nyckelordet import.

Exempel 1: Använda math-modulen ​

Exempel

python
import math

# Exempel: Beräkna kvadratroten av ett tal
tal = 16
kvadratrot = math.sqrt(tal)
print("Kvadratroten av 16 är:", kvadratrot)

  2. Vi använder funktionen sqrt() från math-modulen för att beräkna kvadratroten av 16. Resultatet blir 4, eftersom 4 gånger 4 är 16.

Exempel

python
import random

# Exempel: Generera ett slumpmässigt tal mellan 1 och 10
slumptal = random.randint(1, 10)
print("Ditt slumpmässiga tal är:", slumptal)

Skapa egen modul ​

Man kan också skapa egna moduler! För att skapa en egen modul, sparar man sin Python-kod i en .py-fil och sedan importerar man den filen som en modul i ett annat program.

Steg 1: skapa en modulfil ​

Skapa en ny fil och spara den som min_modul.py i PyCharm eller en annan textredigerare.

min_modul.py

python
def hej(namn):
    """Skriver ut ett välkomstmeddelande."""
    return f"Hej, {namn}! Välkommen till programmet."

def kvadrat(tal):
    """Returnerar kvadraten av ett tal."""
    return tal * tal

I den här modulen har vi två funktioner:

  • hej(namn): Tar emot ett namn som inmatning och returnerar ett välkomstmeddelande.
  • kvadrat(tal): Tar emot ett tal som inmatning och returnerar kvadraten av talet.

Steg 2: Använd modulen i ett annat program ​

Nu skapar vi en ny Python-fil där vi använder vår egen modul. Skapa en fil, till exempel anvand_min_modul.py, och skriv följande:

anvand_min_modul.py

python
# Importera vår egen modul
import min_modul

# Använd funktionen hej
namn = "Kalle"
meddelande = min_modul.hej(namn)
print(meddelande)

# Använd funktionen kvadrat
tal = 5
resultat = min_modul.kvadrat(tal)
print(f"Kvadraten av {tal} är: {resultat}")

  3. Vi använder min_modul.kvadrat(5) för att beräkna kvadraten av talet 5.

Genom att skapa en egen modul kan du enkelt återanvända funktioner och hålla din kod organiserad!
